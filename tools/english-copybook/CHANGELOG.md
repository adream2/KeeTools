## [1.0.0] - 2026-09-20

### 新增

- 标准**四线三格**字帖：导入单词 / 字母 / 短句后逐行排布，可选每行练习 1–8 遍
- 三种描红方式：**描红 + 自写**（首格灰字，推荐）/ 整行描红 / 整行自写
- 排版精度：文字用 SVG 以 `y = 字母基线` 定位，基线严格落在第 3 条线上；实测 `getBBox()` 字宽，超宽自动收字号；另提供「字号 %」与「基线微调」应对不同电脑字体
- 版式可调：行高 12 / 14 / 16 / 18mm、行间距 0 / 2 / 4mm、中文释义列、抬头与「姓名 / 班级 / 日期 / 评价」栏
- 内容来源：粘贴文本 / 打开文件（ET.Import 统一导入组件，自动识别 UTF-8 与 GBK），或一键载入示例（20 个常用单词、26 个字母 Aa–Zz、数字 0–9）
- 长内容自动把「每行遍数」调小，避免字挤成一条线；可导出 CSV 备份
- A4 打印：屏上预览即打印稿；快捷键 `1`/`2`/`3` 切换描红方式、`P` 打印
