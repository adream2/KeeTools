# 英语四线三格字帖

导入单词 / 字母 / 短句，一键生成 A4 四线三格书写练习纸（可描红、可留白）。纯前端、离线可用，双击 `index.html` 即用。

## 用法

1. 右上角 **导入单词**：粘贴单词表（一行一个，可直接粘贴 Excel 整列），或写成 `apple,苹果` 附带中文释义
   —— 也可以点 **示例词表** 快速载入 20 个常用词 / 26 个字母 / 数字 0–9。
2. 顶部页签选描红方式：

| 方式 | 说明 |
|---|---|
| 描红 + 自写（推荐） | 每行第一格印浅灰字，后面几格留白自己写 |
| 整行描红 | 整行浅灰字，适合刚学字母的学生 |
| 整行自写 | 只画四线三格 |

3. 点 **打印字帖**（或按 `P`）出纸：A4 纵向、缩放 100%，边距选「无 / 默认」最准。

## 设置（右上角 ⚙）

- **抬头**：标题、姓名 / 班级 / 日期 / 评价栏、中文释义列
- **四线格**：行高 12 / 14 / 16 / 18mm、行间距 0 / 2 / 4mm、每行遍数、字号 % 、基线微调（±1.5mm）
- **内容**：导入、示例词表、导出 CSV、清空

> **为什么需要「基线微调」**：四线格按「字母基线落在第 3 条线」排版，不同电脑安装的英文手写体字体 x 高略有差异。
> 若发现字母整体压线或悬空，用基线微调上下挪 0.2mm 对齐即可（设置会记住）。

## 数据保存

内容与设置保存在本机浏览器 `localStorage`（前缀 `et_english-copybook_`）。

## 关于统计模块

本工具包含一个**模块化**使用统计块（源码中标注 `et-stats`）：仅在联网条件下向站点上报一次匿名使用量（`use_offline`），不采集任何内容数据；未配置站点地址时完全静默。
**删除该 `<script>` 块即可让工具完全不联网**，其余功能不受任何影响。

## 快捷键

| 键 | 功能 |
|---|---|
| `1` / `2` / `3` | 描红 + 自写 / 整行描红 / 整行自写 |
| `P` | 打印 |
| 翻页笔下页键 | 打印 |
| 翻页笔上页键 | 导入内容 |
