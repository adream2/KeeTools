# 变更记录 — countdown-timer

## [1.4.0] - 2026-09-18

### 新增

- **正计时（秒表）模式**：顶部一键切换倒计时 / 正计时；开始、暂停、继续、清零齐全，快捷键与翻页笔通用
- 正计时**到点提醒**：可设一个时长，到时响铃 + 变红 + 提示（适合「超过 3 分钟就提醒」），↑↓ 可 ±30 秒调整并可取消
- 正计时进度环：设了提醒时长按进度显示，未设时每分钟走一圈；切换标签页 / 休眠回来不丢时间

### 变更

- 帮助与状态提示区分两种模式的快捷键含义（空格 = 开始 / 暂停，R = 重置）

## [1.3.0] - 2026-09-18

### 变更
- 计时数字改为 fg→主题色渐变大字 + 辉光（警示态渐变切换）
- 全局极光呼吸背景；「全屏体验」= 工具全屏（宿主直接全屏 iframe 本体，与工具内全屏按钮等效同屏，无嵌套）

## [1.2.0] - 2026-09-18

### 新增
- **激光笔 / 翻页笔适配**：下页键（PageDown）开始 / 暂停，上页键（PageUp）重置

## [1.1.0] - 2026-09-18

### 新增
- PWA 可安装（blob manifest + theme-color）
- 模块化使用统计（删除 et-stats 块即完全不联网）

### 变更
- 提示音音量整体提高；iframe 内全屏按钮委托宿主页面统一全屏

### 移除
- 打开时的一次性弹窗提示（体感第一）

## [1.0.0] - 2026-09-18

### 新增
- 初始版本
- 大字倒计时 + SVG 进度环（剩余比例可视化）
- 快捷预设（1/2/3/5/10/15/20/30 分钟）与自定义时:分:秒
- 暂停 / 继续 / 重置 / ±30 秒微调（运行中可调）
- 最后 10 秒数字变红 + 每秒滴答提示音，结束提醒音
- 「时间到」全屏定格展示（点击关闭）
- 空格 开始/暂停 · R 重置 · ↑↓ ±30 秒 快捷键
- 深浅色主题 / 全屏 / 音效开关
- 上次时长记忆（localStorage）
