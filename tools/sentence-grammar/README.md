# 句型与语法练习

英语语法单项选择练习：内置 12 题覆盖 be 动词、三单、进行时、名词复数、介词、疑问词等小学常见考点，支持导入题库。

纯前端、离线可用，双击 `index.html` 即用，投屏/白板均适配。

## 功能

- 每题 4 选 1，答后立即判定并显示**语法讲解**
- 选项顺序每题随机；支持乱序重练
- 结束页显示总分；导入格式：句子|选项A|B|C|D|答案|讲解

## 数据保存

设置与进度保存在本机浏览器 `localStorage`（前缀 `et_sentence-grammar_`），不上传任何数据。

## 合规说明

内置示例内容均为自编通用内容，不含任何教材逐课内容与第三方版权素材。
