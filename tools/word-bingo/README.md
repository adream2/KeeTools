# 单词宾果

英语单词 Bingo 课堂游戏：一键生成 3×3 / 4×4 / 5×5 宾果卡（每张排布不同）并打印，配课堂随机报词器。

纯前端、离线可用，双击 `index.html` 即用，投屏/白板均适配。

## 功能

- **卡片生成**：4/8/12/20 张，每张随机排布，5×5 中心免费格
- **课堂报词**：大字显示 + 语音朗读（可用时）、已报列表、撤销
- 预览卡片可点击模拟划词；打印每页 2 张
- 导入词表后自动校验是否够用（3×3 至少 9 词、4×4 至少 16、5×5 至少 25）

## 数据保存

设置与进度保存在本机浏览器 `localStorage`（前缀 `et_word-bingo_`），不上传任何数据。
