# 连词成句 · 排句成段

把打乱的词语排成句子、把打乱的句子排成段落：点卡组句、自动判定，内置示例，可导入自己的句子与段落。

纯前端、离线可用，双击 `index.html` 即用，投屏/白板均适配。

## 功能

- **连词成句**：点词卡组句，点句中词退回，全部用完自动判定
- **排句成段**：整句乱序卡排成通顺段落，练「找开头句、抓代词」
- 导入格式：连词成句每行一句（词间空格），排句成段空行分段
- 看答案、重排本题、进度与失误统计

## 数据保存

设置与进度保存在本机浏览器 `localStorage`（前缀 `et_sentence-order_`），不上传任何数据。

## 合规说明

内置示例内容均为自编通用内容，不含任何教材逐课内容与第三方版权素材。
