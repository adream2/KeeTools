## [1.0.0] - 2026-09-20

### 新增

- 三种规格：**4 × 4**（2×2 宫，低年级）、**6 × 6**（2×3 宫）、**9 × 9**（3×3 宫，标准）
- **实时出题**：回溯法生成终盘 → 逐格挖空并用「解的数量 ≤ 1」校验，保证**唯一解**；
  三档难度只影响挖空数量（9×9：36 / 45 / 52 格），一次生成通常 < 50ms
- 填数交互：点格子选中（同行 / 同列 / 同宫与相同数字自动高亮），数字键盘或键盘 `1–9` 填入，
  再按一次同一个数字可清除；`Backspace` / `0` 清除，方向键移动选中格
- **候选数（铅笔标记）**：点「候选」进入铅笔模式，数字以 3×3 小字记在格内，再点一次取消
- **冲突检测**：重复数字整格标红；**检查** 一键提示冲突数 / 剩余空格数 / 是否全部正确
- **提示**（补一格正确数）与 **显示答案**（二次确认后填满整盘）
- 计时与暂停：第一次填数开始计时，`空格` 暂停 / 继续；进度、用时与候选数都保存在本机
- A4 打印当前题目（屏上预览即打印稿，打印时隐藏控制条与数字键盘）
- 快捷键：`N` 新题目、`H` 提示、`C` 检查、`P` 打印、`空格` 暂停
