# 数独

程序实时出题的数独（4×4 / 6×6 / 9×9），带候选数、冲突检测、计时与打印。纯前端、离线可用，双击 `index.html` 即用。

## 怎么玩

| 操作 | 方式 |
|---|---|
| 选格子 | 鼠标 / 手指点击（同行、同列、同宫与相同数字会自动高亮） |
| 填数 | 下方数字键盘，或键盘 `1`–`9`；再点同一个数字可清除 |
| 清除 | `Backspace` / `Delete` / `0`，或键盘上的「清除」 |
| 移动选中格 | 方向键 `←` `↑` `↓` `→` |
| 候选数 | 点「候选」进入铅笔模式，此时数字以 3×3 小字记在格内（再点一次取消） |

题目给出的数字（黑色）不能修改；自己填的显示为蓝色，重复的显示为红色。

## 出题方式

- 三种规格：4 × 4（2×2 宫）/ 6 × 6（2×3 宫）/ 9 × 9（3×3 宫）
- 三档难度：简单 / 中等 / 困难 —— 只影响挖空数量（9×9 分别挖 36 / 45 / 52 格）
- 每道题都是**现场生成**：先用回溯法生成合法终盘，再逐格尝试挖空，每挖一格都用「解的数量 ≤ 1」校验，
  因此**每道题都有唯一解**，不预置题库（每次都是新题）

## 课堂用法

- 投影后点 **新题目** 换题；**提示** 补一格正确数；**检查** 标出冲突格或确认全部正确
- **打印** 把当前题目印成 A4 练习纸（屏上什么样、纸上就什么样）；想留空白练习可先打印再「显示答案」

## 数据保存

题目、已填内容、候选数、用时与设置保存在本机浏览器 `localStorage`（前缀 `et_sudoku_`），刷新或关掉再打开都能继续。

## 关于统计模块

本工具包含一个**模块化**使用统计块（源码中标注 `et-stats`）：仅在联网条件下向站点上报一次匿名使用量（`use_offline`），不采集任何内容数据；未配置站点地址时完全静默。
**删除该 `<script>` 块即可让工具完全不联网**，其余功能不受任何影响。

## 快捷键

| 键 | 功能 |
|---|---|
| `1`–`9` | 填数 / 切候选数 |
| `0` / `Backspace` / `Delete` | 清除当前格 |
| `←` `↑` `↓` `→` | 移动选中格 |
| `空格` | 暂停 / 继续计时 |
| `N` / `H` / `C` | 新题目 / 提示 / 检查 |
| `P` | 打印 |
| 翻页笔下页键 | 新题目 |
| 翻页笔上页键 | 提示 |
