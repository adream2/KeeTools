## [1.0.0] - 2026-09-19

### 新增

- 初始版本：单个生成 + 全班批量两种模式
- 内置 12 类表现特点标签、约 110 条原创短语句库（亲切 / 正式双文风）
- 含「纪律需加强」「基础需巩固」待改进项时自动切换鼓励型期望句，措辞软化
- 批量模式支持「姓名,特点1/特点2」格式（特点可省略随机抽取），一键导出带 BOM 的 CSV（Excel 直开）
- 生成后自动复制开关、最近 20 条历史记录（可在设置中清空），数据全部存本机
- 翻页笔 / 空格键主操作适配，深浅色主题，iframe 内全屏委托
