# 部首归类 · 形声字

把打乱的字卡按偏旁部首分桶归类：10 个常用部首、均为归属无争议的常用字，分对有讲解。

纯前端、离线可用，双击 `index.html` 即用，投屏/白板均适配。

## 功能

- 每轮 3–4 个部首桶 × 8/12 张字卡，随机组合反复玩
- 分对展示「形旁表义」讲解，渗透形声字规律
- 字库覆盖 氵扌木亻口艹讠女山日 十个高频部首（自编常用字，不含教材逐课生字表）
- 快捷键 1–4 快选部首桶

## 数据保存

设置与进度保存在本机浏览器 `localStorage`（前缀 `et_radical-sort_`），不上传任何数据。

## 合规说明

内置示例内容均为自编通用内容，不含任何教材逐课内容与第三方版权素材。
