## [1.1.0] - 2026-09-20

### 变更

- 大屏教学化改造（用户反馈：全屏显示太小 / 布局不合理 / 知识点不足）：
  - 布局重构——主区上限 1080px 放宽至 1720px，宽屏改为左右双栏
    （左 = 方程大卡，右 = 元素守恒核对 + 练习成绩 + 配平知识点卡，窄屏退化单列）；
  - 字号全面 `clamp()` 按视口缩放：方程 `clamp(24px, 3.4vw, 46px)`（原上限 30px），
    系数输入框、按钮、判定条、原子核对、成绩同步放大，后排看得清；
  - 新增「配平知识点」卡：质量守恒定律（配平依据）、三种常用配平方法
    （最小公倍数法 / 奇数配偶法 / 观察法，各带例题）、化学计量数的意义
    （系数比 = 微粒个数比、必须最简整数比）；
  - 新增反应类型动态讲解：随当前题显示四大基本反应类型特征（A+B→AB 等）。
