## [1.0.0] - 2026-09-20

### 新增

- 早读计时检测：设定时长（默认 15 分钟）后开始，按音量实时判定 **朗读中 / 声音过小 / 太吵** 三态
- 判定去抖：音量需连续达到设定秒数（默认 2 秒）才切换状态，避免咳嗽、翻书误判
- 达标统计：朗读时长、达标率（朗读时长 ÷ 已进行时长）、最长连续朗读、声音过小 / 太吵次数、平均与峰值音量
- 趋势折线按判定结果分段着色 + 阈值上下限虚线，一眼看出"哪些时段没在读"
- 结束时生成早读报告（评级 + 关键指标 + 改进建议），可导出 CSV / 复制文本
- 提示音：长时间声音过小、太吵持续过久时提醒（可在设置中关闭）
- 设置抽屉：检测时长、音量下限、音量上限、判定秒数、平滑系数、提示音
- 麦克风能力检测 + 优雅降级：不支持 / 非 HTTPS（file:// 打开）/ 拒绝授权 / 无设备 / 被占用
  五类状态各自给出中文引导，不白屏、不报错中断
- 共享逻辑复用：`mic-level`（取麦与电平）与 `level-chart`（趋势图）
- 翻页笔：下页键 = 开始 / 结束；深浅色主题；全屏；`localStorage` 持久化
