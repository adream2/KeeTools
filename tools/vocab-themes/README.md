# 主题词汇卡

按主题分类的英语单词卡：颜色/动物/食物/文具/身体/数字六大主题，学习卡翻面 + 4 选 1 小测验，支持导入词表。

纯前端、离线可用，双击 `index.html` 即用，投屏/白板均适配。

## 功能

- **学习卡**：单词 ↔ 释义翻面，附音标，可朗读
- **小测验**：随机 8 题，看中文选英文 / 看英文选中文交替，结束显示得分
- 内置 6 个主题 × 8 词（自编通用词），导入覆盖当前主题

## 数据保存

设置与进度保存在本机浏览器 `localStorage`（前缀 `et_vocab-themes_`），不上传任何数据。

## 合规说明

内置示例内容均为自编通用内容，不含任何教材逐课内容与第三方版权素材。
