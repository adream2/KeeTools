# 百数表探究器

一张可以「盖住、揭开、探规律」的百数表，投影提问与打印练习纸两用。纯前端、离线可用，双击 `index.html` 即用。

## 两种用法

### 投影提问（屏上）

| 操作 | 说明 |
|---|---|
| **遮罩提问**（默认） | 点格子盖住（再点揭开）。适合「被盖住的是几？」「38 的右边是几？」 |
| **随机挖空** | 一次盖住若干个格子（数量在 ⚙ 设置里调，3–60），全班抢答 |
| **相邻数探针** | 切到该模式后点一个数，四周标出 `−1 / +1 / −10 / +10`（每行 5 格时为 ±5），页脚给出完整算式 |
| **跳数高亮** | 顶部下拉选「2 / 3 / 5 / 10 个一数」，表中倍数整块变黄 |

### 打印练习纸

屏上看到什么就打印什么：

1. 先 **随机挖空**（或手工点若干格遮住）→ **打印** = 挖空练习卷；
2. 先 **全部揭开** → **打印** = 完整百数表 / 答案表；
3. 被遮格的显示样式（深色块 / 空白格 / ？）在 ⚙ 设置里选，「空白格」「？」更省墨、便于学生直接填。

A4 纵向、缩放 100%；浏览器若弹出边距选项，选「无 / 默认」最准。

## 设置（右上角 ⚙）

| 分组 | 可调项 |
|---|---|
| 表头 | 表格标题、姓名 / 班级 / 日期栏 |
| 表的结构 | 每行 10 格 / 5 格、1–100 / 1–50 |
| 挖空 · 遮罩 | 每次随机挖空个数、被遮格样式（深色块 / 空白格 / ？） |
| 当前状态 | 已遮哪些数、探针选中数，以及「随机挖空 / 全部揭开 / 导出答案 CSV」快捷按钮 |

## 数据保存

遮罩位置、探针选中数与设置保存在本机浏览器 `localStorage`（前缀 `et_hundred-chart_`）。

## 关于统计模块

本工具包含一个**模块化**使用统计块（源码中标注 `et-stats`）：仅在联网条件下向站点上报一次匿名使用量（`use_offline`），不采集任何内容数据；未配置站点地址时完全静默。
**删除该 `<script>` 块即可让工具完全不联网**，其余功能不受任何影响。

## 快捷键

| 键 | 功能 |
|---|---|
| `1` / `2` | 遮罩提问 / 相邻数探针 |
| `R` | 随机挖空 |
| `P` | 打印 |
| 翻页笔下页键 | 打印 |
| 翻页笔上页键 | 随机挖空 |
