## [1.0.0] - 2026-09-20

### 新增

- 可切换表结构：**1–100**（标准）/ **1–50**（低年级），每行 **10 格**（标准）或 **5 格**
- **遮罩提问**：点任意格子盖住 / 揭开，再点一次复原；被遮格可选「深色块 / 空白格 / ？ 」三种样式（打印练习纸建议后两种）
- **随机挖空**：一次随机盖住 N 格（3–60 可调），用于全班抢答「被盖住的是几？」
- **相邻数探针**：点一个数，四周自动标出 `−1 / +1 / −10 / +10`（每行 5 格时为 ±5），页脚给出完整算式，
  用于讲「上下相差一个十、左右相差一个一」
- **跳数高亮**：按 2 / 3 / 5 / 10 个一数高亮倍数，一眼看出 5 的倍数在列上、10 的倍数在行上
- A4 打印：屏上看到什么就打印什么（先挖空再打印 = 练习纸；先「全部揭开」再打印 = 答案表）
- 导出 CSV（数字 / 是否被遮 / 是否某数的倍数），便于备课留痕
- 快捷键：`1` 遮罩提问、`2` 相邻数探针、`R` 随机挖空、`P` 打印
