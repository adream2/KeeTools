# 英语字母表 更新记录

遵循 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/) 与[语义化版本](https://semver.org/lang/zh-CN/)。

## [Unreleased]

## [1.1.0] - 2026-09-18

### 修复

- 字母读音不再被语音引擎读成冠词弱读：读字母时在字母后加句点，并按「字母名 → 例词」的教材顺序朗读（A. apple.）

### 新增

- **点读设置抽屉**：语速（慢 / 正常 / 快）、朗读内容（字母 + 例词 / 只读字母 / 只读例词）、**具体语音选择**——列出本机全部英语音色并按音质优选（优先 Natural / Neural / Google，避开机械音）
- 音标体系可切换：美式（KK）/ 英式（DJ）；o、r、z 三个字母英美读音不同，详情弹窗会同时列出两种读法
- 顶栏状态显示当前实际使用的语音名称；本机没有英语语音时明确提示安装 English 语音包

### 变更

- 卡片 / 列表 / 翻页朗读统一走「字母 + 例词」，详情弹窗默认只读字母名

## [1.0.0] - 2026-09-18

### 新增

- 初始版本：26 个字母的大小写、国际音标与例词，元音字母高亮
- 卡片 / 列表两种视图，点击放大详情（含大小写写法提示）
- 点击即读：读字母名与例词（浏览器内置语音，能力检测，不支持时静默降级并提示）
- 翻页笔翻页（上页 / 下页键）浏览字母，空格键朗读当前字母
