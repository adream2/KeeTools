# 观察物体 · 三视图

用小正方体搭立体图形，实时给出主视图 / 左视图 / 俯视图。投影讲解与打印练习两用。纯前端、离线可用，双击 `index.html` 即用。

## 怎么搭

在「**从上面看（俯视图）**」的格子里：

- 点一下 = 这一格摆 1 个小正方体
- 再点 = 加一层（每格最多 4 层）
- 点到 0 = 拿走

左侧的**立体图**（等距投影）和右边的**主视图 / 左视图**会实时跟着变。

## 三视图口径

| 视图 | 观察方向 | 说明 |
|---|---|---|
| **主视图** | 从前往后看 | 每一列的高度 = 这一列（前后方向）最高的那格 |
| **左视图** | 从左往右看 | 每一列的高度 = 左右方向那一排最高的那格 |
| **俯视图** | 从上往下看 | 就是底面格子与层数（数字 = 这格的层数） |

## 两种玩法

- **搭一搭**：边搭边看三视图，理解「看到的是平面图形」
- **猜一猜**：遮住主视图与左视图 —— 请学生看立体图说「从正面 / 左面看是什么形状」，再点「显示三视图」对照

**打印**：把当前搭法与三视图印成 A4（编辑格子不打印），可作为课堂练习或课后作业。

## 数据保存

当前搭法、玩法与三视图显隐保存在本机浏览器 `localStorage`（前缀 `et_solid-views_`）。

## 关于统计模块

本工具包含一个**模块化**使用统计块（源码中标注 `et-stats`）：仅在联网条件下向站点上报一次匿名使用量（`use_offline`），不采集任何内容数据；未配置站点地址时完全静默。
**删除该 `<script>` 块即可让工具完全不联网**，其余功能不受任何影响。

## 快捷键

| 键 | 功能 |
|---|---|
| `1` / `2` | 搭一搭 / 猜一猜 |
| `R` | 随机搭一个 |
| `V` | 隐藏 / 显示三视图 |
| `P` | 打印 |
| 翻页笔下页键 | 随机搭一个 |
| 翻页笔上页键 | 隐藏 / 显示三视图 |
