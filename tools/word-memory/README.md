# 单词配对连连看

导入词表即玩的单词配对游戏（记忆翻牌 / 明牌配对），投屏可全班轮流上台。纯前端、离线可用，双击 `index.html` 即用。

## 两种玩法

| 玩法 | 规则 | 适合 |
|---|---|---|
| **记忆翻牌** | 牌面全部朝下，翻两张配「英文 ↔ 中文」，配对成功保持翻开 | 词汇记忆 |
| **明牌配对** | 牌面全部朝上，直接点两张配对的牌 | 低年级 / 快速热身 |

- 配对规则：一张 **英文** 卡 + 一张 **中文** 卡属于同一词条
- 记录 **步数** 与 **用时**，按规模分别保存本机最佳成绩
- 牌面规模：4 / 6 / 8 / 10 / 12 对（顶部下拉或 ⚙ 设置），每局从词表里**随机抽取**

**投屏玩法**：学生轮流上台翻两张，说对了全班跟读；点「全部亮一下」给 2 秒记忆时间再开始。

## 导入词表

点 **导入词表** 粘贴单元词汇，一行一个：`apple,苹果`（第二列是配对用的中文面，建议填写）。
支持逗号 / Tab 分隔、带表头 CSV 与 JSON 数组。

> 内置示例为 **20 个通用基础词汇**（自编），不含任何教材单元词表。

## 数据保存

词表、玩法、规模与最佳记录保存在本机浏览器 `localStorage`（前缀 `et_word-memory_`）。

## 关于统计模块

本工具包含一个**模块化**使用统计块（源码中标注 `et-stats`）：仅在联网条件下向站点上报一次匿名使用量（`use_offline`），不采集任何内容数据；未配置站点地址时完全静默。
**删除该 `<script>` 块即可让工具完全不联网**，其余功能不受任何影响。

## 快捷键

| 键 | 功能 |
|---|---|
| `1` / `2` | 记忆翻牌 / 明牌配对 |
| `空格` / `回车` | 重开一局 |
| `P` | 全部亮一下 |
| 翻页笔下页键 | 重开一局 |
| 翻页笔上页键 | 全部亮一下 |
