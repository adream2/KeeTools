# 变更记录 — scoreboard

## [1.3.0] - 2026-09-18

### 变更
- 全局极光呼吸背景；「全屏体验」= 工具全屏（宿主直接全屏 iframe 本体，与工具内全屏按钮等效同屏，无嵌套）

## [1.1.0] - 2026-09-18

### 新增
- 右上角「队伍 / 设置」抽屉：导入队伍名、导出 CSV（含得分）、按组号快速生成（`第{n}组`）
- **离线名单**：同目录 `roster.js`（或在线 `roster.txt`）打开即自动加载队伍
- PWA 可安装 + 模块化使用统计（删除 et-stats 块即完全不联网）

### 变更
- 提示音音量整体提高；iframe 内全屏委托宿主统一处理

### 移除
- 打开时的一次性弹窗提示

## [1.0.0] - 2026-09-18

### 新增
- 初始版本
- 多小组计分（2–8 队，自动配色，可重命名）
- ±1 / ±5 快捷加减分，加减分即时动画反馈
- 计分历史（最近 200 条，含时间与分数变化）与一键撤销
- 领先队伍皇冠标记与高亮描边
- 队伍名批量导入（复用 `et-import`）
- 分数清零 / 历史清空 / 深浅色主题 / 全屏
- 计分板状态 localStorage 持久化
