## [1.1.0] - 2026-09-19

### 新增

- **词库扩充至 645 条**：小学 245 / 初中 254 / 高中 146，覆盖小初高常用成语，条目带学段标注
- **学段筛选条**：词典页新增「全部 / 小学 / 初中 / 高中」筛选，与首字筛选、关键词检索可叠加生效
- **词库导入 / 导出**（设置抽屉内）：导出为带 BOM 的 CSV（`成语 / 释义 / 出处 / 学段`），可用 Excel 直接打开；导入支持 JSON 对象数组、`{成语:"释义"}` 映射、字符串数组与 CSV（自动跳过表头），并可与内置词库合并或整体替换
- 详情面板新增「学段」字段

### 变更

- 接龙合法性校验、首字索引与检索统一改走合并后的词库索引，导入的成语也参与接龙
