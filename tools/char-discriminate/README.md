# 多音字 · 形近字辨析卡

三类识字辨析卡（多音字 / 同音字 / 形近字），投影讲解与打印卡片两用。纯前端、离线可用，双击 `index.html` 即用。

## 三类卡片

| 类型 | 内置 | 卡面内容 |
|---|---|---|
| **多音字** | 9 张（长 / 行 / 乐 / 数 / 觉 / 种 / 发 / 着 / 重） | 大主字 + 每个读音 + 例词 + 辨析要点 |
| **同音字** | 6 组（在·再、做·作、坐·座、的·得·地、那·哪、元·园·圆） | 大字形 + 例词 + 辨析要点 |
| **形近字** | 6 组（士·土、未·末、己·已·巳、日·曰、天·夭、刀·力） | 大字形 + 例词 + 辨析要点 |

## 课堂用法（推荐节奏）

1. 出示卡片（默认显示答案时可先点「隐藏答案」）
2. 请学生**认读 / 组词 / 说区别**
3. 点 **看答案** 揭晓读音、例词与「怎么分」要点，对照订正

## 打印

- **打印**：只印当前这一张（A4，屏上什么样纸上就什么样）
- **打印全部**：把当前类型的全部卡片排成 A4 卡片页，每页 3 张，打印后**沿边框裁剪**即可当实体卡片
- 浏览器设置：A4 纵向、缩放 100%，边距选「无 / 默认」最准

## 内容说明

内置卡片全部是**通用汉字知识**（自编），不含任何教材生字表、单元编排或教辅内容。

## 自定义数据（导入 / 导出）

右上角「设置 → 卡片数据」：

- **导入**：按当前类型**替换式导入**，支持粘贴文本（逗号 / Tab 分隔）、带表头 CSV、JSON 数组
  - 多音字四列：`主字, 读音（多个用 | 分隔）, 例词（组间 |，组内空格/顿号）, 要点`
  - 同音 / 形近三列：`字头（用 / 分隔）, 例词（组间 |，组内空格/顿号）, 要点`
- **导出 CSV**：当前类型全部卡片，含 UTF-8 BOM，可用 Excel / WPS 编辑后**原样导回**
- **恢复内置卡片**：清掉当前类型的自定义数据

## 数据保存

自定义卡片、当前类型、卡片序号、是否显示答案保存在本机浏览器 `localStorage`（前缀 `et_char-discriminate_`），不上传服务器。

## 关于统计模块

本工具包含一个**模块化**使用统计块（源码中标注 `et-stats`）：仅在联网条件下向站点上报一次匿名使用量（`use_offline`），不采集任何内容数据；未配置站点地址时完全静默。
**删除该 `<script>` 块即可让工具完全不联网**，其余功能不受任何影响。

## 快捷键

| 键 | 功能 |
|---|---|
| `1` / `2` / `3` | 多音字 / 同音字 / 形近字 |
| `←` / `→` | 上一张 / 下一张 |
| `A` | 显示 / 隐藏答案 |
| `P` | 打印 |
| 翻页笔下页键 | 下一张 |
| 翻页笔上页键 | 看答案 |
