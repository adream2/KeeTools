## [Unreleased]

## [1.1.0] - 2026-09-21

### 新增

- **数据导入**：右上角「设置 → 卡片数据 → 导入」，按当前类型**替换式导入**教师自定义卡片；
  复用共享导入组件（`ET.Import`），支持粘贴文本（逗号 / Tab 分隔）、带表头 CSV 与 JSON 数组，
  自动识别 UTF-8 / GBK 编码、首列去重、空行与格式错误逐行提示
- **数据导出**：当前类型全部卡片导出 CSV（UTF-8 BOM，Excel / WPS 可直接编辑后原样导回）；
  内置卡片也可导出作为编辑模板
- **恢复内置卡片**：一键清掉当前类型的自定义数据
- 导入格式：多音字按「主字 / 读音 / 例词 / 要点」四列，同音 / 形近按「字头 / 例词 / 要点」三列；
  多读音 / 多组例词用 `|` 分隔，组内例词用空格或顿号分隔

### 变更

- **屏上改为屏幕适配布局**：卡片视图不再固定 A4 纸面（210mm），改为流式宽度（最大 860px）+
  `clamp()` 流式字号，窄屏（≤560px）读音与例词上下堆叠，手机 / 平板 / 大屏投均可直接使用
- **A4 精确排版（mm / pt）全部移入 `@media print`**：屏幕看屏幕的，打印才是打印稿；「打印」与
  「打印全部」（每页 3 张裁剪卡）的纸张行为不变
- 顶栏移除与工具条重复的 4 个图标按钮（上一张 / 下一张 / 看答案 / 打印全部），小屏更清爽；
  快捷键与翻页笔映射不变
- 帮助弹窗、README 同步补充自定义数据说明

## [1.0.0] - 2026-09-21

### 新增

- 三类辨析卡：**多音字**（9 张：长 / 行 / 乐 / 数 / 觉 / 种 / 发 / 着 / 重）、
  **同音字**（6 组：在·再、做·作、坐·座、的·得·地、那·哪、元·园·圆）、
  **形近字**（6 组：士·土、未·末、己·已·巳、日·曰、天·夭、刀·力）
- 每张卡：大字号主字（或字形组）+ 读音 + 例词 + **「怎么分」辨析要点**
- 讲解节奏：默认显示答案，也可一键「隐藏答案」—— 先让学生认读、组词、说区别，再揭晓对照
- 导航：上一张 / 下一张 / 随机一张；类型页签切换
- **打印**：默认打印当前卡片（屏上即打印稿）；「打印全部」把当前类型排成 A4 卡片页（每页 3 张，可裁剪成实体卡）
- 快捷键：`1`/`2`/`3` 切换类型、`←`/`→` 上一张 / 下一张、`A` 看答案、`P` 打印
- 内容为**通用汉字知识**（自编），不含任何教材生字表或单元编排
