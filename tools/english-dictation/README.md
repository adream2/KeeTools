# 英语听写

英语单词听写练习：语音报词（或看中文提示默写），逐词判对错，结束生成成绩单与错词本，可一键重测错词。

纯前端、离线可用，双击 `index.html` 即用，投屏/白板均适配。

## 功能

- 语音报词：浏览器语音合成（每词 1–3 遍可调）；无语音环境自动降级为「看中文释义默写」
- 逐词判定即时反馈；结束显示得分与错词对照（正确拼写 vs 你写的）
- **重测错词**：一键只听写本轮错词
- 导入词表：单词,释义 两列（支持 Excel 粘贴）

## 数据保存

设置与进度保存在本机浏览器 `localStorage`（前缀 `et_english-dictation_`），不上传任何数据。

内置示例内容均为自编通用内容，不含任何教材逐课内容与第三方版权素材。
