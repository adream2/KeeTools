# 噪音计

用麦克风实时测教室音量的大屏工具：超阈值变色提醒，记录峰值、平均值与超标次数。适合自习课、午休、考场纪律监督。

## 使用要求（重要）

本工具需要**麦克风权限**（`getUserMedia`），首次点「开始监测」时浏览器会弹出询问，请选择「允许」。

| 打开方式 | 能否取麦 |
|---|---|
| 网站「在线体验」/ HTTPS 部署 | ✅ 稳定可用（推荐） |
| `http://` 非 localhost 页面 | ❌ 浏览器直接禁止 |
| 本地服务器 / `localhost` | ✅ 可用 |
| 直接双击本地文件（`file://`） | ⚠️ 取决于浏览器安全策略（Safari 等会直接拒绝；被拒绝时工具会给出引导，不会白屏） |

被拒绝时：点地址栏左侧的权限图标（或站点设置 → 麦克风）改成「允许」后重新开始；
若本地文件方式始终被拒，请改用在线体验或在 HTTPS 环境下打开。

> 📌 之所以这样设计：浏览器只在**安全上下文**里开放麦克风，这是浏览器的安全限制，不是工具故障。

## 怎么用

1. 点「开始监测」并允许麦克风权限 → 大屏显示实时音量与状态（安静 / 正常 / 偏吵 / 太吵）
2. 超过阈值（默认 65 dB）画面转红并播放提示音（3 秒节流，避免连续响）
3. 需要时点顶栏「复位统计」重新开始计数

### 关于读数：这是「近似分贝」

浏览器拿不到专业声级计的标定，因此显示的是 **dBFS + 校准偏移** 换算出的近似值：

- 首次使用建议在**安静教室**里，开始监测后点设置里的「按当前环境校准」（把当前环境定标为 40 dB）；
- 也可手动调整「校准偏移」（默认 90，数值越大读数越高）；
- 读数用于**课堂横向比较**（现在比刚才吵 / 哪个组更安静）是可靠的，**不能代替声级计做正式测量**。

其他可调项：阈值、平滑系数（越大越稳、越小越灵敏，默认 0.85）、超阈值提示音开关。

## 状态与颜色

| 状态 | 条件 | 颜色 |
|---|---|---|
| 安静 | < 阈值 − 15 dB | 绿 |
| 正常 | 阈值 − 15 ~ 阈值 | 蓝 |
| 偏吵 | 阈值 ~ 阈值 + 10 | 橙 + 提示音 |
| 太吵 | > 阈值 + 10 dB | 红 + 提示音 |

## 快捷键

| 键 | 功能 |
|---|---|
| `空格` / 翻页笔下页键 | 开始 / 停止监测 |

## 数据保存

阈值、校准与平滑设置保存在本机浏览器 `localStorage`（前缀 `et_noise-meter_`）；统计与曲线仅存在于本次会话，刷新即清空。

## 共享逻辑

麦克风采集（`mic-level`）与趋势图（`level-chart`）来自 `tools/_shared/logic/`，由 `scripts/sync_shared.py` 内联——同一逻辑不在多个工具里重复维护。

## 关于统计模块

本工具包含一个**模块化**使用统计块（源码中标注 `et-stats`）：仅在联网条件下向站点上报一次匿名使用量（`use_offline`），不采集任何音频或内容数据；未配置站点地址时完全静默。
**删除该 `<script>` 块即可让工具完全不联网**，其余功能不受任何影响。

> 隐私说明：音频只在浏览器内实时计算音量，**不上传、不录制、不保存**。
