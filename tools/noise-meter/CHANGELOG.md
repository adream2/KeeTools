## [1.0.0] - 2026-09-20

### 新增

- 麦克风实时测音量：大屏大字号分贝读数 + 安静 / 正常 / 偏吵 / 太吵四级状态着色
- 横向电平条（带阈值刻度线）与「最近 60 秒」趋势折线，超阈值区段自动转橙 / 红
- 阈值提醒：超过阈值时画面转红并播放提示音（3 秒节流，可在顶栏静音）
- 统计：当前 / 峰值 / 平均 / 超标次数 / 已监测时长，一键复位
- 校准：dBFS → 近似 dB SPL 偏移可调，支持按参照仪校准（读数标注为「近似分贝」）
- 设置抽屉：阈值、校准偏移、平滑系数、提示音、复位统计
- 麦克风能力检测 + 优雅降级：不支持 / 非安全上下文（http 打开）/ 拒绝授权 / 无设备 / 被占用
  五类状态各自给出中文引导，不白屏、不报错中断；以本地文件（file://）打开时另给「可能被浏览器策略拒绝」
  的提示与替代用法（在线体验 / HTTPS）
- 共享逻辑复用：`mic-level`（取麦与电平）与 `level-chart`（趋势图），不在工具内重复实现
- 翻页笔：下页键 = 开始 / 停止；空格键同；深浅色主题；全屏；`localStorage` 持久化
