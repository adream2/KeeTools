# 口算题生成器 更新记录

遵循 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/) 与[语义化版本](https://semver.org/lang/zh-CN/)。

## [Unreleased]

## [1.1.0] - 2026-09-18

### 新增

- **在线答题模式**：每题横线上填写答案，回车跳下一题；点「批改」自动判分——逐题标 ✓ / ✗、错题直接显示正确答案，并给出正确题数、得分与做题用时
- 「重做」清空重答；「只练错题」用本次错题重新组一份卷子
- 答案容错：全角数字、空格自动归一，「7……3 / 7余3 / 7...3」等余数写法都算对

### 修复

- **算式溢出格子**：新增按实际列宽逐轮收敛的字号自适应（最多四轮），同时收紧答案位宽；打印时固定 15px 字号，A4 上不再溢出

### 变更

- 空格键在答题模式 = 批改、题卷模式 = 再来一份；帮助与设置抽屉补充两种模式说明

## [1.0.0] - 2026-09-18

### 新增

- 初始版本：加减乘除（可多选）按数值范围自动出题，题量 10/15/20/30 可选
- 答案显隐一键切换，支持打印题卷（`@media print` 隐藏工具栏）或另存为 PDF
- 减法不出现负数、除法默认整除、除数为 0 永不出现；同卷内题目去重
- 每题答题横线、题号、四列网格排版，参数本机持久化
