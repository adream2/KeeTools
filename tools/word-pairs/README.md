# 词语搭配 · 近反义词

左右连线配对游戏：近义词、反义词、词语搭配三种玩法，内置示例词对，可导入老师自己的词对。

纯前端、离线可用，双击 `index.html` 即用，投屏/白板均适配。

## 功能

- 三种玩法：近义词配对 / 反义词配对 / 「的」字短语搭配
- 点左词再点右词连线，配错抖动提示，统计失误与用时
- 内置示例词对各 8 对（自编通用词），支持导入覆盖（按玩法分别保存）

## 数据保存

设置与进度保存在本机浏览器 `localStorage`（前缀 `et_word-pairs_`），不上传任何数据。

## 合规说明

内置示例内容均为自编通用内容，不含任何教材逐课内容与第三方版权素材。
