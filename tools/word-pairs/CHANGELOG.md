## [1.2.0] - 2026-09-21

### 新增

- **配对成功连线**：左右两列之间加 SVG 覆盖层，配对成功即在两个词块之间画出绿色贝塞尔曲线
  （带端点圆点），课堂投影下连对一目了然；窗口缩放 / 区域滚动时自动重绘
- **选中效果强化**：选中词块改为主题色实底 + 白字 + 放大 6% + 呼吸光晕动画，大屏远看也清晰
- **两列间距加宽**：中缝从 18px 加宽到 clamp(56px, 8vw, 140px)，列宽上限提升到 clamp(240px, 32vmin, 480px)，
  给连线留出空间、大屏利用率更高
- 已配对词块改浅绿底（与连线同色系），不再用蓝色弱底 + 过度降透明度

### 修复

- **左列点击抛 `ReferenceError: pickSide is not defined`**：点击处理里引用了从未声明的
  `pickSide`（早期双方向点选设计遗留的死代码），严格模式下抛错中断渲染 —— 这是「选中没有效果」的
  真正根因；删除该死代码后选中分支恢复正常（此前探针只验了右列配对路径，未覆盖左列选中，故未发现）

## [1.1.1] - 2026-09-21

### 修复

- **内置词对永远加载不出来**：`loadData()` 按「对象字段 `a`/`b`」过滤数据，而内置示例是字符串对数组
  （`['美丽','漂亮']`），恒被过滤掉 → 打开工具左右两列空白。现兼容两种格式（内置数组对 / 导入对象）
- **类型切换无视觉反馈**：连锁问题——切换后渲染的仍是空列表，看起来毫无变化；另补上
  类型页签高亮同步（`setMode` 与启动时按存储的玩法恢复高亮，之前高亮永远停在「近义词」）

> 排查说明：批 C 交付时的点击探针在 `<head>` 预置了 localStorage 自定义词表（对象格式），
> 恰好绕过了这条内置数据路径，探针与 runtime 门禁都未能暴露此 bug。
