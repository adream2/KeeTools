# 作文稿纸生成器

按需生成 A4 作文稿纸（方格 / 横线），填上题目直接打印。纯前端、离线可用，双击 `index.html` 即用。

## 用法

1. 右上角 **⚙ 设置 → 抬头**：填写作文题目（留空则不打印标题），按需开关「姓名 / 班级 / 学号 / 得分」栏、字数栏、页脚。
2. **纸型**：
   - 方格稿纸：每行 15 / 20 / 25 格 × 15 / 20 / 25 行。**20 × 20 = 400 格**是标准作文纸；一二年级建议 15 × 15。
   - 横线稿纸：写话练习用，行高 10 / 12 / 14mm。
3. 顶部页签也能直接切换纸型；点 **打印稿纸**（或按 `P`）出纸。

> 屏上看到的就是打印出来的，不需要二次排版。A4 纵向、缩放 100%；浏览器若弹出边距选项，选「无 / 默认」最准。

## 设置（右上角 ⚙）

| 分组 | 可调项 |
|---|---|
| 抬头 | 作文题目、姓名栏、字数栏、页脚 |
| 纸型 | 方格稿纸 / 横线稿纸 |
| 方格稿纸 | 每行格数、行数 |
| 横线稿纸 | 行数、行高 |
| 份数 | 一次打印 1–5 页 |

## 数据保存

设置保存在本机浏览器 `localStorage`（前缀 `et_writing-paper_`），关掉页面再打开继续有效。

## 关于统计模块

本工具包含一个**模块化**使用统计块（源码中标注 `et-stats`）：仅在联网条件下向站点上报一次匿名使用量（`use_offline`），不采集任何内容数据；未配置站点地址时完全静默。
**删除该 `<script>` 块即可让工具完全不联网**，其余功能不受任何影响。

## 快捷键

| 键 | 功能 |
|---|---|
| `1` / `2` | 方格稿纸 / 横线稿纸 |
| `P` | 打印 |
| 翻页笔下页键 | 打印 |
| 翻页笔上页键 | 切换纸型 |
