## [1.2.0] - 2026-09-20

### 新增

- 画布右上角新增「轨道视角 / 地球视角」切换（快捷键 <kbd>V</kbd>）：地球视角把镜头放在地心并锁定月球，
  **月面形状就是当晚天空中的月相**，拖月龄即可看到月牙 → 弦月 → 凸月 → 满月连续变化，与右侧大图一致；
  该视角下按「太阳光线」还会标出太阳在天空中的方向（亮面永远朝着它）
- 画布右上角新增「复位视角」按钮（双击画面同效）

### 修复

- 全屏后模型跑出画面且拖不回来：改为自动取景（见下），并接入 `ResizeObserver` + `fullscreenchange`
- 月相亮面画反：晨昏线椭圆弧方向标志取反，亮面被画成互补形状（上弦月成了细月牙）
- 亮面比例与右侧大图对不上（上弦月显示 74%）：光照改为无限远平行光（与画出的平行光线一致），
  弦月恢复 50%

### 变更

- 球面光照改为按真实晨昏线绘制：按「球心 → 太阳」方向实时求亮面比例 `k = (1 + lz) / 2`
  与晨昏线椭圆弧（短半轴 `r·(2k−1)`），不再是「亮斑渐变」的假光照
- 默认视角改为教科书式侧上方视角（太阳在画面右侧、相机垂直于日地连线）：
  月球亮面朝太阳、晨昏线正对地球，「亮面永远朝向太阳」一眼可见

## [1.1.0] - 2026-09-20

### 变更

- 成因示意图由 2D SVG 俯视图改为 **3D 模拟场景**（Canvas 手写渲染：透视投影 + 球体光照，
  零依赖离线可用）：太阳 / 地球 / 月球 / 轨道虚线圆 / 太阳光线箭头全部 3D 化，
  月球亮面按「太阳→球心」方向实时着色，盈亏随视角自然呈现
- 场景支持**拖拽旋转视角 / 滚轮缩放**（视角参数持久化）；轨道上 8 个迷你月球按投影坐标点击命中，
  可跳转到对应月相；星空背景随视角产生视差
- 保留：月龄滑块 / 播放（约 16 秒一个朔望月）/ 太阳光线开关 / 八个典型月相按钮 / 面板大图与农历
