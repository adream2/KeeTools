# 自然拼读表

可发音的自然拼读表：26 个字母、短元音、Magic E、辅音组合、长元音组合、R 音节六大分组，点卡片朗读例词。

纯前端、离线可用，双击 `index.html` 即用，投屏/白板均适配。

## 功能

- 六大分组由易到难，覆盖小学阶段主要拼读规律
- 点卡片用浏览器语音朗读例词（en-US，离线可用性取决于系统语音包）
- 例词均为常见词并配中文释义；每分组附规律讲解
- 说明：拼读规律存在例外，页面明确提示以词典与教师示范为准

## 数据保存

设置与进度保存在本机浏览器 `localStorage`（前缀 `et_phonics-chart_`），不上传任何数据。

## 合规说明

内置示例内容均为自编通用内容，不含任何教材逐课内容与第三方版权素材。
