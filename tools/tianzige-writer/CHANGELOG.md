# 田字格字帖 更新记录

遵循 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/) 与[语义化版本](https://semver.org/lang/zh-CN/)。

## [Unreleased]

## [1.1.0] - 2026-09-18

### 修复

- **范字过小、不符合字帖标准**：原 `.tz-cell__char { font-size: 76% }` 是相对页面字号计算（实际约 12px），与格子大小无关。改用 **SVG 范字**（viewBox 100 单位）承载字号，随格子等比缩放——屏幕缩放、A4 打印、任意每行字数下都保持正确占格比例

### 新增

- 设置抽屉新增「范字大小（占格比例）」：小 70% / 标准 82% / 大 92%

## [1.0.0] - 2026-09-18

### 新增

- 初始版本：输入汉字自动排版成字帖，支持田字格 / 米字格 / 空白格
- 描红遍数与自写遍数可调（1 遍描红 + 2 遍自写为默认），每行字数 2–8 可调
- 内置约 120 个小学常用字，点一下追加到字帖
- 楷体 / 黑体（系统字体栈，不引用任何在线字体）、描红深浅可调
- 一键打印或另存为 PDF（`@media print` 隐藏工具栏与顶栏，只打印字帖）
