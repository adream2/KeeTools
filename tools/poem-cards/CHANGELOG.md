## [1.1.0] - 2026-09-18

### 新增

- **诗词库 80 首 → 121 首**：
  - 初中课本必背补齐 30 首（木兰诗、登幽州台歌、黄鹤楼、渡荆门送别、龟虽寿、送杜少府之任蜀州、过零丁洋、山坡羊·潼关怀古、无题、月夜忆舍弟、商山早行等）
  - 高中必背新增 11 首（短歌行、归园田居·其一、登高、念奴娇·赤壁怀古、永遇乐·京口北固亭怀古、声声慢、锦瑟、书愤、静女、客至、将进酒）
  - 学段筛新增「高中」，朝代筛新增「先秦 / 汉魏」（覆盖《诗经》等先秦篇目）
- **作者与注释**：新增「作者与注释」按钮（快捷键 I），弹窗展示**作者简介**（数据中 60 余位作者全覆盖）、**创作背景**、**诗中词语注释**、**主旨与赏析**
- 62 个重点篇目已配齐背景 / 注释 / 赏析，卡片底部提示「含背景与注释」；其余篇目给出作者简介

### 变更

- 卡片底部状态条改为「收藏状态 · 句数 · 学段 · 注释可看性」，信息更集中

## [1.0.0] - 2026-09-18

### 新增

- 内置 **80 首**中小学必背古诗词（小学低 / 中 / 高年级 + 初中，含唐诗、宋词、汉乐府、元曲等），按句 / 联分行存放
- 大字号楷体卡片呈现（诗题、朝代·作者、诗文），投屏齐诵场景优化
- 三种显示模式：全显 / 逐句（空格逐句揭晓，带「还有 N 句」提示）/ 隐藏（只留诗题供学生先背）
- 筛选：学段（低 / 中 / 高 / 初中）、朝代（汉魏六朝 / 唐 / 宋 / 元明清）、搜索（诗题 / 作者 / 诗句字词）
- 收藏：★ 收藏当前诗词，一键只看收藏篇目；抽屉内可清空收藏
- 朗读：`speechSynthesis` 能力检测 + 静默降级，三档语速，整首连读
- 大字模式（后排更清楚）、随机一首、上一首 / 下一首
- 快捷键：空格 = 揭晓 / 下一句 / 下一首，←→ = 上下首，R = 随机，F = 收藏，H = 隐藏切换，翻页笔上下页键同效
- 筛选条件、模式、收藏、进度 localStorage 持久化（下次打开回到上次那首）
