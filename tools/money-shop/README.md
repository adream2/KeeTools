# 认识人民币 · 模拟购物

认识元角分、模拟购物付钱与找零。纯前端、离线可用，双击 `index.html` 即用。

## 两个板块

### 认一认

- **纸币**：1 / 5 / 10 / 20 / 50 / 100 元；**硬币**：1 / 2 / 5 分、1 / 5 角、1 元
- **换算关系**：1 元 = 10 角，1 角 = 10 分，1 元 = 100 分（配例子）
- **换算小练习**：四类题型随机出题（几元 = 几角 / 几角 = 几分 / 几元 = 几分 / 几元几角 = 几角），
  输入答案点「检查」即时判对错，并给出解释；统计对题数

### 买一买

1. 点一件商品（铅笔 8 角、橡皮 1 元 2 角、尺子 1 元 5 角、练习本 2 元、文具盒 6 元 5 角、课外书 18 元）
2. 点下面的钱币付钱（已付的钱会排在「已付」区）
3. 够了点 **结账**：正好付清、或算出**找零**；不够会提示还差多少
4. 点错可「拿回一张」，整个重来点「重新付」

## 图样说明（重要）

本工具的钱币图形是**教学用简化示意**：只有数字、单位与颜色，**不是真实人民币图样**。
按《人民币图样使用管理办法》等规定，真实人民币图样不可随意复制使用 —— 工具页面上也标注了这一点，请勿模仿绘制。

## 数据保存

玩法与答题记录保存在本机浏览器 `localStorage`（前缀 `et_money-shop_`）。

## 关于统计模块

本工具包含一个**模块化**使用统计块（源码中标注 `et-stats`）：仅在联网条件下向站点上报一次匿名使用量（`use_offline`），不采集任何内容数据；未配置站点地址时完全静默。
**删除该 `<script>` 块即可让工具完全不联网**，其余功能不受任何影响。

## 快捷键

| 键 | 功能 |
|---|---|
| `1` / `2` | 认一认 / 买一买 |
| `空格` | 换一题（认一认） |
| `Backspace` | 拿回一张（买一买） |
| `回车` | 检查答案 |
| `P` | 打印 |
| 翻页笔下页键 | 换一题 |
| 翻页笔上页键 | 拿回一张 |
