## [1.0.0] - 2026-09-21

### 新增

- **轴对称**：方格纸上给定一半图形（蓝色）与对称轴（竖直 / 水平），点格子补出另一半；
  「检查」逐格判对错（对 = 绿 / 错 = 红）并报告差几格、多几格；「显示镜像」直接看答案；
  点已知一半的格子可以自己改图形
- **平移**：设定格数后按「向左 / 向右 / 向上 / 向下」，虚线画出原位置、箭头标出移动方向，
  页脚给出「向右平移 3 格」式表述
- **旋转**：绕图形外接矩形中心顺时针 90° / 180° / 逆时针 90°，虚线为旋转前位置
- 方格纸尺寸 10×8 / 12×9 / 16×10 可选（格数均为偶数，对称轴总落在格线上）
- 一键「换个图形」随机生成连通小图形；「复位」还原所有移动
- A4 打印当前方格纸（含姓名 / 班级栏与结论行），屏上预览即打印稿
- 快捷键：`1`/`2`/`3` 切换三种运动、方向键平移、空格主操作、`P` 打印
