# 轴对称与图形运动

方格纸上的图形运动演示与操作：轴对称补全、平移、旋转，投影讲解与打印练习两用。纯前端、离线可用，双击 `index.html` 即用。

## 三种运动

### 1. 轴对称（操作类）

- 蓝色是**已知的一半**，青色虚线是**对称轴**（可选竖直 / 水平）
- 点另一半的格子补全图形；点蓝色一侧的格子可以修改已知图形
- **检查**：逐格判对错（对 = 绿、错 = 红），并提示「还差几格、多出几格」
- **显示镜像**：直接画出正确的另一半（讲评用）

### 2. 平移（演示类）

- 设定格数（1–6），点「向左 / 向右 / 向上 / 向下」
- 虚线 = 原来的位置，橙色箭头 = 移动方向
- 页脚自动给出「向右平移 3 格」式表述，与教材语言一致

### 3. 旋转（演示类）

- 绕图形外接矩形中心：顺时针 90° / 180° / 逆时针 90°
- 虚线 = 旋转前的位置，便于对比「转了几格」

## 打印

屏上预览即打印稿（含姓名 / 班级栏与结论行），A4 纵向、缩放 100%、边距「无 / 默认」最准。
常见用法：先随机出图形 → 让学生口述补全 / 平移方案 → 打印给学生在纸上画。

## 数据保存

方格纸尺寸、当前图形、补全答案、平移与旋转状态保存在本机浏览器 `localStorage`（前缀 `et_motion-lab_`）。

## 关于统计模块

本工具包含一个**模块化**使用统计块（源码中标注 `et-stats`）：仅在联网条件下向站点上报一次匿名使用量（`use_offline`），不采集任何内容数据；未配置站点地址时完全静默。
**删除该 `<script>` 块即可让工具完全不联网**，其余功能不受任何影响。

## 快捷键

| 键 | 功能 |
|---|---|
| `1` / `2` / `3` | 轴对称 / 平移 / 旋转 |
| `方向键` | 平移（平移模式） |
| `空格` | 主操作（轴对称 = 检查，其余 = 换个图形） |
| `P` | 打印 |
| 翻页笔下页键 | 主操作 |
| 翻页笔上页键 | 显示镜像 / 复位 |
