# 变更记录 — pinyin-chart

## [1.4.0] - 2026-09-18

### 变更
- **音频全面切换为真人录音**（替换 TTS 合成音）：采用开源项目 audio-cmn
  （github.com/hugolpz/audio-cmn）的音节真人录音，Chen Wang 录制，CC BY-SA 许可
- **升级为声调表**：韵母与整体认读音节每项提供 ā á ǎ à 四声按钮，点哪个读哪个；
  声母读一声呼读（即本音）；卡片与列表双视图均支持
- 内嵌 183 个真人 mp3（18k-abr 优化档，约 500KB），运行时完全离线
- 新增构建脚本 `scripts/pinyin_fetch_audio.py`（抓取 audio-cmn 并内嵌，支持代理）
- 数据结构调整：`PINYIN_AUDIO[label] = { "1".."4": dataUri }`；TTS 相关代码全部移除

## [1.3.1] - 2026-09-18

### 修复
- **读音带调问题**：此前部分条目直接读例字字音（五wǔ / 夜yè / 月yuè / 云yún / 字zì / 刺cì / 爱ài…），
  混入二三四声。现按《汉语拼音方案》读**本音**：数据新增 `tts` 字段指定第一声同音字
  （哀/屋/迂/耶/约/冤/晕/姿/疵），全部音频重新生成

### 说明（呼读音惯例）
- 声母 d/t/n/l/f 的呼读音「得 dé / 特 tè / 讷 nè / 勒 lè / 佛 fó」、韵母 e「鹅 é」、
  er「耳 ěr」、ang「昂 áng」、整体认读 ri「日 rì」为《汉语拼音方案》规定的标准呼读
  （本音无声调可读），全国教材通例，保留

## [1.3.0] - 2026-09-18

### 修复
- **读音不准的根治**：弃用浏览器 TTS 朗读拼音，改为**内嵌标准读音音频**
  （`scripts/pinyin_gen_audio.py` 构建期用 Windows 中文标准语音合成 58 个音节，
  8kHz WAV 裁剪归一后 base64 内嵌，约 460KB，运行时零依赖完全离线）；
  缺失音节自动回落系统 TTS
- 全局极光呼吸背景；「全屏体验」= 工具全屏（宿主直接全屏 iframe 本体，与工具内全屏按钮等效同屏，无嵌套）

## [1.2.0] - 2026-09-18

### 新增
- **激光笔 / 翻页笔适配**：下页键（PageDown）连读下一节、上页键（PageUp）连读上一节，领读全程不碰鼠标

## [1.1.0] - 2026-09-18

### 修复
- **朗读发音错误**：此前直接朗读拼音字符串会被英语语音读错。改为优先朗读例字汉字
  （中文 TTS 对汉字发音最准），并优选本地中文语音包（zh-CN localService），
  教学语速放缓至 0.65；未检测到中文语音包时明确提示

### 新增
- PWA 可安装 + 模块化使用统计（删除 et-stats 块即完全不联网）
- 提示音音量提高；iframe 内全屏委托宿主统一处理

## [1.0.0] - 2026-09-18

### 新增
- 初始版本
- 内置数据：声母 23 / 单韵母 6 / 复韵母 8 / 鼻韵母 9 / 整体认读音节 16，每项配例字
- 通用渲染器（fixed 型模式验证）：卡片 / 列表双视图切换
- 点击卡片朗读（SpeechSynthesis，zh-CN，不可用时静默降级）
- 分节连读 / 实时检索 / 深浅色主题 / 全屏
- 数据内联于页面中的 JSON 结构（`window.PINYIN_DATA`），可整体替换
