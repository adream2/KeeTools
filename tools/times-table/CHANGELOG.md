## [1.0.0] - 2026-09-18

### 新增

- 9×9 乘法口诀方阵（81 格，程序化生成，非硬编码数据）
- 点格子切换「揭晓 / 遮住」，下方宣读条大字显示口诀（如「三四十二」）
- 口诀朗读：`speechSynthesis` 能力检测 + 静默降级，三档语速；读法遵循「小数在前、积小于 10 加『得』」的传统规则
- 三种课堂用法：全部揭晓 / 全部遮住 / 随机抽考（6、12、18、全部），抽考进度实时显示
- 「抽一个」随机点题，高亮格子供学生回答
- 点表头行号 / 列号高亮整行整列，讲「7 的乘法」这类专题
- 范围切换 1–9 / 1–5 / 6–9，范围外格子自动变暗
- 状态（范围 / 遮罩 / 题量 / 朗读 / 语速）localStorage 持久化，下次打开自动恢复
- 空格键、翻页笔（下页 = 揭晓遮住，上页 = 抽一个）
