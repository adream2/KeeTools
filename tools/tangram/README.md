# 七巧板拼图

可拖动、可旋转、能判对错、能看答案的电子七巧板。纯前端、离线可用，双击 `index.html` 即用。

## 怎么玩

| 操作 | 方式 |
|---|---|
| 移动 | 鼠标 / 手指**拖动**色块（选中块会加粗描边并置顶） |
| 旋转 | 鼠标**滚轮**，或右上角「顺时针 / 逆时针」按钮，或 `←` / `→` |
| 翻转 | 选中平行四边形后点「翻转」（或按 `F`）——平行四边形只有翻面才能拼出某些图形 |
| 吸附 | 松手自动吸附到 0.5 格 / 15°（可在 ⚙ 设置里关掉） |

## 三种玩法

| 玩法 | 内容 |
|---|---|
| **自由创作** | 想拼什么拼什么 |
| **拼正方形** | 7 块全部用上，拼成 4 × 4 正方形 |
| **拼大三角形** | 7 块全部用上，拼成一个大三角形 |

挑战模式下会显示灰色虚线轮廓与参考网格，**打印** 可把当前拼法印成 A4。

## 怎么算拼对了

点 **检查**：工具在轮廓范围内密集采样，计算

- **填充率** = 轮廓内被色块盖住的采样点 ÷ 轮廓内采样点
- **溢出率** = 色块盖住但跑到轮廓外的采样点 ÷ 色块覆盖采样点

填充率 ≥ 97% 且溢出率 ≤ 3% 判为拼对（块与块之间允许微小的视觉缝隙）。

点 **显示答案** 会动画把 7 块摆成该挑战的标准拼法之一（拼法不唯一，答案只给一种）。

## 数据保存

每块的位置 / 角度 / 翻转、当前玩法与设置保存在本机浏览器 `localStorage`（前缀 `et_tangram_`）。

## 关于统计模块

本工具包含一个**模块化**使用统计块（源码中标注 `et-stats`）：仅在联网条件下向站点上报一次匿名使用量（`use_offline`），不采集任何内容数据；未配置站点地址时完全静默。
**删除该 `<script>` 块即可让工具完全不联网**，其余功能不受任何影响。

## 快捷键

| 键 | 功能 |
|---|---|
| `1` / `2` / `3` | 自由创作 / 拼正方形 / 拼大三角形 |
| `A` | 显示答案 |
| `R` | 撒开重来 |
| `F` | 翻转选中块 |
| `←` / `→` | 逆时针 / 顺时针旋转 |
| `P` | 打印 |
| 翻页笔下页键 | 显示答案 |
| 翻页笔上页键 | 撒开重来 |
