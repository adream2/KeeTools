## [1.1.2] - 2026-09-21

### 修复

- **拼图不居中**：1.1.1 的动态视口按「内容包围盒中点」取景，但正方形轮廓（y 0–4）与散点圈
  （挂在 y=0 附近）不对称，包围盒中点算出 (2, 0.1)，轮廓整体偏上。改为以**轮廓中心为锚点**
  对称取半径（散点圈也随之挂在轮廓中心周围），轮廓在大屏上水平垂直都居中

## [1.1.1] - 2026-09-21

### 修复

- **大屏适配**：世界坐标视口从写死的 18×13 改为按「挑战轮廓 ∪ 撒开散点」所需范围 + 舞台实际纵横比动态计算（`fitView()`），窗口 resize 时重算——此前 16:9 大屏按高度 letterbox，拼图只占中间一小块
- 撒开散点圈收紧约 20%，进一步压缩所需世界范围；1080p 下拼图区约放大 30% 且横向铺满
- 自由拼摆模式视口以散点范围为准（固定视野，避免拖块后视野漂移）

## [1.1.0] - 2026-09-21

### 变更（交互重制，参考课堂实操反馈）

- **A4 纸面改为全屏舞台**：拼图区占满可视区域，不再在缩小版 A4 纸上拼摆；打印改为按需生成（点击「打印」时以当前拼面动态生成 A4 作业纸，含标题 / 玩法 / 姓名班级栏）
- **旋转改为 45° 步进**（原默认 15°）：所有可拼合角度都是 45° 的倍数，15° 档位只会让块永远转不回能拼合的角度；设置中仍可切 15° / 5° 精调
- **连续自动判定替代手动「检查」**：7 块全部进入剪影（边界容差）+ 两两不重叠（分离轴 SAT）即自动弹出胜利横幅并计时；顶栏 / 控制条实时显示「已放好 N / 7 块」
- **「看答案」改为演示模式**：呈现标准拼法后不再参与判定，再点「撒开」打散开始挑战（原为动画摆放后仍按普通状态判定）
- 快捷键对齐：`Q` / `E` 旋转、`W` 翻面、方向键改为**微调位置**（原为旋转）、`R` 撒开、`A` 看答案、`P` 打印、`1` / `2` / `3` 切换玩法
- 撒开：散点改为围绕挑战轮廓一圈分布，旋转 45° 随机、平行四边形随机翻面（原仅 90° 倍数且不翻面）
- 吸附改 0.25 格（原 0.5 格），与判定容差匹配；「自由创作」更名「自由拼摆」
- 界面细节：新增深色模式下的轮廓 / 网格配色、色块描边 hover / 选中态过渡

### 移除

- 「检查」按钮（由连续判定取代）
- 「F」翻转快捷键（改为 W，F 不再占用）

## [1.0.0] - 2026-09-20

### 新增

- 标准七巧板 7 块（两块大三角形 / 中三角形 / 两块小三角形 / 正方形 / 平行四边形），比例与真实七巧板一致
- 拖动移动（Pointer Events，鼠标与触屏通用）、滚轮或按钮旋转、平行四边形可翻转；松手自动吸附（位置 0.5 格 / 旋转 15°，可关）
- 两种挑战 + 自由创作：**拼正方形**（4 × 4）、**拼大三角形**，显示灰色虚线轮廓与参考网格
- **显示答案**：内置等距变换求解（枚举镜像 / 起点 / 顶点对应方向后逐顶点验算），动画把 7 块精确摆回标准拼法之一
- **检查**：采样法计算填充率与溢出率（≥97% 且 ≤3% 判为拼对），并给出百分比提示
- 撒开重来、打印当前拼法（A4，屏上预览即打印稿）
- 快捷键：`1`/`2`/`3` 切换玩法、`R` 撒开、`A` 显示答案、`F` 翻转、`←`/`→` 旋转、`P` 打印
- 拼法保存在本机浏览器（`localStorage` 前缀 `et_tangram_`），关掉再打开继续拼
