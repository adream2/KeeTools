# 看拼音写词语生成器

粘贴本课词语表，自动注音并排成田字格练习卷，一键打印。纯前端、离线可用，双击 `index.html` 即用。

## 用法

1. 右上角 **导入词语**：一行一个词语（可直接粘贴 Excel 整列）；不需要写拼音，工具会自动注音。
2. 顶部页签选格子样式（田字格 / 方格）；在 **⚙ 设置** 里调每行几个词、标题与抬头。
3. 想同时印出参考答案，先点 **显示答案**（汉字以浅灰字印在格子里），再点 **打印练习卷**。

> A4 纵向、缩放 100%；浏览器若弹出边距选项，选「无 / 默认」最准。

## 拼音是怎么来的

- 内置 **GB2312 一级汉字 3755 个常用字**的通用读音（压缩后约 26KB，内联在工具里，**运行时不联网**）。
- 数据由 `scripts/gen_hanzi_pinyin.py` 从 [mozillazg/pinyin-data](https://github.com/mozillazg/pinyin-data)（MIT 许可证）生成，
  只取常用字集的第一个读音，已登记在 `src/data/third-party.json`。
- **多音字**：内置的是通用读音，可能不是课文里的那个音。例如「长跑」需要写成 `长跑,cháng pǎo` 覆盖；
  导入时写成「词语,拼音」两列即可（拼音列留空的行仍走自动注音）。
- 内置字表未收录的字（生僻字、异体字）在拼音位置显示红色 `?`，状态栏会提示未收录字数，请手工补拼音。

## 设置（右上角 ⚙）

| 分组 | 可调项 |
|---|---|
| 纸面 | 练习卷标题、姓名 / 班级 / 日期 / 得分栏、格中是否印答案 |
| 格子 / 排版 | 田字格 / 方格、每行 1–4 个词语（格子大小自动适配最长词语） |
| 词语 | 导入、示例词语、导出（含拼音）CSV、清空 |

## 数据保存

词语与设置保存在本机浏览器 `localStorage`（前缀 `et_pinyin-to-words_`）。

## 关于统计模块

本工具包含一个**模块化**使用统计块（源码中标注 `et-stats`）：仅在联网条件下向站点上报一次匿名使用量（`use_offline`），不采集任何内容数据；未配置站点地址时完全静默。
**删除该 `<script>` 块即可让工具完全不联网**，其余功能不受任何影响。

## 快捷键

| 键 | 功能 |
|---|---|
| `A` | 显示 / 隐藏答案 |
| `P` | 打印 |
| `1` / `2` | 田字格 / 方格 |
| 翻页笔下页键 | 打印 |
| 翻页笔上页键 | 显示 / 隐藏答案 |
