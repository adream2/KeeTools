# 变更记录 — wheel-spinner

## [1.3.0] - 2026-09-18

### 变更
- 全局极光呼吸背景；「全屏体验」= 工具全屏（宿主直接全屏 iframe 本体，与工具内全屏按钮等效同屏，无嵌套）

## [1.2.0] - 2026-09-18

### 新增
- **激光笔 / 翻页笔适配**：上下页键（PageDown / PageUp）均可直接旋转转盘

## [1.1.0] - 2026-09-18

### 新增
- 右上角「数据 / 设置」抽屉：导入 / 导出 CSV、快速生成、转盘选项、撤销移除集中收纳
- **按学号快速生成**：起止学号 + `{n}` 模板一键生成点名转盘
- **离线名单**：同目录 `roster.js`（或在线 `roster.txt`）打开即自动加载
- PWA 可安装 + 模块化使用统计（删除 et-stats 块即完全不联网）

### 变更
- 提示音音量整体提高；iframe 内全屏委托宿主统一处理

### 移除
- 打开时的一次性弹窗提示

## [1.0.0] - 2026-09-18

### 新增
- 初始版本
- SVG 大转盘（扇区角度按权重比例分配，或等分）
- 名单导入（复用 `et-import`：粘贴 / CSV / TXT / JSON，GBK 自动识别）
- 转盘缓动旋转动画（rAF 驱动，指针扫过扇区边界发出 tick 音效）
- 中奖结果放大展示 + 彩带特效 + 胜利音效
- 「抽中自动移除」开关（适合轮流抽奖场景）
- 加权开关 / 深浅色主题 / 全屏 / 空格键快捷旋转
- 名单与设置 localStorage 持久化
