## [1.1.0] - 2026-09-20

### 变更

- **场景重画（回答"三态看不出来"）**：改为「烧杯 + 水分子」的可视化实验场景，三态各有一眼可辨的物象——
  - 固态：烧杯中浮着**有棱面的冰晶块**（形状不随杯子变化，一眼可见"形状固定"），分子排成整齐晶格、只原地振动；
  - 液态：水在杯里**有明确水面**、随杯壁变形，分子挨在一起互相滑动；
  - 气态：**没有水面**，分子带运动拖尾飞散并跑出杯口，充满整个空间；
  - 过渡态：0 °C 冰块缩小并**浮在水面上**（冰与水同时存在、晶格分子与自由分子同框）；100 °C 气泡自杯底上涌、水面翻腾 + 蒸汽逸出。
- 新增**温度计**（带 0 °C / 100 °C 刻度线与色柱）与**加热火焰**（温度越高火越旺），滑杆渐变按 0 / 100 °C 对齐并标注刻度。
- 右侧面板重构为：当前状态卡 + **三态物性对比表**（形状 / 体积 / 分子，当前状态高亮，点行可跳到该状态）+ 三态变化清单（正在进行的变化自动高亮）。
- 新增**自动升温演示**按钮（−20 → 130 °C 连续演示）；翻页笔上页键改为降温 5 °C；越过 0 / 100 °C 时弹提示说明熔点 / 沸点。

### 修复

- 固态（冰）下仍有自由水分子四处乱窜：自由分子的分支配逻辑只判断"有没有水"，
  固态时 `waterDepth=0` 反而落进气态分支。改为按"水 / 蒸汽的有无"计算可见度
  `life = max(waterDepth/70, haze)`，固态时为 0 → 全部分子已"结"进晶格而不绘制；
  熔化时随水面上升淡入，凝固时淡出。

- 绘制前按 `<html data-et-theme>` 取色，深色模式下场景不再沿用浅色配色（Canvas 工具通用坑）。
- `et_water-states_t` 读取值增加合法性校验，脏数据不再导致温度越界。
