## [1.0.0] - 2026-09-21

### 新增

- 名单管理：直接粘贴（每行一名，自动去重）/ ET.Import 文件导入 / 一键导出 TXT（与导入格式互逆，可编辑后导回）
- 岗位管理：预置 5 个常见值日岗位，可增删（2–10 个，每个最长 8 字）
- 自动轮换排班：按名单顺序每 P 人一组（P = 岗位数），组内按岗位对号入座，最后一轮人数不足自动留空
- 轮换周期（每日 / 每周）+ 起始日期，每轮自动标注对应日期与星期
- 「上一轮 / 下一轮」切换当前轮（高亮 + 自动滚动定位），支持方向键与翻页笔
- 「打乱顺序」重排名单重新分组
- 打印 A4 轮换表（含周期说明 / 班级栏，当前轮加底色）
- 全部数据保存在本机浏览器（`localStorage` 前缀 `et_duty-roster_`）
