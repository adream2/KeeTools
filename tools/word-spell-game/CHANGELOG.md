# 单词拼写游戏 更新记录

遵循 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/) 与[语义化版本](https://semver.org/lang/zh-CN/)。

## [Unreleased]

## [1.1.0] - 2026-09-21

### 新增

- **导出 CSV**：设置抽屉新增导出，当前词表按「单词,中文」两列导出（UTF-8 BOM），可编辑后导回；导出走共享片段 `et-download`（`ET.download` / `ET.csvCell`）。

## [1.0.0] - 2026-09-21

### 新增

- **一套词表三种玩法**（Wordwall 机制）：**字母重排**（打乱字母点回格子）、**猜词**（按中文提示猜字母，错 6 次算输）、
  **缺字母**（补全单词里缺掉的字母）
- 计分与连对：答对 +10，连对每多一次再 +2（最多 +10）；答错或跳题连对清零；记录本机最高分
- 词表导入（ET.Import 统一组件）：一行一个单词，可写 `apple,苹果` 带中文释义；支持 CSV / JSON / Excel 粘贴
- 内置 20 个通用基础词汇示例（自编，不含任何教材单元词表）；可随时查看当前词表、一键载回示例
- 键盘全支持：字母键直接作答、Backspace 退格、空格 / 回车下一题；翻页笔下页键 = 下一题
- 得分、连对、词表保存在本机浏览器（`localStorage` 前缀 `et_word-spell-game_`）
