# 单词拼写游戏

一套词表、三种玩法（字母重排 / 猜词 / 缺字母），投屏抢答与小组赛都用得上。纯前端、离线可用，双击 `index.html` 即用。

## 三种玩法

| 玩法 | 规则 | 适合 |
|---|---|---|
| **字母重排** | 给出中文释义与打乱的字母，按顺序点回格子 | 低年级入门 |
| **猜词（Hangman）** | 给出中文释义与空格，猜字母，最多错 6 次 | 词汇复习 |
| **缺字母** | 单词挖掉约 1/3 的字母，按顺序补全 | 记忆拼写 |

计分：答对 +10，连对每多一次再 +2（最多 +10）；答错或点「换一个」连对清零。
**投屏玩法**：请学生上台点字母；分队比赛时把得分记到「计分板」工具上。

## 导入词表

点 **导入词表** 粘贴单元词汇，一行一个，可写 `apple,苹果` 带中文（有中文时用中文作提示，没有就用单词本身）。
支持逗号 / Tab 分隔、带表头 CSV 与 JSON 数组。

> 内置示例为 **20 个通用基础词汇**（自编），不含任何教材单元词表 —— 单元词表请由老师自行导入。

## 数据保存

词表、玩法、得分与最高分保存在本机浏览器 `localStorage`（前缀 `et_word-spell-game_`）。

## 关于统计模块

本工具包含一个**模块化**使用统计块（源码中标注 `et-stats`）：仅在联网条件下向站点上报一次匿名使用量（`use_offline`），不采集任何内容数据；未配置站点地址时完全静默。
**删除该 `<script>` 块即可让工具完全不联网**，其余功能不受任何影响。

## 快捷键

| 键 | 功能 |
|---|---|
| `1` / `2` / `3` | 字母重排 / 猜词 / 缺字母 |
| `A`–`Z` | 直接作答 |
| `Backspace` | 退一格 |
| `空格` / `回车` | 下一题 |
| 翻页笔下页键 | 下一题 |
| 翻页笔上页键 | 换一个 |
