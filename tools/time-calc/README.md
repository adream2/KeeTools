# 年月日与时间计算

年月日（日历 / 大小月 / 闰年）、24 时计时法互换、经过时间计算与练习。纯前端、离线可用，双击 `index.html` 即用。

## 三个板块

### 1. 年月日

- 选年份（2018–2036）与月份，自动排出当月日历（周日起始，周末底色，今天高亮）
- 下方实时给出：本月天数（**大月 31 天 / 小月 30 天 / 平年 2 月 28 天 / 闰年 2 月 29 天**）、
  这一年是平年还是闰年、闰年判断口诀（四年一闰、百年不闰、四百年又闰）

### 2. 24 时计时法

- **普通 → 24 时**：选「上午 / 下午 / 晚上」+ 几时几分，自动换成 24 时计时法，并解释「为什么要加 12」
- **24 时 → 普通**：反向转换，给出「下午 3 时」式表述
- 知识点：0 时 = 半夜 12 点（一天的开始）；12 时 = 中午 12 点

### 3. 经过时间

- **计算器**：输入开始 / 结束时刻 → 经过时间，并在 24 小时时间轴上标出这段区间
- **练一练**：点「出一题」随机出题（同一天内），学生填经过的时与分，点「检查」判对错并给出算法
  （分不够减时，先从「时」里借 1 时当 60 分）

## 打印

打印当前日历 / 转换结果 / 练习题（A4）。屏上预览即打印稿。

## 数据保存

年月、板块与练习记录保存在本机浏览器 `localStorage`（前缀 `et_time-calc_`）。

## 关于统计模块

本工具包含一个**模块化**使用统计块（源码中标注 `et-stats`）：仅在联网条件下向站点上报一次匿名使用量（`use_offline`），不采集任何内容数据；未配置站点地址时完全静默。
**删除该 `<script>` 块即可让工具完全不联网**，其余功能不受任何影响。

## 快捷键

| 键 | 功能 |
|---|---|
| `1` / `2` / `3` | 年月日 / 24 时计时法 / 经过时间 |
| `空格` | 出一题 |
| `回车` | 检查答案 |
| `P` | 打印 |
| 翻页笔下页键 | 出一题 |
| 翻页笔上页键 | 回到本月 |
