# 变更记录 — random-name-classic

## [1.4.0] - 2026-09-18

### 新增
- **多人点名**：「每次点名」选择 1–6 人，一次抽出多人，定格展示全部结果
  （不重复模式下自动去重；加权开启时按权重抽取）；人数选择即时生效并记忆

## [1.3.0] - 2026-09-18

### 新增
- **打开即用**：无离线名单 / 本机数据时自动载入默认学号名单（1–40 号），打开就能点名，设置只用来改参数
- 全局极光呼吸背景（edupick 品质基线）

### 变更
- 舞台玻璃化（透出极光），点名结果改为品牌色渐变大字 + 辉光
- 「全屏体验」= 工具全屏（宿主直接全屏 iframe 本体，与工具内全屏按钮等效同屏，无嵌套）

## [1.2.0] - 2026-09-18

### 新增
- **激光笔 / 翻页笔适配**：上下页键（PageDown / PageUp）均可直接点名，不用走到讲台

## [1.1.0] - 2026-09-18

### 新增
- 右上角「名单 / 设置」抽屉（edupick 交互）：导入 / 编辑、导出 CSV、点名选项、记录管理集中收纳，主界面只留核心操作
- **按学号快速生成**：输入起止学号 + 名称模板（`{n}` 占位，默认 `{n}号`）一键生成名单，不用手打
- **离线名单**：工具同目录放 `roster.js`（或在线打开时 `roster.txt`），打开即自动加载，优先于本机保存数据（PPT 直开场景）
- PWA 可安装（blob manifest + theme-color，环境支持时生效）
- 模块化使用统计：联网条件下上报 `use_offline` 使用量（删除 et-stats 注入块即完全不联网）

### 变更
- 提示音音量整体提高（教室大屏场景）
- iframe 内「全屏」按钮委托宿主页面统一全屏，消除双层全屏

### 移除
- 打开时的一次性弹窗提示（体感第一，页脚引导已足够）

## [1.0.0] - 2026-09-18

### 新增
- 初始版本
- 名单导入（复用 `et-import`：粘贴 / CSV / TXT / JSON，GBK 编码自动识别）
- 随机点名（复用 `random-pick`：加权抽取）
- 不重复点名 / 已点标记 / 清除记录
- 点名历史（含时间，最近 200 条）
- 大屏舞台展示 + 结果定格动画 + 彩带特效
- 深浅色主题 / 全屏 / 音效开关 / 空格键快捷点名
- 名单、设置、已点记录 localStorage 持久化
