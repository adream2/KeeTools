# 随机点名器（经典版）

导入学生名单，随机抽人回答问题。支持**多人点名**（每次 1–6 人）。适合课堂互动与大屏投影。

## 多人点名

「每次点名」选择人数（1–6），点「开始点名」一次抽出多人：
- 开启「不重复点名」时本轮内自动去重
- 多人结果以「、」分隔定格展示，按顺序计入已点名单

## 数据格式

点击「导入名单」，支持三种方式：

1. **粘贴文本**：一行一个姓名，或逗号/Tab 分隔
2. **文件**：`.csv` / `.txt` / `.json`（UTF-8 与 GBK 自动识别，Excel 请另存为 CSV）
3. **JSON 数组**：`["张三", "李四"]` 或 `[{"name":"张三","weight":2}]`

### 列识别规则

| 格式 | 说明 |
|---|---|
| `张三` | 仅姓名 |
| `张三,2` | 姓名 + 权重（权重越大越容易被抽中，默认 1） |
| `1,张三,3` | 学号 + 姓名 + 权重 |

带表头的 CSV 会自动识别「姓名 / 学号 / 权重」列；自动去重、跳过空行，解析结果先预览再导入。

## 快捷键

- `空格` / `回车`：开始点名

## 数据保存

名单、已点记录、设置保存在浏览器 `localStorage`（前缀 `et_random-name-classic_`），换电脑或清除浏览器数据会丢失，请自行导出备份名单。

## 离线名单（推荐）

把名单存成 `roster.js` 放在本工具**同目录**，下次双击打开自动加载、免反复设置（适合从 PPT / 收藏夹直接打开）：

```js
window.ET_ROSTER = "张三
李四,2";
```

也可以写成数组：`window.ET_ROSTER = ["张三", "李四"]` 或 `[{"name":"张三","weight":2}]`。
在线打开时还支持 `roster.txt`（一行一个，UTF-8）。离线名单**优先于**本机保存的数据。

## 关于统计模块

本工具包含一个**模块化**使用统计块（源码中标注 `et-stats`）：仅在联网条件下向站点上报一次匿名使用量（`use_offline`），不采集任何内容数据；未配置站点地址时完全静默。
**删除该 `<script>` 块即可让工具完全不联网**，其余功能不受任何影响。

## 翻页笔 / 激光笔

翻页笔的上下页键（PageDown / PageUp）即本工具的主操作键，无需鼠标即可完成核心操作，适合教室大屏远距离操控。
