# 数位计数器 · 大数读写

可拨动的虚拟计数器：从个位到亿级，拨珠读数、看数拨珠、分级读大数，理解位值原理。

纯前端、离线可用，双击 `index.html` 即用，投屏/白板均适配。

## 功能

- 拨珠计数：每一位 0–9 颗珠子，联动进位/退位
- 数位表覆盖个级 / 万级 / 亿级，同步显示读法与写法
- 读数 / 写数 / 拨珠三向练习，随机出数

## 数据保存

设置与进度保存在本机浏览器 `localStorage`（前缀 `et_place-value-lab_`），不上传任何数据。
