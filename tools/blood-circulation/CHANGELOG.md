## [1.1.0] - 2026-09-20

### 变更

- 舞台从 SVG 重写为 **Canvas 精确绘制**：
  - 血管以三次贝塞尔链定义并重采样为等距点列，血细胞沿闭合环路按**弧长匀速**流动，
    血细胞体积随所在血管管径自适应；
  - 完整单循环闭环：右心室 → 肺动脉（**左右两支**，血细胞逐个交替过左 / 右肺）→
    肺泡毛细血管 → 肺静脉 → 左心房 → 左心室 → 主动脉弓 → 全身毛细血管网 →
    上 / 下腔静脉 → 右心房；
  - 气体交换段血管颜色**沿路径渐变**（肺段：静脉血 → 动脉血；体段：动脉血 → 静脉血）；
  - 心脏解剖位四腔（图左为右心）+ 房间隔 / 室间隔 + 随心动周期开合的房室瓣 +
    心室搏动缩放，心腔内可见房 → 室血流；
  - 新增肺泡纹理、气管 / 支气管、组织细胞毛细血管网、O₂ / CO₂ 交换粒子动画（图例已补充）；
  - 点击命中检测改为几何级（矩形 / 折线距离 / Path2D），悬停手型，选中结构发光高亮；
  - 深浅色主题各自配色；窗口尺寸变化自适应（DPR 感知）。
- 交互与持久化（模式 / 播放 / 速度 / 选中 / 空格与翻页笔快捷键）保持不变。
