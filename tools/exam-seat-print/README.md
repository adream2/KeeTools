# 考试座位表打印

导入考生名单 → 自动分考场排座 → 一键打印三种考务用纸。纯前端、离线可用，双击 `index.html` 即用。

## 用法

1. 右上角 **导入名单**：粘贴考生姓名（一行一个，Excel 可整列复制），或 `姓名,学号`、`学号,姓名`，
   也支持带表头的 CSV（姓名 / 学号列自动识别）。
   也可在 **⚙ 设置 → 名单** 里按起止学号 + `{n}` 模板一键生成。
2. 顶部页签切换打印稿，屏上看到的就是打印出来的，不需要二次排版：

| 打印稿 | 版式 | 用途 |
|---|---|---|
| 考场座位总表 | 一个考场一页：抬头 + 讲台 + `行×列` 座位网格（座位号 / 姓名 / 考号）+ 监考签名栏 | 考场门张贴、监考老师使用 |
| 座位贴条 | 每页 2 / 3 / 4 列 × 8 行（16 / 24 / 32 张），虚线可裁 | 裁剪后贴在课桌左上角 |
| 考场签到表 | 座位号 / 考号 / 姓名 / 考生签名，每页 30 行自动分页 | 考场签到、缺考登记 |

3. 点 **打印**（或按 `P`）：A4 纵向、缩放 100%；浏览器若弹出边距选项，选「无 / 默认」最准。

## 设置（右上角 ⚙）

- **打印抬头**：考试名称、学校 / 考点（打印在每页顶部）
- **考场座位**：每考场行数 / 列数（考场数按 `ceil(人数 ÷ 每考场座位数)` 自动推算）；
  座位号编法可选 **蛇形**（推荐，单数行反向）/ 按行 / 按列
- **考号规则**：默认 **考场号 + 座位号**（第 2 考场 3 号 → `0203`）；
  也可按名单顺序编号（可设起始号与位数，如起始 1、4 位 → `0001`），或直接使用名单中的学号
- **座位贴条**：每页列数
- **名单**：按学号快速生成、导入、导出 CSV、清空

> 考号与姓名绑定：打乱考场顺序后，按名单顺序编号的考号会按新顺序重排；用「考场号 + 座位号」或名单学号则不受影响。

## 数据保存

设置与名单保存在本机浏览器 `localStorage`（前缀 `et_exam-seat-print_`），关掉页面再打开继续有效。

## 离线名单（推荐）

把名单存成 `roster.js` 放在本工具**同目录**，下次双击打开自动加载、免反复设置（适合从 PPT / 收藏夹直接打开）：

```js
window.ET_ROSTER = "张三\n李四,2026002";
```

也可以写成数组：`window.ET_ROSTER = ["张三", "李四"]` 或 `[{"name":"张三","id":"2026002"}]`。
在线打开时还支持 `roster.txt`（一行一个，UTF-8）。离线名单**优先于**本机保存的名单。

## 关于统计模块

本工具包含一个**模块化**使用统计块（源码中标注 `et-stats`）：仅在联网条件下向站点上报一次匿名使用量（`use_offline`），不采集任何内容数据；未配置站点地址时完全静默。
**删除该 `<script>` 块即可让工具完全不联网**，其余功能不受任何影响。

## 快捷键

| 键 | 功能 |
|---|---|
| `1` / `2` / `3` | 切换考场总表 / 座位贴条 / 签到表 |
| `P` | 打印 |
| 翻页笔下页键 | 打印 |
| 翻页笔上页键 | 导入名单 |
