## [1.0.0] - 2026-09-20

### 新增

- 导入考生名单（粘贴 / CSV / JSON，`姓名` 与 `姓名,学号` 均自动识列）自动分考场排座
- 三种打印稿，屏上所见即所得（A4 分页，`window.print()` 直接出纸）：
  - **考场座位总表**：一考场一页，讲台 + rows×cols 座位网格（座位号 / 姓名 / 考号）+ 监考签名栏
  - **座位贴条**：每页 2/3/4 列 × 8 行（16 / 24 / 32 张），含考场、座位号、姓名、考号，虚线裁剪后贴课桌
  - **考场签到表**：按座位号排序的签到名单（座位号 / 考号 / 姓名 / 考生签名），超过 30 行自动分页
- 座位号编法：蛇形（默认）/ 按行 / 按列；考号规则：考场号+座位号（默认）/ 按名单顺序编号（可设起始号与位数）/ 使用名单中的学号
- 每考场行数、列数可调，考场数量按名单人数自动推算（`ceil(人数 ÷ 每考场座位数)`）
- 打乱考场顺序、导出 CSV（带 BOM，Excel 直开）、清空名单
- 按学号快速生成名单（起止学号 + `{n}` 姓名模板）；离线名单 `roster.js` / `roster.txt` 优先于本机数据
- 设置抽屉（抬头 / 考场 / 考号 / 贴条 / 名单）、空格不绑定（避免误触打印）、`1` `2` `3` 切换打印稿、`P` 打印
- 翻页笔：下页键 = 打印，上页键 = 导入名单；深浅色主题；全屏；`localStorage` 持久化
