# 长方体正方体展开图

正方体展开图互动教具：判断 6 格图形能否折成正方体、点面观察折叠去向、11 种展开图图鉴（含教材四类分族）。

纯前端、离线可用，双击 `index.html` 即用，投屏/白板均适配。

## 功能

- **判断能不能折**：内置 11 种合法展开图 + 19 个典型错误图形，答后给出相对面分析
- **动手拼一拼**：点展开图上的面，立体示意图高亮它折到哪一面，直观理解相对面
- **11 种图鉴**：按一四一 / 二三一 / 二二二 / 三三 教材口径分族筛选
- 折叠判定用「滚立方体」算法实时校验，不依赖硬编码答案

## 数据保存

设置与进度保存在本机浏览器 `localStorage`（前缀 `et_cuboid-net_`），不上传任何数据。

## 合规说明

内置示例内容均为自编通用内容，不含任何教材逐课内容与第三方版权素材。
