# 数对定位 · 方格寻宝

用「列、行」数对确定位置的互动方格教具：认识数对、藏宝寻宝、按数对找格三种玩法，可打印空白方格纸。

纯前端、离线可用，双击 `index.html` 即用，投屏/白板均适配。

## 功能

- **认识数对**：点任意格，实时给出（列，行）；可切换行号方向（从下往上 / 从上往下）
- **寻宝游戏**：盘上藏 3 个宝箱，没挖到会提示「离最近的宝藏还有几格」
- **按数对找格**：输入数对反查位置，全班抢答
- 方格规模 5×5 / 6×6 / 8×8 / 10×10；支持打印空白方格纸

## 数据保存

设置与进度保存在本机浏览器 `localStorage`（前缀 `et_grid-coordinates_`），不上传任何数据。
