# 古诗默写 · 飞花令

三种课堂玩法共用一套内置诗词数据：**填空默写**（可打印默写卷）、**飞花令**（含字检索）、**接句抢答**（带倒计时）。
纯前端、离线可用，双击 `index.html` 即用。

## 三种模式

### 1. 填空默写（可打印）

- **挖字填空**：随机空掉一部分字（比例 10%–90% 可调，默认 40%），练「把字写对」
- **每句后半挖空**：每句只给前半句，练补下句，接近正式默写题型
- **整句挖空**：空出偶数句（下句），练整句默写
- 点 **重新挖空** 换一组空；**显示答案** 用红字填回；**打印** 出 A4 默写卷（带姓名 / 班级 / 得分栏）

> 低年级建议 30%（扶一扶），高年级 50% 以上，或直接用整句挖空。

### 2. 飞花令

输入一个字（或点顶部的常用字快捷键），列出内置篇目中**所有含这个字的诗句**，标出出处。
适合「含月字的诗句」抢答赛；数据范围可在设置里按学段收窄。

### 3. 接句抢答

屏幕给出上句（含出处与句序），学生抢答下句，点 **显示下句** 揭晓；**30 秒抢答** 提供倒计时与时间到提示音。

## 数据来源

内置 121 首教材常见必背古诗词（公版古诗文全文 + 朝代 / 作者 / 学段标注），与同族工具「古诗词卡片」共用同一份数据，
抽取后随工具一起打包，**运行时不联网**。数据量 < 500 条，属 `fixed` 型工具合理范围。

## 数据保存

当前模式、篇目序号、挖空方式与比例保存在本机浏览器 `localStorage`（前缀 `et_poem-quiz_`）。

## 关于统计模块

本工具包含一个**模块化**使用统计块（源码中标注 `et-stats`）：仅在联网条件下向站点上报一次匿名使用量（`use_offline`），不采集任何内容数据；未配置站点地址时完全静默。
**删除该 `<script>` 块即可让工具完全不联网**，其余功能不受任何影响。

## 快捷键

| 键 | 功能 |
|---|---|
| `1` / `2` / `3` | 填空默写 / 飞花令 / 接句抢答 |
| `空格` | 主操作（下一篇 / 揭晓下句） |
| `←` / `→` | 上一篇 / 下一篇（默写模式） |
| `A` | 显示答案 / 揭晓下句 |
| `P` | 打印 |
| 翻页笔下页键 | 主操作 |
| 翻页笔上页键 | 重新挖空 / 换一句 |
