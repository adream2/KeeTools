## [1.0.0] - 2026-09-20

### 新增

- 内置 **121 首**教材常见必背古诗词（公版全文，含朝代 / 作者 / 学段标注，抽取自同族工具 poem-cards，完全离线）
- **填空默写**：三种挖空方式 —— 挖字填空（比例 10%–90% 可调）、每句后半挖空（练下句）、整句挖空（默整句）；
  空位以横线标出，点「显示答案」对答案，「重新挖空」换一组空
- **飞花令**：输入任意一个字（或点「月 / 花 / 春 / 风 / 山 / 水」等常用字快捷键），
  列出内置篇目中所有含该字的诗句，标出出处与命中字，附总数与涉及篇目数
- **接句抢答**：屏幕给出上句，学生抢答下句，点「显示下句」揭晓；「30 秒抢答」提供倒计时与时间到提示音
- 学段筛选（小学低 / 中 / 高年级、初中、高中），随机一篇 / 上一篇 / 下一篇只在该范围内选
- A4 打印默写卷（含姓名 / 班级 / 得分栏），屏上预览即打印稿
- 快捷键：`1`/`2`/`3` 切换模式、空格主操作、`←`/`→` 换篇、`A` 显示答案、`P` 打印
