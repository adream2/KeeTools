## [1.1.0] - 2026-09-20

### 变更

- 海陆轮廓由手绘简化多边形改为**真实海岸线与国界**：数据管线 `scripts/gen_world_map.py`（新增）下载
  world-atlas countries-110m TopoJSON，解码后按 177 个国家归入七大洲（着色沿用洲色，俄罗斯归欧洲），
  等距圆柱投影 + Douglas-Peucker 简化后注入单文件（约 68KB，离线可用）
- 新增 **3D 地球仪模式**（Canvas 正射投影）：拖拽旋转、滚轮缩放、自动自转（可关），
  地平圆求交裁剪避免弦切缺口，经纬网 / 首都标记 / 大洲名称同步显示，
  点击按反解经纬度做点在内判定命中大洲
- 南极洲多边形闭合到 -90°（南极点封顶，平面与球面均完整）
- 交互与持久化不变：大洲 / 国家选中逻辑、经纬网 / 首都标记 / 大洲名称开关均对两种视图生效
