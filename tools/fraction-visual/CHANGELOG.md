# 分数可视化 更新记录

遵循 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/) 与[语义化版本](https://semver.org/lang/zh-CN/)。

## [Unreleased]

## [1.1.0] - 2026-09-18

### 新增

- **色条拖动的视觉反馈**：新增拖动把手（实时显示当前分数 n/d），拖动时色条高亮 + 外发光，未涂色格悬停时提示「可拖到该格」
- 分数 B 的把手与悬停提示改用蓝色系，与 A 区分

### 变更

- 色条与把手的移动带缓动动画，拖动过程中取消动画以跟手

## [1.0.0] - 2026-09-18

### 新增

- 双视图呈现同一分数：SVG 饼图（平均分成 n 份）+ 等分色条
- 分子 / 分母 − + 步进（循环取值），分母上限 12 / 20 可切换
- **色条拖动改分子**：鼠标与触屏均支持（PointerEvent，老内核回退 mouse/touch 事件）
- 底部信息带：分数、自动约分（说明同除以几）、小数、百分数
- **对比模式**：分数 B 独立编辑（橙色 A / 蓝色 B），数轴圆点直观比位置，并给出通分过程（如 9/12 > 8/12）与大小判定
- 常用分数快捷 chips（1/2、2/3、3/4…3/10）一键切换
- 快捷键：空格 / → = 分子 +1，← = 分子 −1，↑↓ = 分母 ±1，C = 切换对比模式
- 全部状态 localStorage 持久化（分数、分母上限、对比模式、数值显示）
