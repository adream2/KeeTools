# 情景对话卡 · 任务转盘

英语情景对话教具：随机抽卡分角色朗读，台词可遮住背诵；读完转任务转盘领任务（改编/表演/背诵/提问）反复操练。

纯前端、离线可用，双击 `index.html` 即用，投屏/白板均适配。

## 功能

- 内置 3 段示例对话（动物园 / 餐厅 / 问路，自编），支持导入自己的对话
- **对话卡**：两列气泡按角色分布，点台词遮住/展开，可朗读全文（双音色区分角色）
- **任务转盘**：6 个课堂任务扇形转盘，惯性旋转随机停
- 导入格式：空行分段，段内「场景 / 角色 / 台词行」

## 数据保存

设置与进度保存在本机浏览器 `localStorage`（前缀 `et_dialogue-cards_`），不上传任何数据。

## 合规说明

内置示例内容均为自编通用内容，不含任何教材逐课内容与第三方版权素材。
