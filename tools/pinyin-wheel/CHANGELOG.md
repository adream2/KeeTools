## [1.0.2] - 2026-09-21

### 修复

- **朗读发音不正确**：原先把带调拼音串（如「kǒ」）直接交给 `zh-CN` 语音引擎，
  引擎遇到拉丁字母发音不可靠。改为**同音字方案**：新增数据管线
  `scripts/gen_pinyin_read_chars.py`（含 `--check` 门禁），从 pinyin-to-words 内嵌的
  GB2312 一级常用字拼音表反查「带调拼音 → 常用字」，枚举本工具 声母 × 韵母 × 5 声调
  组合生成 `PW_READ` 映射表（覆盖 1203 个音节），朗读时念同音汉字，中文引擎读汉字发音正确
- j/q/x/y + ü 类组合按规范拼写归一化（xüé → xué →「学」）
- 轻声组合回退读带调同音字；非规范音节（如 k + o）点「朗读」明确提示「不是规范音节」，
  随机拼到时自动跳过不弹提示

## [1.0.1] - 2026-09-21

### 修复

- **「随机拼一个」轮盘甩出画面**：旋转加在 SVG `<g>` 上，而 SVG 元素 CSS transform 的默认原点
  是画布 (0,0)（HTML 元素才是中心），一转整盘绕左上角甩出。给 `.pw-rot` 显式指定
  `transform-origin: 110px 110px`（轮盘圆心）修复
- 经验：SVG 内 CSS 旋转必须显式 `transform-origin`（HTML div 默认中心、SVG g 默认左上角）

## [1.0.0] - 2026-09-21

### 新增

- 声母 × 韵母双转盘（汉语拼音方案：23 声母含「—」无声母位 + 24 韵母），点格子直接选中或「随机拼一个」双轮同转（CSS cubic-bezier 惯性旋转）
- 中央大字显示当前音节与组成（如「声母 l + 韵母 i」）
- 声调按钮（轻 / 一至四声），按「a o e 优先、i u 并列标后」规则自动标调（li+3 声 → lǐ）
- TTS 朗读（zh-CN、rate 0.6），不支持语音的设备自动禁用按钮（优雅降级）；随机拼出后自动朗读
- 快捷键：空格 / 翻页笔下页键 = 随机、`S` = 朗读、`←` / `→` = 单转声母 / 韵母、`0`–`4` = 切声调
- 当前选择与声调保存在本机浏览器（`localStorage` 前缀 `et_pinyin-wheel_`）
