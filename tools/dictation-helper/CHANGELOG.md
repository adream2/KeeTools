## [1.0.0] - 2026-09-18

### 新增

- 初始版本：词表（一行一个）按顺序自动报词，支持手输、按学号生成、粘贴 / CSV 导入
- 朗读使用浏览器内置语音（能力检测；不支持时自动降级为「只显示词语」模式，不白屏）
- 可隐藏文字、设置每词朗读遍数、词间间隔秒数、语速；报词前有提示音
- 大字号显示当前词语与进度（第 x / N），支持上一词 / 重复 / 下一词 / 暂停继续
- 翻页笔：下页键下一词，上页键重复当前词；空格键开始 / 暂停
