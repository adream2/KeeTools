## [1.0.0] - 2026-09-21

### 新增

- 网格画布自由作画，镜像图形实时同步：左右对称（竖轴）/ 上下对称（横轴）/ 四象限（双轴，一次画 4 份）
- 8 色画笔 × 3 档粗细；橡皮（点击擦除整条笔迹，命中任一镜像副本即删）、撤销（Ctrl+Z）、清空（二次确认）
- 虚线对称轴 + 可开关方格网；作品自动保存在本机浏览器
- 打印 A4 作品纸（含对称方式 / 姓名栏 / 日期栏）
- 快捷键：`1` / `2` / `3` 切换对称方式、`E` 橡皮、`P` 打印、`Ctrl+Z` 撤销
