# 因数与倍数 · 质数筛

1–100 百数表上的因数倍数练习与埃拉托斯特尼质数筛：找因数、圈倍数、筛质数三种玩法。

纯前端、离线可用，双击 `index.html` 即用，投屏/白板均适配。

## 功能

- **找因数**：在百数表点出目标数的全部因数，完成即统计失误
- **圈倍数**：点出 100 以内的所有倍数
- **质数筛**：点 2、3、5、7… 划掉倍数，剩下的就是质数（支持自动筛演示）
- 目标数可任意选择（2–100），实时显示进度与已找到的数

## 数据保存

设置与进度保存在本机浏览器 `localStorage`（前缀 `et_factor-sieve_`），不上传任何数据。
