## [1.0.0] - 2026-09-21

### 新增

- 四种图形的**剪拼 / 割补推导动画**（滑块逐帧或自动播放）：
  - **平行四边形**：沿高剪下直角三角形 → 平移到另一边 → 长方形 → 面积 = 底 × 高
  - **三角形**：两个完全一样的三角形，一个绕边中点旋转 180° → 平行四边形 → 面积 = 底 × 高 ÷ 2
  - **梯形**：两个完全一样的梯形旋转 180° 拼合 → 平行四边形（底 = 上底 + 下底）
  - **圆**：平均分成 4 / 8 / 16 / 32 份交错拼开 → 近似长方形（长 ≈ πr，宽 = r）→ 面积 = πr²
- 底 / 高 / 半径可调（4–12 / 3–8 / 2–5），公式面板**实时代入计算**
- 每种图形配「推导步骤」分步说明，适合边演示边板书
- 旋转过程中视图框自动跟随，图形不会被裁掉；圆的份数越多越接近长方形（渗透极限思想）
- A4 打印当前推导图与公式；快捷键：`1`–`4` 切换图形、空格播放 / 暂停、`←`/`→` 单步、`P` 打印
