# 面积公式推导

把教材里「转化」的推导过程**演出来**：平行四边形、三角形、梯形、圆的面积公式剪拼动画。纯前端、离线可用，双击 `index.html` 即用。

## 四种推导

| 图形 | 转化过程 | 得到 |
|---|---|---|
| **平行四边形** | 沿高剪下直角三角形，**平移**到另一边 | 长方形（长 = 底，宽 = 高）→ 面积 = 底 × 高 |
| **三角形** | 两个完全一样的三角形，一个**旋转 180°** | 平行四边形 → 面积 = 底 × 高 ÷ 2 |
| **梯形** | 两个完全一样的梯形旋转 180° 拼合 | 平行四边形（底 = 上底 + 下底）→ 面积 = (上底 + 下底) × 高 ÷ 2 |
| **圆** | 平均分成 4 / 8 / 16 / 32 份**交错拼开** | 近似长方形（长 ≈ πr，宽 = r）→ 面积 = πr² |

## 怎么用

- **拖动滑块**逐帧演示，或点 **播放** 自动演完（约 2 秒）
- 下方公式面板**实时代入计算**（底 / 高 / 半径可在 ⚙ 设置里改）
- 每种图形配有分步「推导步骤」，适合学生复述转化过程
- **课堂建议**：先让学生猜「剪拼之后会变成什么图形」→ 拖滑块验证 → 请学生说结论 → 看公式
- 圆的份数调到 32 份，拼出的图形非常接近长方形，正好渗透「极限」思想

## 打印

打印当前图形与公式（A4），可作为板书补充或讲义。屏上预览即打印稿。

## 数据保存

图形类型、尺寸数据与演示进度保存在本机浏览器 `localStorage`（前缀 `et_area-explorer_`）。

## 关于统计模块

本工具包含一个**模块化**使用统计块（源码中标注 `et-stats`）：仅在联网条件下向站点上报一次匿名使用量（`use_offline`），不采集任何内容数据；未配置站点地址时完全静默。
**删除该 `<script>` 块即可让工具完全不联网**，其余功能不受任何影响。

## 快捷键

| 键 | 功能 |
|---|---|
| `1`–`4` | 平行四边形 / 三角形 / 梯形 / 圆 |
| `空格` | 播放 / 暂停 |
| `←` / `→` | 单步后退 / 前进 |
| `P` | 打印 |
| 翻页笔下页键 | 播放 / 暂停 |
| 翻页笔上页键 | 还原 |
