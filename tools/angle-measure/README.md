# 交互量角器

屏幕上可拖动的量角器：内外圈双刻度，量一量（读角）、拼一拼（摆角）两种玩法，训练规范使用量角器。

纯前端、离线可用，双击 `index.html` 即用，投屏/白板均适配。

## 功能

- **量一量**：拖动量角器对准顶点与边，读数输入答案（±1° 容差）
- **拼一拼**：给出目标角度，拖动/输入让另一条边到位，先估后量
- 内圈外圈双刻度与真实量角器一致，含中心十字与底部握把
- 设置可开启优角（180°–320°）练习

## 数据保存

设置与进度保存在本机浏览器 `localStorage`（前缀 `et_angle-measure_`），不上传任何数据。
