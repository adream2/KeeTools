# 控笔练习生成器

一键生成 A4 控笔练习纸：直线/斜线/折线/波浪/圆弧/圆圈/螺旋七种图案，每行三遍描红（实线描 → 虚线跟 → 独立画），屏上即打印稿。

纯前端、离线可用，双击 `index.html` 即用，投屏/白板均适配。

## 功能

- 七种线条图案（可混合随机），每页 4/6/8 行
- 每行同一图案三组：深色实线、灰色虚线、浅色虚线，由易到难
- 页面含姓名/日期栏；@media print 只输出纸面，打印对话框选无边距即可
- 纯 SVG 绘制，打印矢量化不糊

## 数据保存

设置与进度保存在本机浏览器 `localStorage`（前缀 `et_pre-writing-tracing_`），不上传任何数据。
