# 元素周期表 更新记录

遵循 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/) 与[语义化版本](https://semver.org/lang/zh-CN/)。

## [Unreleased]

## [1.1.0] - 2026-09-18

### 新增

- **点击元素弹出详细介绍弹窗**：
  - 左侧**可旋转 3D 原子模型**（原子核 + 各电子层 + 绕核运动的电子，SVG + CSS 3D，零外部库；按住拖动可旋转与改变倾角）
  - 右侧英文名、相对原子质量、元素类别、周期与族、质子 / 中子 / 电子数、电子层排布、**电子排布式（按构造原理）**
  - **性质与用途**：常见元素逐条撰写，其余按类别给出通用说明，另附该类元素整体解说
- 底部概览新增「3D 模型与详细介绍」入口按钮
- 顶栏新增「点击弹详情」开关：关闭后点元素只更新概览，可按需从按钮打开

### 变更

- 方向键浏览（只更新概览，不弹窗）与随机抽元素（弹出详情）两种行为解耦

## [1.0.0] - 2026-09-18

### 新增

- 内置 **118 种元素**数据：原子序数、符号、中文名、相对原子质量、类别、周期、族、电子层排布
- 标准周期表布局（CSS Grid 18 族 × 7 周期 + 镧系 / 锕系两行），主表内以「57-71」「89-103」标记指示
- 电子层排布按构造原理（Aufbau 顺序）逐层累加计算，并对 Cr、Cu、Nb、Mo、Ru、Rh、Pd、Ag、La、Ce、Gd、Pt、Au 及锕系若干元素按实际排布修正；详情中按 K L M N O P Q 分层展示
- 点击方块看详情：符号、中文名、序数、类别、周期、族、相对原子质量（含量整提示）、电子层排布
- 高亮讲规律：点左列周期号高亮整周期、点顶部族号高亮整族、点镧系 / 锕系标记高亮对应区块
- 类别筛选（金属 / 非金属 / 准金属 / 稀有气体 / 镧系锕系）+ 搜索（符号、中文名、序数），不匹配方块变暗而非隐藏，保留位置感
- 10 类元素配色 + 可折叠图例，深色模式自动加深底色
- 方块可切换显示中文名 / 原子量（取整），窄屏自动隐藏中文名
- 键盘：←→ 按序数移动，↑↓ 同族上下移动，空格 / R 随机抽一个元素
- 筛选、选中元素、显示偏好 localStorage 持久化
