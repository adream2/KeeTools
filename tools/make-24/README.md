# 二十四点

经典四牌算 24 游戏：内置求解器保证每题有解，点牌列式、括号可嵌，看答案给出一种解法。

纯前端、离线可用，双击 `index.html` 即用，投屏/白板均适配。

## 功能

- 每道题经内置求解器校验，**保证有解**；「看答案」给出一种列法
- 点牌 + 运算符 + 括号组式，实时求值判定（支持分数中间值）
- 难度两档：热身（1–10）/ 挑战（1–13）
- 快捷键 1–9 快速出牌、Enter 提交、Backspace 删除

## 数据保存

设置与进度保存在本机浏览器 `localStorage`（前缀 `et_make-24_`），不上传任何数据。

## 合规说明

内置示例内容均为自编通用内容，不含任何教材逐课内容与第三方版权素材。
