## [1.1.0] - 2026-09-19

### 新增

- **逐笔书写动画**：内置 hanzi-writer-data 的真实笔迹中位线数据（210 字全覆盖），逐笔沿书写轨迹描红写出，笔尖实时游走；已写过的笔画留红，未写的笔画为浅灰，右侧笔画面板同步高亮「序号 + 笔画名称」
- 播放 / 单步 / 重放均触发书写动画，动画速度跟随「演示速度」设置

### 修复

- 修正 3 处笔画数与笔顺错误：飞（2 → 3 画）、北（4 → 5 画）、春（8 → 9 画）

### 变更

- 有笔迹数据时隐藏系统字形，只显示真实书写轨迹，避免字形与轨迹错位
- 帮助弹窗与说明文案注明笔迹数据来源与许可证（hanzi-writer-data / Arphic Public License）
