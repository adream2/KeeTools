## 一、通用

| 项 | 规则 |
|---|---|
| 编码 | UTF-8 **无 BOM** |
| 换行 | **LF** |
| 缩进 | PHP / JS / CSS / Python = **4 空格**；JSON / YAML / Markdown = **2 空格** |
| 行宽 | 建议 ≤ 100 字符 |
| 行尾 | 不留空格 |
| 文件末尾 | 保留**一个**空行 |
| 制表符 | ❌ 不使用 |

以上由 `.editorconfig` 统一约束。

## 三、PHP

### 3.1 文件头

```php
<?php
declare(strict_types=1);

namespace App\Services;

use App\Core\Database;
use App\Core\Security;
```

**要求**：

- 所有 PHP 文件必须 `declare(strict_types=1);`
- 文件**不写** `?>` 结束标签（避免意外输出空白）
- 缩进 4 空格

### 3.2 类型声明

```php
// 参数与返回值都声明类型
public function findById(string $toolId): ?array
{
    // …
}

// 联合类型（PHP 8）
public function format(?int $size): string|int

// 数组用 PHPDoc 说明结构
/**
 * @return array<int, array{id: int, tool_id: string, title: string}>
 */
public function listAll(): array
```

### 3.3 数据库访问

```php
// 正确：参数化
$stmt = $pdo->prepare('SELECT * FROM tools WHERE tool_id = :id');
$stmt->execute([':id' => $toolId]);

// 错误：拼接
$pdo->query("SELECT * FROM tools WHERE tool_id = '$toolId'");
```

表名列名动态时走白名单（见 [`安全规范.md`](安全规范.md) §3.3）。

### 3.4 输出转义

```php
function e(?string $value): string
{
    return htmlspecialchars($value ?? '', ENT_QUOTES | ENT_SUBSTITUTE, 'UTF-8');
}
```

```php
<h1><?= e($tool['title']) ?></h1>
<script>var d = <?= json_encode($tool, JSON_UNESCAPED_UNICODE | JSON_HEX_TAG) ?>;</script>
```

### 3.5 错误处理

```php
// 可预期的失败：抛异常，由统一处理器兜底
if ($manifest === null) {
    throw new RuntimeException("manifest 解析失败: {$path}");
}

// 需要提示用户的失败：返回值 + 上层处理
$ok = $writer->write($toolId, $data);
if (!$ok) { /* 提示用户 */ }
```

**禁止**静默 `return;` 吞掉错误。

### 3.6 类结构顺序

```php
final class ToolScanner
{
    // 1. 常量
    public const MAX_DEPTH = 3;

    // 2. 属性
    private PDO $db;

    // 3. 构造函数
    public function __construct(PDO $db) { $this->db = $db; }

    // 4. 公共方法
    public function scanAll(): array { }

    // 5. 私有方法
    private function readManifest(string $path): ?array { }
}
```

- 无状态服务类优先 `final class`
- 依赖通过构造函数注入

## 四、JavaScript

### 4.1 分场景约束（重要）

| 场景 | 位置 | 可用语法 |
|---|---|---|
| **工具代码** | `tools/**` | ES5 + 少量 ES6（`let` / `const` / 箭头函数 / 模板字符串），**禁用新增 API** |
| **网站代码** | `public/assets/js/`、`src/views/` | ES2018，可稍宽松 |
| **注入脚本** | 统计上报注入片段 | ES5（教室老浏览器） |

### 4.2 工具侧禁用清单

| 禁止 | 替代 |
|---|---|
| `?.` 可选链 | `a && a.b` |
| `??` 空值合并 | `a != null ? a : b` |
| `structuredClone()` | `JSON.parse(JSON.stringify(x))` |
| `Array.prototype.at()` | `arr[arr.length - 1]` |
| `String.prototype.replaceAll()` | `str.split(x).join(y)` 或 `/g` 正则 |
| `Object.hasOwn()` | `Object.prototype.hasOwnProperty.call(obj, k)` |
| `:has()` CSS | 加辅助类或用 JS 判断 |
| 顶层 `await` | 放 async 函数内 |
| 可选 catch 绑定 `catch {}` | `catch (e) {}` |

### 4.3 工具代码结构

```js
(function () {
    'use strict';

    var LS_PREFIX = 'et_tool-id_';

    // ── 状态 ──
    var state = { items: [], picked: [] };

    // ── 工具函数 ──
    function lsGet(key, fallback) {
        try {
            var v = localStorage.getItem(LS_PREFIX + key);
            return v === null ? fallback : JSON.parse(v);
        } catch (e) {
            return fallback;
        }
    }

    function lsSet(key, value) {
        try {
            localStorage.setItem(LS_PREFIX + key, JSON.stringify(value));
        } catch (e) {
            /* 隐私模式 / 配额满，静默失败 */
        }
    }

    // ── 业务逻辑 ──
    function render() { /* … */ }

    // ── 事件绑定 ──
    function bind() { /* … */ }

    // ── 初始化 ──
    function init() {
        bind();
        render();
    }

    if (document.readyState === 'loading') {
        document.addEventListener('DOMContentLoaded', init);
    } else {
        init();
    }
})();
```

**要求**：

- 用 IIFE 包裹，**不污染全局**
- `'use strict';`
- 不引入任何全局变量
- `localStorage` 读写必须包 `try/catch`（隐私模式会抛异常）

### 4.4 网站代码

```js
// 可用 const/let、箭头函数、模板字符串、Promise、fetch
const loadTools = async (category) => {
    const res = await fetch(`/api/tools?category=${encodeURIComponent(category)}`);
    if (!res.ok) throw new Error('加载失败');
    return res.json();
};
```

仍**避免**：不在必要时使用 `<script type="module">`（教室环境可能被拦截）。

## 五、CSS

### 5.1 四层结构（网站）

| 文件 | 职责 | 数值字面量 |
|---|---|---|
| `tokens.css` | CSS 变量定义 | ✅ 全部数值集中于此 |
| `base.css` | 重置 + 基础排版 | ❌ 必须 `var(--...)` |
| `components.css` | 按钮 / 卡片 / 表格 / 表单 / 标签 | ❌ 必须 `var(--...)` |
| `site.css` | 前台页面布局 | ❌ 必须 `var(--...)` |

**硬规则**：后三层**禁止出现字面量颜色与尺寸**。由 `python scripts/check_css_tokens.py` 校验。

```css
/* 正确 */
.card-title {
    font-size: var(--fs-lg);
    color: var(--c-text);
    padding: var(--sp-3) var(--sp-4);
}

/* 错误 */
.card-title {
    font-size: 18px;
    color: #1f2937;
    padding: 12px 16px;
}
```

### 5.2 类名前缀

| 前缀 | 用途 |
|---|---|
| `.btn-` | 按钮 |
| `.card-` | 卡片 |
| `.form-` | 表单 |
| `.list-` | 列表 |
| `.nav-` | 导航 |
| `.tag-` | 标签 |
| `.modal-` | 弹层 |
| `.alert-` | 提示 |
| `.is-` / `.has-` | 状态修饰 |
| `.u-` | 工具类 |

### 5.3 工具内 CSS

工具自包含，**不受网站令牌约束**，可自由定义（但同样建议用 CSS 变量组织）。

## 六、Python 工程脚本

### 6.1 通用要求

- **标准库优先**，不引入 pip 依赖
- Python 3.8+
- 入口统一 `if __name__ == "__main__":`
- 退出码：`0` 成功、`1` 校验失败
- 中文提示

### 6.2 脚本骨架

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""脚本用途说明。

用法:
    python scripts/xxx.py [参数]
"""

from __future__ import annotations

import sys
from pathlib import Path

ROOT = Path(__file__).resolve().parent.parent


def main() -> int:
    """返回退出码。"""
    print("[INFO] 开始…")
    return 0


if __name__ == "__main__":
    sys.exit(main())
```

### 6.3 输出约定

```
[OK]   全部通过
[WARN] 警告，不阻断
[ERR]  错误，退出码 1
[INFO] 普通信息
```

## 八、SQL

```sql
-- 关键字大写，表名列名小写 snake_case
CREATE TABLE IF NOT EXISTS tool_netdisks (
    id              INTEGER PRIMARY KEY AUTOINCREMENT,
    tool_id         TEXT    NOT NULL,
    netdisk_type    TEXT    NOT NULL,
    url             TEXT    NOT NULL,
    extract_code    TEXT    DEFAULT '',
    is_active       INTEGER NOT NULL DEFAULT 1,
    last_checked_at TEXT,
    check_status    TEXT    DEFAULT 'unknown',
    created_at      TEXT    NOT NULL DEFAULT (datetime('now', 'localtime'))
);

CREATE INDEX IF NOT EXISTS idx_netdisks_tool ON tool_netdisks(tool_id);
```

**要求**：

- 关键字大写
- 表名 / 列名 `snake_case`
- 时间统一存 `YYYY-MM-DD HH:MM:SS` 文本（SQLite 无原生日期类型）
- 尽可能标准 SQL，避免 SQLite 专有语法（为将来迁移 MySQL 留路）
- 外键字段必须建索引

## 十、注释

### 10.1 原则

> 注释解释**为什么**，不解释**是什么**（代码本身说明是什么）。

```php
// 好：解释原因
// 用 realpath 而非字符串拼接，防止 ../ 路径穿越
$real = realpath($path);

// 差：复述代码
// 获取真实路径
$real = realpath($path);
```

### 10.2 必须注释的地方

| 位置 | 内容 |
|---|---|
| 类顶部 | 类的职责 |
| 复杂算法 | 思路与边界条件 |
| 兼容性 hack | 为何需要、针对哪个浏览器 |
| 安全相关 | 为何这样写才安全 |
| 魔数 | 数值含义与来源 |

### 10.3 禁止

- ❌ 无意义的 `// TODO`（要么做，要么写清何时做）
- ❌ 注释掉的死代码（git 有历史）
- ❌ 中文与英文混用的注释风格

## 十一、Git 提交

### 11.1 格式

```
<type>(<scope>): <subject>
```

### 11.2 type

| type | 含义 |
|---|---|
| `feat` | 新功能 |
| `fix` | 修复 |
| `docs` | 文档 |
| `style` | 格式（不影响逻辑） |
| `refactor` | 重构 |
| `perf` | 性能 |
| `build` | 构建 / 脚本 |
| `chore` | 杂项 |
| `tool` | 新增或更新工具（scope 填工具 id） |
| `security` | 安全相关 |

### 11.3 scope

填受影响的模块：`frontend`、`admin`、`scanner`、`stats`、`package`、`icons`、`{tool-id}`。

### 11.4 示例

```
feat(frontend): 详情页增加网盘主按钮
fix(admin): 修复 manifest 回写时中文被转义
tool(random-name-classic): v1.2.0 支持加权抽取
docs: 补充设计令牌说明
build(icons): 图标子集化脚本支持增量更新
security(admin): 无密码登录强制 IP 白名单
```

### 11.5 禁止

- ❌ `update`、`fix`、`修改`、`提交` 等无意义描述
- ❌ 一次提交混合多个不相关改动
- ❌ 提交 `var/`、`.env`、`*.db`

### 11.6 提交前检查

```bash
git status                              # 确认没有意外文件
python scripts/check_manifest.py
python scripts/check_no_external.py
python scripts/sync_shared.py --check
git diff --cached                       # 复核改动
```
