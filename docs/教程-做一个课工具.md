# 教程：做一个课工具

> 本教程带你走完全流程：从提案到工具出现在[在线站](https://keetools.ztsite.com)。
> 全程约 1-2 小时（不含工具本身的开发时间）。开工前请先读 [CONTRIBUTING.md](../CONTRIBUTING.md)。

---

## 0. 准备环境（一次性）

```bash
git clone https://github.com/adream2/KeeTools.git
cd KeeTools
git config core.hooksPath .githooks   # 启用 pre-commit 六项校验
cp .env.example .env
php scripts/init_db.php               # 需要 PHP 8+（pdo_sqlite、zip）与 Python 3.8+
php -S 127.0.0.1:8000 -t public public/router.php
```

打开 http://127.0.0.1:8000 确认站点能访问。

## 1. 提案（Issue）

在 GitHub 开一个 **工具提案** Issue：说清楚场景、学段学科、为什么现有工具不够用。
维护者确认后动手——避免做出「课堂用不上」的东西。

## 2. 生成骨架

```bash
python scripts/new_tool.py --id my-tool --title "我的工具" \
    --type shell --subjects 通用 --grades 1-12 --yes
```

脚本会生成 `tools/my-tool/`（manifest.json / index.html / CHANGELOG.md），
并自动把共享外壳（顶栏 / 设置抽屉 / 全屏 / 音效 / 图标）内联进 HTML。

> **id 规则**：小写字母数字连字符，等于目录名，也是网址 slug（`/tool/my-tool`）。

## 3. 认识骨架

打开 `tools/my-tool/index.html`，你会看到几个自动生成的区块：

| 区块 | 能不能改 | 作用 |
|---|---|---|
| `ET-META` 注释 | 只改 version | 与 manifest.json 的版本号联动，门禁校验一致性 |
| `ET:INLINE … et-chrome-css` | ❌ 禁改 | 共享外壳样式（由 `sync_shared.py` 注入） |
| `ET:INLINE … icons` | ❌ 禁改 | 工具图标库 |
| `ET:INLINE … et-util / et-chrome / et-stats` | ❌ 禁改 | 共享逻辑（localStorage 封装 / 外壳 / 统计） |
| 工具自身的 `<style>` / `<main>` / 最后的 `<script>` | ✅ **你的主战场** | 工具的全部功能 |

共享外壳已经帮你解决了：顶栏品牌、深浅色主题、全屏、音效、设置抽屉、
翻页笔按键、PWA 元数据、页脚回流。**你只需要写核心交互。**

## 4. 实现功能（改三处）

1. **工具样式**：替换 `<style>` 里的占位样式。颜色用 `--et-accent` 等令牌，字号要大（教室后排要看得清）
2. **页面结构**：替换 `<main id="et-main">` 里的内容
3. **业务逻辑**：替换最后的 `<script>` 块，套用现成能力：

```js
var store = ET.store('my-tool');          // localStorage，自动加 et_my-tool_ 前缀
var chrome = ET.Chrome.mount({
    toolId: 'my-tool',
    title: '我的工具',
    accent: '#0891b2',                    // 主题色（建议与学科色一致）
    primary: function () { /* 翻页笔 PageDown = 主操作 */ },
    settings: { build: function (body) { /* 右上角设置抽屉 */ } },
    help: '<div>帮助弹窗内容</div>'
});
chrome.toast('完成！');                    // 轻提示
chrome.setStatus('就绪');                  // 顶栏状态
```

**交互基线**（详见 [工具开发规范.md](工具开发规范.md) §八A）：
名单类工具用右上角设置抽屉导入；提供按学号快速生成；
翻页笔上下页键 = 主/副操作；音量按教室大屏调校。

## 5. 自检（全部通过才算完成）

```bash
python scripts/check_manifest.py          # manifest + ET-META 一致性
python scripts/check_no_external.py       # 零外部依赖（一个外链都不许有）
python scripts/sync_shared.py --check     # 共享逻辑已同步
python scripts/check_tools_runtime.py     # 无头渲染抓 JS 报错（需本机 Node/浏览器）
```

手动验证：**双击 `tools/my-tool/index.html`（file:// 协议）能用 → DevTools 断网重试 →
localStorage 刷新后还在 → 1024×768 和 1920×1080 都不糊**。

## 6. 上架（全自动，无需任何后台操作）

把目录放进 `tools/` 之后，刷新本地站点即可看到工具出现——
框架会在每次请求时比对 manifest 的修改时间，自动入库上架（manifest 改动也会自动重扫）。

## 7. 提交 PR

```bash
git checkout -b tool/my-tool
git add tools/my-tool
git commit -m "tool(my-tool): v1.0.0 一句话说明"
git push -u origin tool/my-tool
```

然后开 Pull Request，按模板勾选自检清单。CI 会自动跑门禁；
全绿后维护者审核教学适用性与素材版权，合并后自动出现在在线站。

## 常见坑（前人踩过）

| 坑 | 后果 | 正确做法 |
|---|---|---|
| 在 HTML 里手写完整的 `ET:INLINE` 标记对（哪怕在注释里） | 同步脚本把共享代码注入字符串，页面静默损坏 | 拆字符串：`'<' + '!-- ET:' + 'INLINE … -->'` |
| JS 字符串里出现 `</script>` 字面量 | HTML 提前闭合 script 标签 | 转义为 `'<\/script>'` |
| 引用外部 CDN（字体 / 图标 / 库） | CI 红灯，且违反零依赖原则 | 全部内联；图标走 `tools/_shared/icons/` |
| localStorage key 没加 `et_{toolId}_` 前缀 | 与其他工具数据冲突 | 用 `ET.store('my-tool')` 封装 |
| 只在 1920 宽屏上试过 | 投影仪 1024×768 下布局崩 | 两种分辨率都手动过一遍 |
| 示例数据用了真实学生名单 | 隐私事故 | 用「同学 A / 张三」等虚构名 |
