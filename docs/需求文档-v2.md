## 〇、v2 相对 v1 的关键变更

| # | v1 原设计 | v2 冻结决策 |
|---|---|---|
| 1 | TailwindCSS 做网站 UI | **弃用 Tailwind**，网站自写一套 CSS（设计令牌 + 组件层）。决策理由见 §3.1 |
| 2 | 允许 CDN / 按需打包 | **全站零外部网络依赖**，所有资源本地化 |

| 5 | 图标库在线引用 | 网站：Iconify **仅内置用到的**（Python 脚本子集化）；工具：**完全不依赖网站图标库** |
| 6 | 工具从独立子域提供 | **同源 iframe 嵌入**，不用子域 |
| 7 | 需要 preview.png 封面 | **取消预览图**，iframe 已可预览 |
| 8 | 数据库抽象层预留 MySQL | **不做抽象层**，PDO + 标准 SQL，保留迁移预案 |
| 9 | 工具可能付费/受限 | **全部工具免费**；收益靠赞助 / 网盘分发 / 站内广告 / 工具定制 |
| 10 | PWA 为核心引流通道 | 降级为可选（教师认知低、iOS 不支持 Background Sync、与离线包能力重复） |
| 11 | 逻辑唯一源缺失 | **采用 `tools/_shared/` 共享逻辑源 + 同步脚本**（决策 B）；工具物理独立，但逻辑只维护一处 |
| 12 | 工具面向常规屏 | 工具**默认按大屏 / 全屏投影设计** |
| 13 | 版本号管理无落点 | **URL 绝不含版本号**；版本号写在 manifest 与工具包内 `CHANGELOG.md`，后台据此判断待更新 |
| 14 | 工程规范未定义 | 先建**标准 VibeCoding 文件**（AGENTS.md / docs / tasks）+ **git 版本管控** + 临时产物隔离目录 |

## 二、核心设计原则

| 原则 | 含义 |
|---|---|
| **解耦** | 网站与工具完全独立。工具不通信、不引用网站资源、不依赖网站后端。`manifest.json` 是唯一契约。 |
| **离线优先** | 工具断网可用；网站负责分发与统计。 |
| **零外部依赖** | 网站与工具**均不得引用任何第三方域名资源**。无 CDN、无在线字体、无在线图标。 |
| **工具独立** | 一个工具一个目录、一个永久路径、一个独立版本号。工具之间不共享运行时资源。 |
| **变现导向** | 网盘（合集包）是核心变现路径；详情页设计服务于转化。 |
| **统计轻量** | 只统计"被打开"级行为，不侵入工具内部。能统计到就统计，不写补偿/重试逻辑。 |
| **规范统一** | 所有工具遵守同一套 manifest + HTML 规范。 |
| **可迁移** | 无 ORM 抽象层，但 SQL 尽量标准，保留一次性迁移到 MySQL 的能力。 |

## 三、技术栈（冻结）

| 层 | 技术 | 说明 |
|---|---|---|
| 网站前端 | **原生 HTML + 自写 CSS + 原生 JS** | 不用 Tailwind、不用前端框架。设计令牌 + 组件层。 |
| 网站图标 | **Iconify 图标子集 + 内联 SVG sprite** | 只内置用到的图标；须做许可证合规登记。 |
| 网站后端 | **PHP 8+** | 自研轻量框架（路由 / 中间件 / 视图 / 安全层） |
| 数据库 | **SQLite（WAL 模式）+ PDO** | 不做抽象层；SQL 保持标准，预留迁移预案 |
| 打包 | **PHP ZipArchive**（必要时 CLI zip） | 后台异步任务，带进度轮询 |
| 工具本体 | **纯 HTML/CSS/JS 单文件，零依赖，资源全内联** | 默认大屏设计 |
| 工具数据 | **localStorage**（key 前缀 `et_{toolId}_{key}`） | 不依赖服务器 |
| PWA | Service Worker + Cache API（**可选，非核心**） | 若实现，须有 `online` / `visibilitychange` 降级上报 |
| 工程脚本 | **Python 3（标准库优先）** | 图标子集化、`_shared` 同步、离线包校验、域名检查 |
| 版本管控 | **Git** | 见 §4.0 工程规范 |

### 3.1 为什么弃用 TailwindCSS（决策留痕）

| 方案 | 传输体积 | 是否依赖外网 | 结论 |
|---|---|---|---|
| Tailwind Play CDN | 运行时浏览器编译 | ❌ 依赖外网 | 明确禁止 |
| 本地 CLI 构建产物 | ~20-30KB | ✅ 本地 | 技术上可行，但引入 Node/npm 工具链 |
| 完整预编译版 | min 后 ~3.4MB | ✅ 本地 | 能零 CDN，但体积过大 |
| **手写设计令牌 + 组件层 CSS** | **~25-35KB** | **✅ 本地** | **✅ 采纳** |

**决策理由**：
1. 网站 UI 复杂度不高（列表 / 卡片 / 表格 / 表单 / 详情页），手写一套令牌 + 组件的成本低于引入构建链
2. 避免 Node/npm 工具链（与"零外部依赖、纯 PHP"的极简取向一致）
3. 完全可控，不被框架升级节奏绑架

**前置约束**：必须**先定令牌体系**（色板 / 字号阶梯 / 间距基数 / 圆角 / 阴影），否则前台与后台必然两套风格。令牌定义见 §7.5。

**兜底方案**：若手写 CSS 在 P1 阶段被证明拖慢进度，可切回"Tailwind 本地 CLI 构建产物"，此时只替换 `assets/css/` 产出，不影响其他架构。**此切换只允许发生一次，且必须在 P1 结束前决定。**

### 3.2 工程脚本语言

统一使用 **Python 3（标准库优先，不引入 pip 依赖）**，覆盖：

| 脚本 | 职责 |
|---|---|
| `scripts/icons/build_sprite.py` | 扫描代码中的图标名 → 子集化导出 SVG → 生成 sprite |
| `scripts/sync_shared.py` | 把 `tools/_shared/` 的逻辑内联进各工具 `index.html` |
| `scripts/check_no_external.py` | 检查产出物是否含非本站域名 URL |
| `scripts/check_manifest.py` | 校验 manifest 完整性 + `ET-META` 版本一致性 |
| `scripts/build_package.py` | 离线包构建的本地预演（生产由 PHP 执行） |

### 硬性验收标准

产出物中**不得出现任何非本站域名的 URL**。构建流程加入自动检查：

```bash
python scripts/check_no_external.py
# 或快速检查
grep -rEn 'https?://' dist/ public/ | grep -v 'YOUR_DOMAIN'
```

### 4.0 工程规范（VibeCoding 标准件）

| 文件 / 目录 | 作用 |
|---|---|
| `AGENTS.md` | **AI Agent 协作契约**：项目背景、硬约束、编码规范、目录约定、常用命令、禁止事项 |
| `README.md` | 人类开发者入口：项目简介、快速开始、状态 |
| `docs/` | 全部规范文档（需求 / 架构 / 工具规范 / manifest 规范 / 安全 / 编码 / 品牌） |
| `tasks/` | **分阶段任务计划表**（每阶段一个 md，含验收标准与进度勾选） |
| `.env.example` | 环境变量模板（**含后台账号密码 / 无密码开关**） |
| `.gitignore` | 忽略产出物、临时文件、密钥、数据库 |
| `.editorconfig` | 统一缩进 / 换行 / 编码（跨编辑器一致） |
| `CHANGELOG.md` | 项目级变更日志（工具级变更在各工具包内） |
| `THIRD-PARTY-LICENSES.md` | 第三方资源许可证登记 |
| `scripts/` | Python 工程脚本 |
| `var/` | **临时产物隔离区**（构建中间件 / 缓存 / 预览 / 导出草稿），全量 gitignore |

**临时产物规则（硬约束）**：
> 任何临时文件、构建中间产物、调试输出、导出的草稿 **一律写入 `var/`**，禁止散落在仓库根或 `app/`、`assets/`、`tools/` 等架构目录内。`var/` 整体不纳入版本管控。

### 4.2 单个工具

```
tools/{tool-id}/
├── manifest.json             # 必须 — 工具身份证，唯一契约
├── index.html                # 必须 — 入口
├── CHANGELOG.md              # 必须 — 工具级版本变更日志
├── README.md                 # 可选 — 工具说明 / 数据格式 / 使用提示
└── assets/                   # 可选 — 非单文件工具的资源；单文件工具不得引用
```

**单文件规则（修正版）**：

> **能单文件的尽量单文件**。单文件意味着 CSS/JS/图标/素材全部内联，双击 `file://` 即可运行。
> 若工具确实无法单文件（如需要大体积模型、多张高清素材、WebAssembly 模块），允许使用 `assets/` 相对引用，但必须：
> 1. manifest 中 `single_file` 显式设为 `false`
> 2. 在 `dependencies` 中声明实际使用的本地资源
> 3. 登记到 `docs/工具例外清单.md`
> 4. 离线包打包时**整个目录一起打包**（不能只打 `index.html`）

### 4.3 `_shared/` 的定位（决策 B，已采纳）

工具物理独立，但**同一逻辑不在多份文件中重复维护**。设立 `_shared/` 作为**开发期唯一逻辑源**：

```
tools/_shared/
├── logic/                    # 共享逻辑源（点名/倒计时/计分/随机算法…）
│   ├── random-pick.js
│   ├── countdown.js
│   └── scoreboard.js
├── ui/                       # 共享 UI 片段
│   ├── et-import.js          # 通用数据导入组件（重点基建）
│   └── et-chrome.js          # 全屏工具条 / 页脚回流条
├── icons/                    # 工具用图标（内联源，独立于网站图标库）
└── shared.manifest.json      # 声明各工具引用了哪些共享片段
```

**工作流**：

```bash
# 1. 改逻辑 → 只改 tools/_shared/logic/xxx.js
# 2. 跑同步脚本 → 自动内联进所有引用它的工具
python scripts/sync_shared.py            # 全部工具
python scripts/sync_shared.py random-name-classic   # 指定工具
python scripts/sync_shared.py --check    # 仅检查是否已同步（CI 用）
```

**同步机制**：工具 `index.html` 中使用占位标记，脚本做幂等替换：

```html
<!-- ET:INLINE name="random-pick" src="logic/random-pick.js" -->
<script>
/* 此处由 scripts/sync_shared.py 自动注入，请勿手工修改 */
</script>
<!-- /ET:INLINE -->
```

- 标记内的内容由脚本生成，**禁止手工编辑**
- `--check` 模式用于 git pre-commit 钩子，防止忘记同步
- `_shared/` 不参与扫描、不进离线包、不对外分发、不出现在任何 URL 中

## 五、manifest.json 规范（冻结）

### 5.1 完整示例

```json
{
  "id": "random-name-classic",
  "title": "随机点名器（经典版）",
  "version": "1.2.0",
  "type": "shell",
  "description": "导入名单即可随机点名，支持去重、已点标记、加权抽取。适合课堂互动与大屏投影。",
  "author": "EduTools Team",
  "entry": "index.html",
  "single_file": true,
  "offline": true,
  "grade_range": ["1-12"],
  "subjects": ["通用"],
  "tags": ["点名", "课堂互动", "抽签", "大屏"],
  "family": "random-name",
  "license": "free",
  "dependencies": [],
  "screen": "large",
  "stats_enabled": true,
  "created_at": "2026-09-01",
  "updated_at": "2026-09-18"
}
```

### 5.2 字段说明

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `id` | string | ✅ | 全局唯一，**必须等于目录名**，即 URL slug。仅允许 `[a-z0-9-]` |
| `title` | string | ✅ | 展示名称 |
| `version` | string | ✅ | 语义化版本 `MAJOR.MINOR.PATCH`。用于判断与管理 |
| `type` | enum | ✅ | `fixed` / `shell` / `experiment` |
| `description` | string | ✅ | 一句话简介，建议 ≤ 60 字 |
| `author` | string | ✅ | 作者 / 团队 |
| `entry` | string | ✅ | 入口文件名，固定 `index.html` |
| `single_file` | bool | ✅ | 是否单文件。**能单文件的尽量为 `true`**；为 `false` 需登记例外清单 |
| `offline` | bool | ✅ | 是否离线可用 |
| `grade_range` | string[] | ✅ | 适用学段，如 `["1-6"]`、`["7-9"]`、`["10-12"]` |
| `subjects` | string[] | ✅ | 学科，通用类填 `["通用"]` |
| `tags` | string[] | ✅ | 自由标签。**关联同一逻辑不同花样工具的主要手段** |
| `family` | string | ❌ | 逻辑族标识。同一算法的不同花样填相同值（如 `random-name`） |
| `license` | string | ❌ | 默认 `free` |
| `dependencies` | string[] | ✅ | 本地资源依赖列表。单文件工具**必须为空数组**；非单文件工具须逐项声明 |
| `screen` | enum | ❌ | 目标屏幕：`large`（默认）/ `any` |
| `stats_enabled` | bool | ❌ | 是否纳入统计，默认 `true` |
| `created_at` / `updated_at` | date | ✅ | `YYYY-MM-DD` |

### 5.3 工具内元数据块（版本一致性校验）

工具 HTML 中必须包含机器可读块，扫描器与 `manifest.json` 比对：

```html
<!-- ET-META
{"id":"random-name-classic","version":"1.2.0"}
-->
```

**不一致时后台必须高亮报错**，不允许静默通过。

### 5.4 版本号与变更记录（重要）

**版本号落点（URL 绝不含版本号）**：

| 序号 | 落点 | 说明 |
|---|---|---|
| 1 | `manifest.json` 的 `version` | 唯一的机器可读真源 |
| 2 | 工具目录内 `CHANGELOG.md` | **工具级变更日志**（新增/修复/破坏性变更） |
| 3 | 工具 HTML 页脚展示 | 运行时可见，如 `v1.2.0` |
| 4 | 前台详情页展示区 | `v1.2.0 · 更新于 2026-09-18` |
| 5 | 离线包文件名 | 如 `EduTools-初中物理-v2026.09.zip` |
| 6 | 后台"待更新"列表 | 据此判断哪些工具需重新打包 |

**URL 规则**：

- 工具永久路径：`/tool/{id}`（**无扩展名、不含版本号**）
- 带版本号会导致更新后 URL 变更 → SEO 权重归零、外链失效、统计断裂
- 旧版本如需留档：`/tool/{id}/v/{version}`，可访问但 `noindex`，不进导航与搜索

**工具内 `CHANGELOG.md` 模板**：

```markdown
# 变更记录 — random-name-classic

## [1.2.0] - 2026-09-18
### 新增
- 支持加权抽取（按权重列）
### 修复
- 修复 500 人名单导入时的卡顿

## [1.1.0] - 2026-09-10
### 新增
- 已点标记与去重开关
```

**发布流程**：改代码 → 升 `manifest.version` → 更新 `CHANGELOG.md` → 升 HTML 内 `ET-META.version` → `python scripts/check_manifest.py` 通过 → 提交。

## 六、工具开发规范（冻结）

| 规则 | 要求 |
|---|---|
| 单文件 | CSS / JS / 图标 / 素材**尽量全部内联**到 `index.html`，双击 `file://` 打开即用 |
| 外部依赖 | ❌ **禁止**任何外部 URL 引用（含 CDN、在线字体、在线图标） |
| 图标 | 使用**内联 SVG**（工具自带 `_shared/icons/`），**不得**引用网站图标库 |
| 数据持久化 | `localStorage`，key 命名 `et_{toolId}_{key}` |
| 导入导出 | JSON / CSV 文件操作，使用 File API，不依赖服务器 |
| 与网站通信 | ❌ **不通信**。允许监听 `postMessage` 接收主题参数（可选，需有默认值） |
| 统计 | ❌ 工具内部**不统计任何操作**。统计由网站服务端注入脚本完成 |
| 屏幕设计 | **默认按大屏 / 全屏投影设计**（基准 1920×1080），同时兼容 1024×768 |
| 浏览器兼容 | Win7 + 老版 Chrome / 360。使用系统字体栈；避免 `:has()`、`structuredClone` 等新 API |
| 回流 | 见 §11.4 三层回流设计。引导信息内置于代码中（工具内不主动弹窗）；打包产物内含品牌信息文件 |
| 变更记录 | 必须维护工具目录内 `CHANGELOG.md`，版本变更时同步更新 |
| 共享逻辑 | 引用共享片段必须使用 `ET:INLINE` 标记 + `scripts/sync_shared.py`，**禁止手工复制粘贴** |

### 6.1 类型定义

| 类型 | 标识 | 说明 | 示例 |
|---|---|---|---|
| 固定知识型 | `fixed` | 知识有限、标准 | 拼音表、元素周期表、古诗词 |
| 空壳容器型 | `shell` | 老师自行导入数据 | 随机点名、大转盘、倒计时、计分板 |
| 实验模拟型 | `experiment` | H5 理科实验交互 | 电路搭建、凸透镜成像、酸碱滴定 |

> **`fixed` 型的数据边界**：建议内置数据 **> 500 条即不算"工具"**，应改为"通用渲染器 + 可替换数据文件"结构，避免沦为题库维护（与"只做工具不做题库"定位冲突）。

### 6.2 强制复用组件

`shell` 型工具的核心留存点是"老师导入名单"。所有需导入数据的工具**必须复用同一导入组件**（`_shared/ui/et-import.js`）：

- 支持：粘贴文本 / CSV / JSON / Excel
- 自动识别列、去重、空值处理
- 教室高频操作，此组件质量优先级**高于新增工具数量**

### 8.1 manifest 回写规则（关键）

- `manifest.json` 是**唯一真源**。后台编辑元数据时**写回文件**（`JSON_PRETTY_PRINT | JSON_UNESCAPED_UNICODE`）
- 数据库只存三类：**索引**（供查询排序）、**统计**、**纯用户态字段**（featured / sort / publish / 网盘链接）
- 若 `tools/` 不可写，**降级为写 DB override 表**，并在后台明确提示处于降级模式

### 8.2 角色权限边界

| 能力 | admin | editor |

| 工具元数据编辑 | ✅ | ✅ |
| 分类管理 | ✅ | ✅ |

### 8.3 管理员账号与环境变量（重要）

管理员凭据**不硬编码**，全部来自环境变量（`.env`，不纳入版本管控）：

```dotenv
# ── 应用 ──────────────────────────────
APP_ENV=local                     # local | production
APP_DEBUG=true                    # 生产必须 false
APP_URL=http://localhost:8000
APP_TIMEZONE=Asia/Shanghai

# ── 后台管理员 ────────────────────────
# 方式一：账号密码
ADMIN_USERNAME=admin
ADMIN_PASSWORD=                   # 留空则视为未设置密码

# 方式二：无密码后台（仅限本机/内网）
ADMIN_PASSWORDLESS=false          # true = 跳过密码校验
ADMIN_PASSWORDLESS_IPS=127.0.0.1,::1   # 仅这些 IP 允许无密码登录

# ── 数据库 ────────────────────────────
DB_PATH=storage/app.db
STATS_DB_PATH=storage/stats.db

# ── 安全 ──────────────────────────────
APP_KEY=                          # 32 字节随机串，用于签名/加密
SESSION_NAME=et_session
SESSION_LIFETIME=7200

# ── 站点 ──────────────────────────────
SITE_NAME=EduTools
SITE_DOMAIN=localhost             # check_no_external.py 用此白名单
DOWNLOAD_DIRECT_ENABLED=true      # 单文件直接下载总开关
```

**实现规则**：

| 规则 | 说明 |
|---|---|
| 优先级 | 环境变量 > `site_config` 表 > 代码默认值 |
| 密码存储 | 环境变量给的是**明文**，首次登录后可在后台改密（改密后写入 `admins` 表，环境变量降级为初始值） |
| 无密码后台 | `ADMIN_PASSWORDLESS=true` 时：① 仅 `ADMIN_PASSWORDLESS_IPS` 白名单内的 IP 可直接进入 ② **`APP_ENV=production` 且非白名单时必须强制报错退出**，不得静默降级 |
| 生产保护 | `APP_ENV=production` 时，若 `ADMIN_PASSWORD` 为空且 `ADMIN_PASSWORDLESS=false`，启动即拒绝服务 |
| 密钥保护 | `.env` 必须在 `.gitignore` 中；仓库只提交 `.env.example` |
| 泄露防护 | 后台"系统信息"页回显配置时，所有 `*_PASSWORD` / `APP_KEY` 显示为 `******` |

## 九、数据库设计（SQLite）

```sql
-- 分类表（两级：学段一级，学科二级）
categories (
  id, name, slug, parent_id, level, sort_order, icon
)

-- 工具元数据索引（与 manifest.json 镜像）
tools (
  id, tool_id UNIQUE, title, description, version, type,
  family, grade_range JSON, subjects JSON, tags JSON,
  is_featured, is_published, sort_order,
  dir_path, manifest_mtime, meta_mismatch INTEGER,
  created_at, updated_at
)

-- 分类-工具关联
tool_category (tool_id, category_id)

-- 网盘链接
tool_netdisks (
  id, tool_id, netdisk_type, url, extract_code,
  package_name, file_size, is_active,
  last_checked_at, check_status
)

-- 统计（独立库文件，减轻写锁）
stats (
  id, tool_id, event_type, netdisk_type,
  ip_hash, ua_hash, referer, created_at
)

-- 管理员
admins (id, username, password_hash, role, last_login)

-- 站点配置
site_config (key, value)
```

### 9.1 SQLite 并发要点（必须实现）

`POST /api/track` 是全站最高频写操作，而 SQLite 写锁是**库级全局锁**，与管理后台写入并发时必然触发 `SQLITE_BUSY`。

| 措施 | 说明 |
|---|---|
| WAL 模式 | `PRAGMA journal_mode=WAL` |
| 超时等待 | `PRAGMA busy_timeout=5000` |
| 统计独立库 | `storage/stats.db` 与业务库物理隔离 |
| 写入缓冲 | 请求只写 append-only 日志，每分钟批量落库 → N 次写变 1 次写 |

### 9.2 MySQL 迁移预案（不做抽象层）

- 全部 SQL 使用 **PDO 参数化查询**，禁止字符串拼接
- 尽量标准 SQL：避免 SQLite 专有语法（如 `INSERT OR REPLACE` 用事务 + `SELECT/UPDATE` 替代）
- 迁移时另写一次性脚本处理：自增列定义、时间函数、JSON 字段、索引语法
- 数据库连接集中在一个 `Database` 类，切换只需改该类 + 迁移脚本，**不引入 ORM**

## 十、统计体系

### 10.1 统计事件（只保这三个）

| 事件 | 标识 | 说明 |
|---|---|---|
| 详情页浏览 | `view` | 页面加载 |

### 10.2 统计注入方式（关键决策）

在线访问工具时，由 **PHP 在输出 HTML 前，向 `</body>` 前注入一小段上报脚本**：

- 独立 IIFE，不依赖工具任何代码
- 下载的单文件保持**绝对干净**（无统计代码）
- 统计能力由**服务端保证**，不靠工具自觉，工具无需留任何接口

| 趋势 | 近 7 / 30 / 90 天按日趋势 |
| 转化率 | 浏览 → 网盘点击转化率 |

## 十一、分发体系

### 11.1 轨道 A：离线合集包（变现核心）

| 环节 | 设计 |
|---|---|
| 定位 | **单个工具 = 免费尝鲜；合集包 = 网盘获取** |
| 入口 | 工具详情页 → "获取工具"区 → 网盘选项置顶高亮 |
| 中间页 | `/netdisk/{tool_id}?type=baidu` → 链接 + 提取码 + 倒计时 + 引流 |
| 网盘类型 | 百度网盘 / 阿里云盘 / 123云盘 / 夸克网盘 |
| 后台管理 | 每工具可配多个网盘链接 + 提取码，独立启用/禁用 + 探活 |
| 统计 | 记录每次点击（工具 ID + 网盘类型 + IP 哈希 + 时间） |
| 包内容 | 按学段 + 学科打包合集，含**本地导航门户** + 品牌回流文件 |
| 体积控制 | **目标 < 10MB / 包**（只放 HTML 单文件，不放图片素材与 PDF） |
| 网盘选择 | 优先限速宽松的 123 / 夸克；百度次之。最终按后台转化数据决定 |
| 提取码 | 放**中间页**（转化道具），**不放包内**（自相矛盾） |
| 失效处理 | `last_checked_at` 定时探活；中间页提供"链接失效"反馈；同工具至少配 2 个网盘 |

### 11.2 轨道 B：直接下载单文件（免费）

| 环节 | 设计 |
|---|---|
| 入口 | 详情页折叠区"仅下载本工具"（**次级文字链，不与网盘并列**） |
| 后台 | **开关控制** |
| 内容 | 单个 HTML 文件，双击即用 |
| 统计 | 记录点击（可丢失） |
| 回流 | 必须**强制植入品牌回流**（见 11.4） |

### 11.3 轨道 C：PWA（可选）

保留但不作为核心。若实现，必须支持 `online` / `visibilitychange` 降级上报。

### 11.4 品牌回流设计（必须有可见触点）

仅靠 HTML 注释或包内说明文件**回流效率接近 0**。采用三层：

| 层级 | 位置 | 说明 |
|---|---|---|
| L1 | 首次运行一次性轻提示 | 可永久关闭，`localStorage` 记标记 |
| L2 | 工具内低调页脚一行 | 小字非侵入，如"EduTools · 更多课堂工具" |
| L3 | **离线包本地导航门户 `index.html`** | **主力触点** — 老师打包后一定会打开它 |

补充：打包产物的 `关于EduTools.txt` 作为附加，不作主力。

### 11.5 离线包导航门户（高价值基建）

在线版与离线包**复用同一套外壳代码**，仅切换数据源：

```
在线版：外壳 + manifest 索引（远程加载工具）→ 部署在服务器
离线包：外壳 + 本地 tools-index.json（zip 内加载工具）→ 打包给网盘
```

导航门户需支持：本地搜索（无需后端）、按学段/学科筛选、显示工具版本号、"检查更新"链接回站。

**引流埋点**：打包时给门户内每个工具链接加 UTM（`?from=offline-pkg`），用于统计网盘带来的真实流量。

## 十二、安全要求（自研框架必须自己兜）

| 项 | 要求 |
|---|---|
| **路径穿越**（最高危） | manifest 扫描 + 后台文件操作必须 `realpath()` 校验并限制在 `tools/` 根内 |
| CSRF | 所有 POST 表单 + AJAX 必须带 token 并在服务端校验 |
| 会话安全 | `session_regenerate_id()` 防固定；同 IP/账号失败计数限流；Cookie 加 `HttpOnly` + `SameSite` |
| 权限 | 统一 `require_role()` 中介层，敏感端点全覆盖 |
| 输出转义 | 所有输出 `htmlspecialchars()`；JS 上下文用 `json_encode()` |
| 上传/导入 | 严格 MIME + 扩展名白名单；不使用原始文件名 |
| ZipArchive 打包 | 用**临时目录 + 分批 `addFile`**，避免一次性 `addFromString` 爆内存；设为**异步任务**（前端轮询进度），防止 `max_execution_time` 超时；打包排除 `.DS_Store`、`node_modules`、`src/` |
| 密钥管理 | `.env` 纳入 `.gitignore`；仓库只提交 `.env.example`；后台回显一律掩码 |
| 无密码后台 | `ADMIN_PASSWORDLESS=true` 时**必须**配 `ADMIN_PASSWORDLESS_IPS` 白名单；`APP_ENV=production` 且非白名单 IP 命中时**拒绝服务并报错**，不得静默放行 |
| 生产启动自检 | `APP_ENV=production` 时校验：`APP_DEBUG=false`、`APP_KEY` 非空、管理员凭据已设置，任一不满足则拒绝启动 |
| 目录不可访问 | `var/`、`storage/`、`src/`、`tools/`、`docs/` **必须**在 Web 层拒绝访问（`.htaccess` / Nginx 规则 / 把 Web 根限定为 `public/`） |

| 约束 | 要求 |
|---|---|

### 13.1 图标策略与许可证合规

**网站图标**：从 Iconify 取用，但**只内置用到的**，通过 Python 脚本子集化：

```
assets-src/icons/icons.txt          # 手写：用到的图标名清单（每行一个）
        ↓ python scripts/icons/build_sprite.py
public/assets/icons/sprite.svg      # 产出：SVG sprite（仅含用到的图标）
```

- `icons.txt` 形如：`lucide:search`、`lucide:download`、`tabler:external-link`
- 脚本从**本地离线图标集合**读取（不联网），按名字提取 → 合成 `<symbol>` → 输出 sprite
- 网站页面用 `<svg><use href="/assets/icons/sprite.svg#i-search"></use></svg>`
- 不使用 icon font（字体加载失败会变方框）；SVG 可用 `currentColor` 跟随主题色

**工具图标**：完全独立，来源为 `tools/_shared/icons/`（内联进工具 HTML），**与网站 sprite 无关**。

**Iconify 许可证注意**（它是聚合器，不同图标集许可证不同）：

| 图标集 | 许可证 | 商用 |
|---|---|---|
| Lucide / Tabler / Phosphor | ISC / MIT / MIT | ✅ |
| Material Symbols | Apache-2.0 | ✅（保留声明） |
| FontAwesome Free | CC-BY 4.0 | ⚠️ 需署名 |
| `logos:` / `simple-icons:` | 商标限制 | ⚠️ 慎用 |

**建议**：只选 2-3 个宽松集（Lucide + Tabler 基本够用），按需导出，登记至 `THIRD-PARTY-LICENSES.md`。

### 13.2 临时产物隔离（硬约束）

| 规则 | 说明 |
|---|---|
| 临时产物目录 | 一律写入 `var/`（`cache/`、`tmp/`、`logs/`、`exports/`） |
| 禁止位置 | 仓库根、`app/`、`src/`、`assets/`、`public/`、`tools/` **不得**出现临时文件 |
| `var/` 生命周期 | 全量 gitignore；可随时整体删除，不影响运行（首次运行自动重建） |
| 构建中间产物 | 图标子集化中间文件、CSS 构建中间文件 → `var/cache/` |
| 调试导出 | 后台导出的 CSV / 打包预览 → `var/exports/` |
| 日志 | 应用日志 → `var/logs/`（**不是** `storage/`，存储层只放数据库） |

> 判据：**`var/` 之外出现非计划内的文件 = 架构污染**。git 提交前用 `git status` 复核。

## 十七、已知风险与应对

| 风险 | 应对 |
|---|---|
| 同一逻辑多工具重复 → 修 N 遍 | 采用 `_shared/` + `sync_shared.py`（决策 B），git hook `--check` 防漏同步 |
| 网盘限速导致转化流失 | 包体压到 <10MB；主推限速宽松网盘；中间页做分卷提示 |
| 网盘链接失效伤信任 | 定时探活 + 一键反馈 + 多网盘冗余 |
| 单文件免费下载分流网盘转化 | 定位改为"先下载一个试试"；主按钮留给合集包；后台可关 |
| `fixed` 型沦为题库维护 | 设 500 条数据上限判据，超出改用渲染器 + 可替换数据 |
| `tools/` 目录不可写 | 降级为 DB override 表，后台提示降级模式 |
| 教室老浏览器不兼容 | 系统字体栈 + 回避新 API + 双分辨率适配 |
| 统计被广告拦截 | 只保证三个核心事件，不做补偿逻辑 |
| 手写 CSS 拖慢进度 | §3.1 兜底方案：切 Tailwind 本地构建产物，只换 `assets/css/` 产出 |
| 无密码后台被误暴露 | 强制 IP 白名单 + 生产环境拒绝启动 + 启动自检 |
| 临时产物污染架构 | `var/` 隔离 + `.gitignore` + 提交前 `git status` 复核 |
| 工具忘记同步共享逻辑 | `python scripts/sync_shared.py --check` 接入 git pre-commit |
