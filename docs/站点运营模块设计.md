## 一、总原则（沿用 EduPick 验证过的三条硬约定）

1. **工具本体永不投广告**。`/tool/{id}/use`（iframe 内）`adsAllowed = false`；
   工具页纯公益、不影响课堂体验，这是产品底线，不可动摇。
2. **关闭即零痕迹**。总开关关 / 插槽无代码 / 公告关闭时，前台对应节点数为 0，
   不输出任何空壳标签。
3. **模板不读裸配置**。所有运营数据经统一访问层归一化（旧键兼容集中一处）；
   未配置 / 坏数据 → 返回空，前台照常出页面。

另加 KeeTools 特有约定：

4. **所有外部 URL 过白名单**（对应 edupick `ioSafeUrl()`）：只放行 `http(s)://`、
   `mailto:`、站内 `/` 开头路径；拒绝 `javascript:` / `data:` / `vbscript:` /
   `file:` 与协议相对 `//`。友链、公告链接、备案链接、二维码一律过此过滤。
5. **原始 HTML 字段**（广告代码）仅 `admin` 角色可写（editor 无权），原样输出。
6. 广告与统计同属 P1，共享同一套「运营配置」后台 Tab 框架。

## 二、广告位

### 2.1 插槽清单（键名固定，与 edupick 一致）

| slot | 位置 | 说明 |
|---|---|---|
| `home_top` | 首页 Hero 上方 | 最高曝光 |
| `list_top` | 列表页顶部（分类 / 搜索） | |
| `list_bottom` | 列表页底部（页脚上方） | |
| `detail_side` | 详情页侧栏（工具信息卡下方） | |
| `detail_bottom` | 详情页正文末尾 | |
| `footer` | 页脚内（备案行上方） | 高可视低干扰 |

### 2.2 每槽属性

```sql
CREATE TABLE ad_slots (
    slot       TEXT PRIMARY KEY,      -- 上表 6 个键名
    enabled    INTEGER NOT NULL DEFAULT 0,
    code       TEXT    NOT NULL DEFAULT '',   -- 原始 HTML/JS，仅 admin 可写，原样输出
    device     TEXT    NOT NULL DEFAULT 'all' CHECK (device IN ('all', 'desktop', 'mobile')),
    start_date TEXT    NULL,          -- YYYY-MM-DD 生效期，空 = 不限
    end_date   TEXT    NULL,
    updated_at TEXT    NOT NULL
);
```

要点（照搬 edupick 的踩坑结论）：

- **设备区分只加 CSS 类、不在服务端按 UA 分流**（`ad-slot--device-mobile` +
  媒体查询隐藏），避免缓存 / 缓存层把桌面广告发给手机。
- 生效期按**日期字符串比较**（`ioInDateWindow()`），避免时区歧义；活动广告到期自动下架。
- 输出包裹 `<div class="ad-slot ad-slot--{slot}">…<span class="ad-label">广告</span></div>`，
  「广告」标签必须存在（合规 + 用户体验）。
- `code` 为空 / 未启用 / 不在生效期 → 输出空串，零痕迹。

### 2.3 后台

站点设置新增「广告位」Tab：6 张插槽卡（总开关 + 每槽开关 / 代码 textarea / 生效期 / 设备下拉）。
保存按槽增量写入，互不清空。

## 三、公告

参考 edupick `announcements.json` + 顶部通栏 + 公告中心弹层。

### 3.1 数据

```sql
CREATE TABLE announcements (
    id         INTEGER PRIMARY KEY,
    type       TEXT    NOT NULL DEFAULT 'info' CHECK (type IN ('info', 'update', 'warning')),
    text       TEXT    NOT NULL,
    link       TEXT    NULL,             -- 过 URL 白名单
    link_text  TEXT    NULL,             -- 链接文案，默认「查看」
    pinned     INTEGER NOT NULL DEFAULT 0,   -- 置顶（通栏排序优先）
    enabled    INTEGER NOT NULL DEFAULT 0,
    start_date TEXT    NULL,
    end_date   TEXT    NULL,
    sort_order INTEGER NOT NULL DEFAULT 0,
    created_at TEXT    NOT NULL
);
```

全局开关：`site_config.announce_enabled`；通栏条数：`announce_bar_count`（默认 1，
可 1~3）；可关闭：`announce_closable`（默认开）；通栏居中：`announce_center`。

### 3.2 前台行为

- 顶部通栏（`header` 下方）显示生效期内、enabled 的公告，按 pinned → sort 排序取前 N 条。
- **关闭记忆用内容指纹**：渲染时输出 `data-notice-finger = sha1(text)`，
  localStorage 记住已关闭的指纹；**改了文案指纹变化，旧访客会重新看到**（edupick 关键设计）。
- 「公告中心」弹层：通栏关闭后仍可从入口回看全部公告（pinned 优先）。
- 类型带色点：info（蓝）/ update（绿）/ warning（橙），复用 `.tag-*` 配色。

### 3.3 后台

「公告」Tab：列表增删改排序 + 每条启用/置顶/类型/生效期；顶部通栏开关与条数。

## 四、页脚设置

参考 edupick `footer.*` 结构。全部存 `site_config`（键名前缀 `footer_`）：

| 键 | 说明 |
|---|---|
| `footer_brand_desc` | 品牌描述（留空取站点口号；页脚宜短） |
| `footer_copyright` | 版权行，支持占位符 `{year}` `{site_name}` |
| `footer_icp_number` / `footer_icp_url` | ICP 备案号 + 查询链接（默认工信部；**备案要求可点击**） |
| `footer_police_number` / `footer_police_url` | 公安备案 |
| `footer_statement` | 补充声明（未成年人保护 / 免责说明） |
| `footer_show_sitemap` | 是否显示「站点地图」链接（P3 有 sitemap 后生效） |

页脚布局（自上而下）：品牌描述 → 友链分组（见 §五）→ 备案行（ICP / 公安，可点击）→
补充声明 → 版权行。友链 / 公告等归各自模块，页脚设置**只管自己的字段**（分区保存互不影响）。

「关于 / 使用说明 / 更新日志」等链接 P1 后期以单页模块补充，出现后自动进页脚，
不占用友链配置。

## 五、友链（首页 / 内页分离）

与 edupick 的差异点：edupick 友链只有页脚一组（最多 3 组列）；
KeeTools 按 SEO 惯例拆成**首页友链**与**内页友链**两个投放面：

- **首页友链**：只在首页页脚渲染。放权重交换的主友链（对首页投票价值最高）。
- **内页友链**：分类页 / 搜索页 / 详情页页脚渲染。放次级友链或量大的导航互收，
  不稀释首页导出权重。

### 5.1 数据

```sql
CREATE TABLE friend_links (
    id         INTEGER PRIMARY KEY,
    name       TEXT    NOT NULL,             -- 锚文本，1~20 字
    url        TEXT    NOT NULL,             -- 过 URL 白名单（http(s) / 站内 /）
    placement  TEXT    NOT NULL DEFAULT 'all' CHECK (placement IN ('home', 'sub', 'all')),
    nofollow   INTEGER NOT NULL DEFAULT 0,   -- 内页友链建议默认 1
    enabled    INTEGER NOT NULL DEFAULT 1,
    sort_order INTEGER NOT NULL DEFAULT 0,
    created_at TEXT    NOT NULL
);
```

渲染规则：

- 每个投放面最多展示 20 条（超出截断，提示超出部分不输出——不搞分页）。
- 首页面 = `placement IN ('home', 'all')`；内页面 = `placement IN ('sub', 'all')`。
- 外链自动 `target="_blank" rel="noopener"`；`nofollow=1` 时追加 `rel="nofollow"`。
- URL 白名单过滤失败的条目**直接跳过**（后台列表标红提示，前台零痕迹）。

### 5.2 后台

「友链」Tab：列表 CRUD + 排序 + 投放面选择（首页 / 内页 / 两处）+ nofollow 开关；
按投放面分两栏展示预览。批量添加沿用 edupick 的文本格式（每行 `名称 | URL | nofollow`），
便于从旧站迁移。

## 六、赞助

参考 edupick `sponsor` 配置 + `/sponsor/` 独立页 + 底部入口。KeeTools 需求文档
§变现已定「赞助」为收益来源之一，此处为其最小实现（**不做**支付对接 / 订单，
那是 P5 可选项）。

### 6.1 配置（site_config，前缀 `sponsor_`）

| 键 | 说明 |
|---|---|
| `sponsor_enabled` | 总开关（关 = 前台所有赞助入口消失） |
| `sponsor_title` / `sponsor_desc` | 赞助页标题与导语（edupick 文案模板可直接抄） |
| `sponsor_cost_note` | 站点开销说明（如「服务器 + 域名 + 网盘，每年约 ¥300」） |
| `sponsor_note` | 自愿声明（不赞助不影响任何功能） |
| `sponsor_wechat_qr` / `sponsor_alipay_qr` | 收款码图片（站内路径 `/assets/...` 或外链，过白名单） |
| `sponsor_show_footer` | 页脚「支持本站」入口 |

### 6.2 页面与入口

- 路由 `/sponsor/`：开销说明 → 收款码双卡（微信 / 支付宝，未配置显示占位）→ 鸣谢列表。
- 入口（`sponsor_show_footer` 控制）：页脚「支持本站」链接 + 首页底部 CTA 卡（可关）。
- **「我扫了这码」按钮**：点击上报一次匿名事件（P1 统计上线后加
  `sponsor_click` 事件类型到 stats 表 CHECK 白名单），让站长知道转化情况；
  不收集任何个人信息。

### 6.3 鸣谢

```sql
CREATE TABLE sponsor_thanks (
    id         INTEGER PRIMARY KEY,
    name       TEXT NOT NULL,        -- 留名，1~20 字
    note       TEXT NOT NULL DEFAULT '',  -- 一句话，60 字内
    amount     TEXT NULL,            -- 可选展示（如 ¥10），不强制
    created_at TEXT NOT NULL
);
```

后台「赞助」Tab 内 CRUD，前台按时间倒序展示。没有记录时该区块整体隐藏。

## 十、验收标准（并入 P1 验收）

1. **关闭即零痕迹**：广告总开关关 / 插槽无代码 / 公告关闭 / 赞助关闭时，
   首页 HTML 中 `ad-slot`、`notice-bar`、sponsor 节点计数 = 0
2. **工具页永无广告**：`/tool/{id}/use` 的 `ad-slot` 计数 = 0
3. **URL 白名单**：友链填 `javascript:alert(1)` 被丢弃，前台不输出；
   `//evil.com` 协议相对与 `data:` / `file:` 同样拒绝
4. **分区保存**：保存「页脚」后广告位配置一字未变；保存「广告位」后页脚配置一字未变
5. **生效期**：广告 end_date 为昨日的槽位前台不再输出，无需手动关闭
6. **公告指纹记忆**：关闭公告后刷新不再出现；后台改文案保存后，同访客重新看到
7. **友链投放面**：首页友链不出现在分类页页脚；`all` 的两处都出现；
   nofollow 正确输出到 rel
8. **赞助开关**：`sponsor_enabled=false` 时 `/sponsor/` 返回 404，页脚入口消失
