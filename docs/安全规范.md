## 一、Web 根隔离（第一道防线）

**Web 根必须指向 `public/`**，以下目录**绝对不能**能通过 HTTP 访问：

| 目录 | 风险 |
|---|---|
| `src/` | PHP 源码泄露 |
| `tools/` | 工具源文件直接下载（绕过统计与详情页） |
| `storage/` | **数据库文件被下载 = 全站数据泄露** |
| `var/` | 日志、缓存泄露 |
| `docs/`、`tasks/` | 内部资料泄露 |
| `.env` | **密钥泄露，最严重** |

### 1.1 部署方式

**推荐**：Web 服务器根目录直接指向 `public/`。

```nginx
# Nginx
server {
    root /path/to/KeeTools/public;
    index index.php;
    location / { try_files $uri $uri/ /index.php?$query_string; }
    location ~ \.php$ {
        fastcgi_pass unix:/run/php/php8-fpm.sock;
        fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
        include fastcgi_params;
    }
    # 禁止访问敏感文件
    location ~ /\.(?!well-known) { deny all; }
    location ~* \.(db|sqlite|log|env)$ { deny all; }
}
```

```apache
# Apache：仓库根放 .htaccess 兜底
# /.htaccess
<IfModule mod_rewrite.c>
    RewriteEngine On
    RewriteRule ^(src|tools|storage|var|docs|tasks|scripts)(/|$) - [F,L]
    RewriteRule ^\.env - [F,L]
</IfModule>
```

> **注意**：Apache 兜底规则只在下述情况有效——仓库根被设为 Web 根。若已正确将 Web 根指向 `public/`，兜底规则只是双保险。

### 1.2 `public/` 内部

```
public/
├── index.php        # 唯一入口
├── .htaccess        # 重写规则
├── assets/          # 静态资源（可公开）
└── tool/            # 工具产物（可公开）
```

`public/` 下**不得**放 `.env`、数据库、日志。

## 二、路径穿越（最高危）

manifest 扫描 + 后台文件操作是路径穿越的高发点。

### 2.1 规则

> 任何来自用户输入的路径片段，**必须**经过 `realpath()` 校验，并确认最终路径在允许的根目录内。

### 2.2 实现

```php
<?php
declare(strict_types=1);

final class Security
{
    /**
     * 安全拼接路径并校验未越界
     *
     * @param string $base    允许的根目录（绝对路径）
     * @param string ...$parts 用户可控的路径片段
     * @throws RuntimeException 越界时抛出
     */
    public static function safePath(string $base, string ...$parts): string
    {
        $baseReal = realpath($base);
        if ($baseReal === false) {
            throw new RuntimeException('基础目录不存在');
        }

        // 逐段拒绝危险片段
        foreach ($parts as $part) {
            if ($part === '' || $part === '.' || $part === '..') {
                throw new RuntimeException('非法路径片段');
            }
            if (strpbrk($part, "/\\\0") !== false) {
                throw new RuntimeException('路径片段含非法字符');
            }
        }

        $path = $baseReal . DIRECTORY_SEPARATOR . implode(DIRECTORY_SEPARATOR, $parts);
        $real = realpath($path);

        // 文件可能尚不存在（如新建），此时校验其父目录
        if ($real === false) {
            $parentReal = realpath(dirname($path));
            if ($parentReal === false || !self::isInside($parentReal, $baseReal)) {
                throw new RuntimeException('路径越界');
            }
            return $path;
        }

        if (!self::isInside($real, $baseReal)) {
            throw new RuntimeException('路径越界');
        }
        return $real;
    }

    private static function isInside(string $path, string $base): bool
    {
        $path = rtrim(str_replace('\\', '/', $path), '/');
        $base = rtrim(str_replace('\\', '/', $base), '/');
        return $path === $base || strpos($path, $base . '/') === 0;
    }
}
```

### 2.3 使用示例

```php
// ✅ 正确
$manifestPath = Security::safePath(TOOLS_DIR, $toolId, 'manifest.json');
$html = file_get_contents($manifestPath);

// ❌ 错误 —— 可直接穿越到 ../../.env
$path = TOOLS_DIR . '/' . $toolId . '/manifest.json';
```

### 2.4 工具 id 白名单

`toolId` 来自 URL，除路径校验外，还需格式校验：

```php
if (!preg_match('/^[a-z0-9-]{1,64}$/', $toolId)) {
    throw new RuntimeException('非法工具 id');
}
```

## 三、SQL 注入

### 3.1 规则

> **禁止**字符串拼接 SQL。所有值必须走 PDO 参数化。

### 3.2 正确写法

```php
// ✅ 命名参数
$stmt = $pdo->prepare('SELECT * FROM tools WHERE tool_id = :id AND is_published = 1');
$stmt->execute([':id' => $toolId]);
$tool = $stmt->fetch();

// ✅ 位置参数
$stmt = $pdo->prepare('SELECT * FROM tools WHERE title LIKE ? LIMIT ?');
$stmt->bindValue(1, '%' . $keyword . '%', PDO::PARAM_STR);
$stmt->bindValue(2, $limit, PDO::PARAM_INT);
$stmt->execute();
```

### 3.3 表名 / 列名动态拼装

表名列名无法参数化，必须**白名单**：

```php
$allowedOrderBy = ['created_at', 'view_count', 'title'];
$orderBy = in_array($input['order_by'] ?? '', $allowedOrderBy, true)
    ? $input['order_by']
    : 'created_at';

$allowedDir = ['ASC', 'DESC'];
$dir = in_array(strtoupper($input['dir'] ?? ''), $allowedDir, true)
    ? strtoupper($input['dir'])
    : 'DESC';

$sql = "SELECT * FROM tools ORDER BY {$orderBy} {$dir} LIMIT :limit";
```

### 3.4 PDO 配置

```php
$pdo = new PDO('sqlite:' . $dbPath, null, null, [
    PDO::ATTR_ERRMODE            => PDO::ERRMODE_EXCEPTION,
    PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC,
    PDO::ATTR_EMULATE_PREPARES   => false,   // 使用真实预处理
]);

// SQLite 必要 PRAGMA
$pdo->exec('PRAGMA journal_mode = WAL');
$pdo->exec('PRAGMA busy_timeout = 5000');
$pdo->exec('PRAGMA foreign_keys = ON');
$pdo->exec('PRAGMA synchronous = NORMAL');
```

## 四、XSS（输出转义）

### 4.1 规则

> **所有**输出到 HTML 的内容必须转义。**默认转义，例外才不转义。**

### 4.2 辅助函数

```php
function e(?string $value): string
{
    return htmlspecialchars($value ?? '', ENT_QUOTES | ENT_SUBSTITUTE, 'UTF-8');
}
```

### 4.3 使用

```php
<!-- ✅ HTML 上下文 -->
<h1><?= e($tool['title']) ?></h1>
<p><?= e($tool['description']) ?></p>

<!-- ✅ 属性上下文（含引号，务必用 e()） -->
<a href="/tool/<?= e($tool['tool_id']) ?>" title="<?= e($tool['title']) ?>">

<!-- ✅ JS 上下文 —— 用 json_encode，不用 e() -->
<script>
var toolData = <?= json_encode($tool, JSON_UNESCAPED_UNICODE | JSON_HEX_TAG | JSON_HEX_AMP | JSON_HEX_APOS | JSON_HEX_QUOT) ?>;
</script>

<!-- ✅ URL 参数 -->
<a href="/search?q=<?= urlencode($keyword) ?>">

<!-- ❌ 危险 -->
<div><?= $tool['description'] ?></div>
```

### 4.4 富文本

工具描述等若允许富文本，**必须**使用白名单过滤（只允许 `p` / `br` / `strong` / `em` / `ul` / `li` / `a[href]`），并过滤 `href` 的协议（只允许 `http` / `https` / 相对路径）。**不引入第三方富文本库**（零依赖原则），自己写 50 行白名单过滤器。

## 五、CSRF

### 5.1 规则

> **所有** POST / PUT / DELETE 请求必须带 CSRF token 并在服务端校验。

### 5.2 实现

```php
final class Csrf
{
    public static function token(): string
    {
        if (empty($_SESSION['_csrf'])) {
            $_SESSION['_csrf'] = bin2hex(random_bytes(32));
        }
        return $_SESSION['_csrf'];
    }

    public static function verify(?string $token): void
    {
        if (!is_string($token) || $token === ''
            || empty($_SESSION['_csrf'])
            || !hash_equals($_SESSION['_csrf'], $token)
        ) {
            http_response_code(419);
            exit('CSRF 校验失败');
        }
    }
}
```

### 5.3 表单

```php
<form method="post" action="/admin/tools/save">
    <input type="hidden" name="_csrf" value="<?= e(Csrf::token()) ?>">
    <!-- … -->
</form>
```

### 5.4 AJAX

```js
fetch('/admin/api/save', {
    method: 'POST',
    headers: {
        'Content-Type': 'application/json',
        'X-CSRF-Token': window.__CSRF__
    },
    body: JSON.stringify(payload)
});
```

服务端从 `X-CSRF-Token` 头或 `_csrf` 表单字段读取。

**例外**：`/api/track`（统计上报）为公开端点，不校验 CSRF，但需限流。

## 六、会话安全

| 项 | 要求 |
|---|---|
| 会话 ID 重新生成 | 登录成功后 `session_regenerate_id(true)` |
| Cookie 属性 | `HttpOnly` + `SameSite=Lax` + 生产环境 `Secure` |
| 会话名 | 用 `SESSION_NAME` 环境变量，不用默认 `PHPSESSID` |
| 超时 | 空闲 `SESSION_LIFETIME` 秒后失效 |
| 存储路径 | 默认即可（系统临时目录），不放在 `public/` |
| 登出 | 清空 `$_SESSION` + 删除会话 Cookie + `session_destroy()` |

```php
session_name(getenv('SESSION_NAME') ?: 'et_session');
session_set_cookie_params([
    'lifetime' => 0,
    'path'     => '/',
    'httponly' => true,
    'samesite' => 'Lax',
    'secure'   => (getenv('APP_ENV') === 'production'),
]);
session_start();
```

## 七、认证与权限

### 7.1 密码存储

```php
// 存储
$hash = password_hash($plain, PASSWORD_DEFAULT);

// 校验
if (!password_verify($plain, $hash)) { /* 失败 */ }

// 需要时重哈希
if (password_needs_rehash($hash, PASSWORD_DEFAULT)) {
    // 更新为新哈希
}
```

**禁止**：MD5 / SHA1 / 自写加密。

### 7.2 登录限流

```php
// 同 IP + 同账号，15 分钟内失败 5 次 → 锁定 15 分钟
// 记录在 storage/app.db 的 login_attempts 表
```

| 规则 | 值 |
|---|---|
| 失败窗口 | 15 分钟 |
| 失败阈值 | 5 次 |
| 锁定时长 | 15 分钟 |
| 记录字段 | `ip_hash`、`username`、`attempted_at` |

**注意**：失败提示统一为"用户名或密码错误"，不区分账号是否存在。

### 7.3 角色权限

```php
function require_role(string $role): void
{
    $user = current_admin();
    if (!$user) {
        redirect('/admin/login');
    }
    if ($role === 'admin' && $user['role'] !== 'admin') {
        http_response_code(403);
        exit('无权访问');
    }
}
```

**所有敏感端点必须经过此中介层**：

| 端点 | 要求 |
|---|---|
| 站点设置 | `require_role('admin')` |
| 网盘链接管理 | `require_role('admin')` |
| 工具删除 | `require_role('admin')` |
| 离线包打包 | `require_role('admin')` |
| 工具元数据编辑 | 登录即可（`editor` 可用） |
| 统计看板 | 登录即可（只读） |

### 7.4 无密码后台（高风险功能）

配置 `ADMIN_PASSWORDLESS=true` 时：

| 规则 | 说明 |
|---|---|
| **必须**配 IP 白名单 | `ADMIN_PASSWORDLESS_IPS` 必须为具体 IP，**禁止** `*` |
| 白名单外拒绝 | 非白名单 IP 走正常密码流程 |
| 生产环境保护 | `APP_ENV=production` 且 `ADMIN_PASSWORDLESS=true` 但 IP 不在白名单 → **拒绝服务并报错**，不得静默降级 |
| 后台提示 | 页面顶部显示醒目警告条"当前为无密码模式" |
| 日志 | 每次无密码登录记入 `var/logs/` |

**IP 获取注意**：若在反向代理后，需从 `X-Forwarded-For` 取值，但**必须**先校验可信代理，否则伪造头即可绕过白名单。

```php
function client_ip(): string
{
    // 仅当直连 IP 属于可信代理时才采信 X-Forwarded-For
    $trustedProxies = ['127.0.0.1', '::1'];
    $remote = $_SERVER['REMOTE_ADDR'] ?? '';
    if (in_array($remote, $trustedProxies, true) && !empty($_SERVER['HTTP_X_FORWARDED_FOR'])) {
        $parts = explode(',', $_SERVER['HTTP_X_FORWARDED_FOR']);
        return trim($parts[0]);
    }
    return $remote;
}
```

## 八、生产环境启动自检

`APP_ENV=production` 时，`bootstrap.php` 必须校验以下项，任一不满足则**拒绝启动**：

```php
$errors = [];
if (getenv('APP_DEBUG') === 'true')            $errors[] = 'APP_DEBUG 必须为 false';
if (strlen(getenv('APP_KEY') ?: '') !== 64)    $errors[] = 'APP_KEY 必须为 64 位十六进制';
if (getenv('SITE_DOMAIN') === 'localhost')     $errors[] = 'SITE_DOMAIN 不能为 localhost';

$hasPassword = !empty(getenv('ADMIN_PASSWORD'));
$passwordless = getenv('ADMIN_PASSWORDLESS') === 'true';
$ips = getenv('ADMIN_PASSWORDLESS_IPS') ?: '';
if (!$hasPassword && !$passwordless) {
    $errors[] = '必须设置 ADMIN_PASSWORD，或启用 ADMIN_PASSWORDLESS 并配置 IP 白名单';
}
if ($passwordless && (empty($ips) || strpos($ips, '*') !== false)) {
    $errors[] = 'ADMIN_PASSWORDLESS_IPS 必须为具体 IP，不可为空或通配';
}

if ($errors) {
    http_response_code(500);
    exit("启动自检失败：\n- " . implode("\n- ", $errors));
}
```

## 九、文件上传与导入

| 项 | 要求 |
|---|---|
| 扩展名白名单 | 仅允许 `.zip`、`.json`、`.csv`、`.md`、`.txt` |
| MIME 校验 | 用 `finfo` 读实际 MIME，不信任 `$_FILES['type']` |
| 文件名 | **不使用**原始文件名，重命名为 `{随机串}.{白名单扩展名}` |
| 大小限制 | 单文件上限，超限拒绝 |
| 存储位置 | `var/tmp/uploads/`（不入 git） |
| 禁止 | 上传目录**不得**可执行（`php_flag engine off` 或存到 Web 根之外） |

## 十、离线包打包安全（ZipArchive）

| 项 | 要求 |
|---|---|
| 临时目录 | 用 `var/tmp/package_{随机串}/` |
| 分批添加 | 用 `addFile()` 逐个添加，**不用** `addFromString()` 一次性塞大内容 |
| 路径穿越 | `addFile()` 的第二个参数（zip 内路径）必须过滤 `..` |
| 排除项 | `.DS_Store`、`__pycache__`、`node_modules/`、`var/`、`storage/`、`.git/`、`.env` |
| 异步执行 | 打包为后台任务（前端轮询进度），防 `max_execution_time` 超时 |
| 产出位置 | `packages/`（Web 根之外，通过 PHP 下载控制器提供） |
| 下载限流 | 同一 IP 单位时间内下载次数限制 |
| 清理 | 临时目录用完即删（含异常路径，用 `try/finally`） |

## 十一、统计端点 `/api/track` 的防护

公开端点，不校验 CSRF，容易被打。防护措施：

| 措施 | 说明 |
|---|---|
| 限流 | 同 IP 每分钟最多 N 次 |
| 参数白名单 | `event_type` 只允许 `view` / `use_online` / `netdisk_click` |
| `tool_id` 校验 | 必须存在于 `tools` 表 |
| 长度限制 | 所有字符串参数限长，超长直接拒绝 |
| 不存原始 IP | 只存 `ip_hash = sha256(ip + APP_KEY + 日盐)` |
| 无补偿逻辑 | 被拦截就丢弃，不做重试（见需求文档 §10.1） |

## 十二、日志与信息泄露

| 项 | 要求 |
|---|---|
| 生产环境错误 | `APP_DEBUG=false`，**不向用户显示**堆栈、SQL、路径 |
| 错误日志 | 写 `var/logs/app-{date}.log`，不入 git |
| 后台回显配置 | 所有 `*_PASSWORD`、`APP_KEY` 显示为 `******` |
| 版本号暴露 | 响应头不暴露 PHP 版本（`expose_php = Off`） |
| 目录列表 | Web 服务器关闭目录索引（`Options -Indexes`） |
| 数据库位置 | `storage/` 在 Web 根之外 |

## 十三、安全自检清单

- [ ] Web 根指向 `public/`，`src/` `tools/` `storage/` `var/` `.env` 均不可 HTTP 访问

- [ ] 所有 POST 端点校验 CSRF

- [ ] 登录限流生效，`session_regenerate_id()` 已调用
