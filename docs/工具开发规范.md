# 工具开发规范

> 写任何工具之前**必须**读完本文档。
> 配套：[`manifest规范.md`](manifest规范.md)、[`../AGENTS.md`](../AGENTS.md)
> 最后更新：2026-09-18（P2：浏览器基准修订为现代浏览器优先）

---

## 一、第一原则：工具是独立产品

一个工具 = 一个 HTML 文件 = 一个独立产品。

打开方式只有一种：**双击 `index.html`**。它必须立刻能用，不需要任何前置条件。

推论：

- 不需要服务器
- 不需要联网
- 不需要安装
- 不需要登录
- 不需要网站存在

**检验标准**：把 `index.html` 单独拷到 U 盘，插到一台没网的教室电脑上双击，必须正常工作和保存数据。

---

## 二、目录结构

```
tools/{tool-id}/
├── manifest.json        # 必须 — 工具身份证
├── index.html           # 必须 — 入口
├── CHANGELOG.md         # 必须 — 工具级版本变更日志
├── README.md            # 可选 — 使用说明 / 数据格式
└── assets/              # 可选 — 仅非单文件工具使用
```

`{tool-id}` 规则：

- 只允许 `[a-z0-9-]`
- 全局唯一
- **等于 manifest 的 `id`**，也等于 URL slug
- 命名方式：`功能-花样`，如 `random-name-classic`、`random-name-cartoon`

> 同一逻辑的不同花样（如经典版 / 卡通版）**算两个独立工具**，用相同 `tags` 和 `family` 关联。

---

## 三、单文件规则

> **能单文件的尽量单文件。**

单文件意味着以下全部内联到 `index.html`：

| 内容 | 内联方式 |
|---|---|
| CSS | `<style>...</style>` |
| JS | `<script>...</script>` |
| 图标 | 内联 `<svg><symbol>` + `<use href="#id">` |
| 图片 | base64 data URI（仅小图，<20KB） |
| 字体 | 不使用字体文件，只用系统字体栈 |

### 3.1 例外（允许非单文件）

只有在以下情况才允许使用 `assets/` 相对引用：

- 需要大体积素材（高清图、音频、视频）
- 需要 WebAssembly 模块
- 需要大型 JSON 数据集（> 1MB）
- 其他内联会显著影响性能的情况

例外时必须：

1. manifest 中 `single_file` 设为 `false`
2. `dependencies` 声明实际使用的本地资源
3. 登记到 [`工具例外清单.md`](工具例外清单.md)
4. **离线包打包时整个目录一起打包**（不能只打 `index.html`）

## 四、硬性技术约束

| 项 | 要求 |
|---|---|
| 外部依赖 | ❌ **禁止**任何外部 URL（含 CDN / 在线字体 / 在线图标） |
| 相对路径 | 单文件工具❌ 不得有相对路径引用 |
| 图标 | 使用内联 SVG，来自 `tools/_shared/icons/`。**不得**引用网站 sprite |
| 数据持久化 | `localStorage`，key 命名 `et_{toolId}_{key}` |
| 导入导出 | JSON / CSV，使用 File API |
| 与网站通信 | ❌ 不通信。可选监听 `postMessage` 接收主题参数，但**必须有默认值** |
| 统计 | ❌ 工具内不统计任何操作 |
| 响应式 | 基准 1920×1080，兼容 1024×768 |
| 浏览器 | **现代浏览器优先**（见 §4.1） |

### 4.1 浏览器兼容基准（2026-09-18 修订）

> **决策**：工具基于 H5 实现，**优先适配现代浏览器**（Chrome / Edge 90+、Safari 14+、Firefox 90+）。
> 原先"Win7 + 老版 Chrome / 360 ES5"的约束不再作为硬性要求；引用了浏览器内置能力
> （SpeechSynthesis、WebAudio、TextDecoder GBK 等）时须做**能力检测 + 优雅降级**，不允许白屏或报错中断。

**仍然禁止**（与浏览器新旧无关）：

| 项 | 原因 |
|---|---|
| 任何外部 URL（CDN / 在线字体 / 在线图标） | 零外部依赖硬约束 |
| 无降级的新 API 直接调用 | `file://` 与老内核下可能直接白屏 |

**建议保守使用**：

- 工具代码可用 ES2018+（`const/let`、模板字符串、解构、`async/await`）
- `?.` / `??` / `:has()` 等较新语法在确认基线（Chrome 90+）后可用，但共享片段（`_shared/`）建议保持宽松写法
- SVG 元素的 `className` 是只读的 `SVGAnimatedString`，改 class 一律用 `setAttribute('class', …)` 或 `classList`

### 4.2 字体栈

```css
font-family: "Microsoft YaHei", "PingFang SC", "Hiragino Sans GB",
             system-ui, -apple-system, "Segoe UI", Roboto, sans-serif;
```

### 4.3 大屏设计基准

| 分辨率 | 说明 |
|---|---|
| 1920×1080 | **主基准**，教室大屏 / 一体机 |
| 1024×768 | 兼容，投影仪常见 |
| 1366×768 | 兼容，老笔记本 |

**设计要点**：

- 关键信息（被点到的学生名、倒计时数字）字号要大，后排学生能看清
- 交互按钮大，鼠标/触屏都好点
- 支持全屏（`document.documentElement.requestFullscreen()`）
- 避免依赖悬停（投影场景用鼠标，但触屏一体机常见）

## 五、工具类型

| 类型 | 标识 | 说明 | 示例 |
|---|---|---|---|
| 固定知识型 | `fixed` | 知识有限、标准 | 拼音表、元素周期表、古诗词 |
| 空壳容器型 | `shell` | 老师自行导入数据 | 随机点名、大转盘、倒计时、计分板 |
| 实验模拟型 | `experiment` | H5 理科实验交互 | 电路搭建、凸透镜成像、酸碱滴定 |

### 5.1 `fixed` 型的数据边界（重要）

> **内置数据 > 500 条，就不算"工具"，算"数据包"。**

做法：工具本体做成**通用渲染器**（表格 / 卡片 / 检索 / 筛选），数据放在独立数据文件，官方给一份样例，老师可自行替换。

这样 `fixed` 型和 `shell` 型在架构上统一，维护成本归零，也守住"只做工具不做题库"的定位。

## 六、共享逻辑（`_shared/`，决策 B）

工具物理独立，但**同一逻辑不在多份文件中重复维护**。

### 6.1 `_shared/` 结构

```
tools/_shared/
├── logic/                    # 共享逻辑源
│   ├── random-pick.js        # 随机抽取（去重 / 加权）
│   ├── countdown.js          # 倒计时
│   └── scoreboard.js         # 计分板
├── ui/                       # 共享 UI 片段
│   ├── et-import.js          # 通用数据导入组件（重点基建）
│   ├── et-chrome.js          # 全屏工具条
│   └── et-import.css         # 导入组件样式
├── icons/                    # 工具用图标（内联源，独立于网站图标库）
│   └── icons.svg             # 图标 symbol 集合
└── shared.manifest.json      # 声明各工具引用了哪些片段
```

### 6.2 引用方式

工具 `index.html` 中使用**占位标记**，同步脚本做幂等替换：

```html
<!-- ET:INLINE name="random-pick" src="logic/random-pick.js" -->
<script>
/* 此块由 scripts/sync_shared.py 自动注入，请勿手工修改 */
</script>
<!-- /ET:INLINE -->
```

CSS 同理：

```html
<!-- ET:INLINE name="et-import" src="ui/et-import.css" type="css" -->
<style>
/* 此块由 scripts/sync_shared.py 自动注入，请勿手工修改 */
</style>
<!-- /ET:INLINE -->
```

图标：

```html
<!-- ET:INLINE name="icons" src="icons/icons.svg" type="svg" -->
<svg style="display:none">
  <!-- 图标 symbol 集合 -->
</svg>
<!-- /ET:INLINE -->
```

### 6.3 工作流

```bash
# 改逻辑 → 只改 _shared
vim tools/_shared/logic/random-pick.js

# 同步到所有引用了它的工具
python scripts/sync_shared.py

# 只同步指定工具
python scripts/sync_shared.py random-name-classic

# 检查是否已同步（CI / pre-commit 用）
python scripts/sync_shared.py --check
```

### 6.4 硬规则

- ✅ 改逻辑**只改** `tools/_shared/`
- ❌ **禁止**手工编辑工具内 `ET:INLINE` 标记之间的内容
- ❌ **禁止**手工复制粘贴逻辑代码到工具中
- ✅ 提交前跑 `python scripts/sync_shared.py --check`

#### 6.4.1 工具 HTML 里禁止出现的两种字面量（2026-09-18 新增，踩过坑）

这两种文本一旦出现在**工具 HTML 源码**中（哪怕只是"展示给别人看的代码示例"，或者在注释里），
都会被解析器/同步脚本当真，导致**静默损坏**——门禁全绿但页面已经跑不起来：

| 禁止出现 | 后果 | 正确写法 |
|---|---|---|
| 完整的 `ET:INLINE` 标记对（含 `<!--` 与 `-->`） | `sync_shared.py` 的正则会把它当成真标记，把整份共享代码注入到字符串/注释里 | 展示标记写法时拆开字符串：`'<' + '!-- ET:' + 'INLINE name="…" -->'` |
| script 结束标签的字面量 | HTML 解析器提前闭合外层 `<script>`，其后所有代码变成 HTML 文本 | 字符串里用转义：`'<\/script>'`；注释里改写为"script 结束标签" |

**为什么门禁抓不到**：`check_manifest` / `check_no_external` / `sync_shared --check` 都不做
HTML 或 JS 解析。唯一可靠的本地捕获手段是抽取 `<script>` 块跑 `node --check`
（见 `tasks/P4-工具批次计划.md` 的"每批自检"）。

### 6.5 `shared.manifest.json` 格式

```json
{
  "random-name-classic": {

    "et-import": "ui/et-import.js",
```

## 七、通用数据导入组件（`et-import`，重点基建）

`shell` 型工具的核心留存点是"老师导入名单"。**所有需要导入数据的工具必须复用同一组件。**

### 7.1 支持格式

| 格式 | 来源 |
|---|---|
| 粘贴文本 | 一行一个，支持 `,` `\t` 分隔 |
| CSV | 文件上传 |
| TXT | 文件上传 |
| JSON | 文件上传 |
| Excel | 文件上传（`.xlsx` 需纯 JS 解析，体积较大，评估后决定是否支持） |

### 7.2 必须的能力

- 自动识别列（姓名列 / 学号列 / 权重列）
- 去重
- 空值 / 空白行处理
- 导入预览（前 10 行）
- 错误提示（哪一行有问题）
- 编码识别（UTF-8 / GBK，教室电脑 Excel 导出的 CSV 常为 GBK）

### 7.3 优先级

> 这一个组件做好了，**比多做 20 个工具更有价值**。

## 八、品牌回流（2026-09-18 修订：两层设计）

> **修订**：取消 L1 首次运行弹窗提示——**使用体感第一**，工具打开不弹任何窗；
> 页脚引导（L2）低调常显即可。

| 层级 | 位置 | 说明 |
|---|---|---|
| L2 | 工具内低调页脚一行 | 小字非侵入，如"KeeTools 课工具 · 更多课堂工具" |
| L3 | **离线包本地导航门户** | **主力触点** — 老师一定会打开它 |

**实现要求**：

- 任何形式的启动弹窗 / 浮层引导**一律不做**（`BrandInjector` 同样只注入页脚）
- L2 不得遮挡内容，不得影响大屏观感
- L2 链接指向网站首页，带 UTM：`?from=tool-footer&tool={toolId}`
- 站点来源获取：宿主注入 `window.ET_SITE_ORIGIN`，或 iframe 内 postMessage
  协议（`et-hello` → `et-origin`）发现；都不可得时页脚显示纯文本（必须有默认值）
- `et-chrome.js` 提供统一实现

## 八A、交互约定（edupick 基线，2026-09-18 定稿）

以下为所有数据型工具（`shell`）的统一交互基线：

| 约定 | 说明 |
|---|---|
| **设置入口右上角** | 主界面只保留核心操作；导入 / 导出 / 选项 / 记录等集中在右上角 ⚙ 设置抽屉（`et-chrome` 的 `opt.settings`，右侧滑入抽屉） |
| **按学号快速生成** | 数据型工具必须提供"免手打"路径：起止学号 + 名称模板（`{n}` 占位）一键生成名单/数据（参考 edupick 名单模块） |
| **离线名单** | 工具同目录可选 `roster.js`（`window.ET_ROSTER = "…"` / 数组，`file://` 与 http 均生效）或 `roster.txt`（一行一个，仅 http）。**离线名单优先于本机保存数据**，便于从 PPT / 收藏夹直开免设置；文件不存在时零影响 |
| **导出** | 名单 / 数据提供 CSV 导出（带 BOM，Excel 直开） |
| **iframe 全屏委托** | 工具在 iframe 内时，全屏按钮发 `{type:'et-fullscreen-toggle'}` 给宿主统一 fullscreen（**不允许双层全屏**）；宿主回传 `{type:'et-fullscreen-change', value}` 同步图标 |
| **激光笔 / 翻页笔适配** | 数据型交互工具必须接入 `et-chrome` 的 `opt.primary` / `opt.secondary`：翻页笔的上下页键（PageDown / PageUp）即主 / 副操作键（点名、旋转、开始计时、分节连读等），输入框聚焦与弹窗打开时不响应，`preventDefault` 防止页面滚动 |
| **音效音量** | WebAudio 增益按教室大屏调校（设备 100% 音量也能听清），不做静音兜底提示 |

## 八B、PWA 与统计模块

### PWA 可封装

- `et-chrome` 挂载时自动生成 blob URL manifest（名称 / 主题色 / SVG 图标）+ `theme-color` meta
- 环境不支持时静默跳过；https 部署下工具可被浏览器"安装"为独立应用

### 使用统计（模块化，可移除）

- 共享模块 `ui/et-stats.js`：仅上报匿名打开计数（`use_offline`），不含任何内容数据
- 行为：iframe 内不上报（宿主服务端已计）；独立打开（file:// / 下载单文件 / 离线包）
  且联网时经 `sendBeacon` 上报 `window.ET_SITE_ORIGIN + /api/track`（text/plain 免预检）
- 端点未配置（`ET_SITE_ORIGIN` 缺失）时**完全静默，零请求**
- **整个 `et-stats` 注入块可安全删除**——删除后工具功能不受影响且完全不联网；
  此说明必须写入每个带统计模块工具的 README
- 事件白名单：`StatsService::EVENTS`（增事件须同步 `scripts/init_db.php` 的 CHECK 约束，旧表自动重建）

## 九、版本与变更记录

### 9.1 版本号

语义化版本 `MAJOR.MINOR.PATCH`：

| 变更 | 位数 | 示例 |
|---|---|---|
| 破坏性变更（数据结构不兼容） | MAJOR | `1.2.0` → `2.0.0` |
| 新增功能 | MINOR | `1.2.0` → `1.3.0` |
| Bug 修复 | PATCH | `1.2.0` → `1.2.1` |

### 9.2 必须同步的地方

发布新版时必须同时更新：

1. `manifest.json` 的 `version`
2. `index.html` 内 `ET-META` 的 `version`
3. `CHANGELOG.md` 新增条目
4. `manifest.json` 的 `updated_at`

漏掉任何一处，`python scripts/check_manifest.py` 会报错。

### 9.3 `CHANGELOG.md` 模板

```markdown
# 变更记录 — random-name-classic

## [1.2.0] - 2026-09-18

### 新增
- 支持加权抽取（导入格式新增"权重"列）

### 修复
- 修复 500 人名单导入时的界面卡顿

## [1.1.0] - 2026-09-10

### 新增
- 已点标记与去重开关
```

### 9.4 发布检查清单

```bash
# 1. 升级版本号（manifest + ET-META）
# 2. 更新 CHANGELOG.md
# 3. 校验
python scripts/check_manifest.py

python scripts/sync_shared.py --check

# 4. 手动验证
#    - 双击 index.html 能用

git add tools/{tool-id}
```

- [ ] `CHANGELOG.md` 已更新
- [ ] 无 `?.` / `??` / `structuredClone` / `:has()` 等新 API
- [ ] `localStorage` key 使用 `et_{toolId}_` 前缀
- [ ] 1024×768 与 1920×1080 下都正常
