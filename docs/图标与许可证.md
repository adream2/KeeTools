# 图标与许可证

> 配套：[`需求文档-v2.md`](需求文档-v2.md) §13.1、[`../THIRD-PARTY-LICENSES.md`](../THIRD-PARTY-LICENSES.md)
> 最后更新：2026-09-18

---

## 一、核心原则

> Iconify 是图标**聚合器**，不是单一图标库。只使用其中许可证宽松的图标集，并且**只内置用到的**。

两条独立要求：

| 要求 | 说明 |
|---|---|
| **离线内置** | 产出物中不得引用 `api.iconify.design` 等在线地址 |
| **按需子集化** | 不打包整个图标库，只导出实际用到的图标 |

---

## 二、网站图标与工具图标完全分离

| | 网站图标 | 工具图标 |
|---|---|---|
| 位置 | `assets-src/icons/icons.txt` → `public/assets/icons/sprite.svg` | `tools/_shared/icons/icons.svg` |
| 使用方式 | `<svg><use href="/assets/icons/sprite.svg#i-search"></use></svg>` | 内联 `<svg><symbol>` + `<use href="#i-search">` |
| 构建 | `python scripts/icons/build_sprite.py` | `python scripts/sync_shared.py` |
| 依赖关系 | 依赖网站 CSS | **完全不依赖网站** |

> 工具内的图标必须内联，否则单文件离线会破。

## 三、图标集选择

只从以下**许可证宽松**的图标集中选取：

| 图标集 | Iconify 前缀 | 许可证 | 商用 | 署名 |
|---|---|---|---|---|
| Lucide | `lucide:` | ISC | ✅ | 无需 |
| Tabler Icons | `tabler:` | MIT | ✅ | 无需 |
| Phosphor | `ph:` | MIT | ✅ | 无需 |
| Material Symbols | `material-symbols:` | Apache-2.0 | ✅ | 需保留 NOTICE |

**禁止使用**：

| 图标集 | 原因 |
|---|---|
| `logos:` | 各品牌商标，商用界面使用有法律风险 |
| `simple-icons:` | 同上 |
| `fa-brands:` | 品牌商标 |
| 许可证不明或标注 NC / ND 的集合 | 禁止商用 / 禁止演绎 |

> 默认策略：**只开 Lucide + Tabler**。第三个及以后需要时再评估。

2. 名称形如 `lucide:search`

**要求**：

- `#` 开头为注释
- 按字母序排列（便于 diff）

## 五、构建流程（网站图标）

```
assets-src/icons/icons.txt          手写：用到的图标清单
        │
        │  python scripts/icons/prepare_source.py    ← 唯一联网步骤，仅新增图标时跑
        ▼
assets-src/icons/{集合}.json        离线图标源（按需子集，入库；此后构建不联网）
        │
        │  python scripts/icons/build_sprite.py      ← 离线，pre-commit 会跑 --check
        ▼
public/assets/icons/sprite.svg      产出：SVG sprite（入库）
```

> 图标源是**按需子集**而非整个图标库：Lucide 全量约 1600 个图标，本项目只取用到的 46 个，
> 源文件约 14KB。详见 [`../assets-src/icons/README.md`](../assets-src/icons/README.md)。

> **别名回溯**：Lucide 中 `home` / `trash-2` / `alert-triangle` / `globe-2` 等只是别名，
> 定义体挂在被指向的图标（`house` / `trash` / `triangle-alert` / `earth`）上。
> 构建脚本会沿 `aliases.parent` 链自动解析，`icons.txt` 中可直接写常用名。

### 5.1 sprite 格式

```xml
<svg xmlns="http://www.w3.org/2000/svg" style="display:none" aria-hidden="true">
  <symbol id="i-search" viewBox="0 0 24 24">
    <g fill="none" stroke="currentColor" stroke-width="2"
       stroke-linecap="round" stroke-linejoin="round">
      <circle cx="11" cy="11" r="8"/><path d="m21 21-4.3-4.3"/>
    </g>
  </symbol>
  <!-- … -->
</svg>
```

**规范**：

| 项 | 规则 |
|---|---|
| `symbol` id | `i-{名称}`（去掉集合前缀，如 `lucide:search` → `i-search`） |
| 命名冲突 | 加集合前缀：`i-lucide-search` / `i-tabler-search` |
| `viewBox` | 保留原图标值（通常 `0 0 24 24`） |
| 颜色 | 统一为 `currentColor`，跟随文字颜色 |
| 硬编码颜色 | **一律剥离**；`none` / `currentColor` / `inherit` 保留（删掉会丢失描边） |
| 描边与填充 | 由 `.icon` 统一控制（`fill:none; stroke:currentColor`），symbol 内的 `<g>` 自带兜底属性 |

> 图标源里的 `body` 通常整段包在 `<g fill="none" stroke="…">` 中。
> 剥离硬编码颜色后会剩 `<g fill="none" stroke="currentColor">`，
> 这与 `.icon` 的声明一致，因此**在无 CSS 的场景下也能正确显示**（不会变成实心黑块）。

### 5.2 使用

```html
<!-- 跟随文字颜色 -->
<svg class="icon" width="20" height="20" aria-hidden="true">
  <use href="/assets/icons/sprite.svg#i-search"></use>
</svg>
```

```css
.icon { fill: none; stroke: currentColor; }
.btn:hover .icon { stroke: var(--c-primary); }
```

### 5.3 为什么不用 icon font

| 问题 | 说明 |
|---|---|
| 加载失败变方框 | 字体加载失败时整页图标全废 |
| 无法部分加载 | 字体是整体资源 |
| 无法跟随 `currentColor` 之外的颜色 | 单色字体，多色图标需额外 hack |
| 渲染位置偏移 | 字体基线问题在小尺寸下明显 |
| 体积更大 | 字体通常比用到的 SVG 大 |

## 七、许可证合规检查清单

新增图标时：

- [ ] 图标集在白名单内（Lucide / Tabler / Phosphor / Material Symbols）
- [ ] 非品牌图标（不用 `logos:` / `simple-icons:` / `fa-brands:`）
- [ ] 已登记到 `THIRD-PARTY-LICENSES.md`
- [ ] 若为 Apache-2.0，产出页面保留 NOTICE 声明
- [ ] 不是从某网站上直接抓取的 SVG（来源不明 = 风险不明）

## 八、素材图片

| 项 | 要求 |
|---|---|
| 来源 | 自绘 / 公共领域 / 明确允许商用的素材库 |
| 格式 | 优先 SVG（矢量、体积小） |
| 大小 | 内联进工具时 ≤ 20KB（base64 会膨胀 33%） |
| 登记 | 必须登记到 `THIRD-PARTY-LICENSES.md` |
| 禁止 | 从搜索引擎直接下载的图片（来源与授权不明） |

## 九、工具间图标一致性

工具是独立产品，但图标风格应尽量统一：

- 优先使用 `lucide:`（线条风格统一）
- 通用图标（全屏 / 设置 / 关闭 / 导入）在 `tools/_shared/icons/` 中统一定义
- 通过 `ET:INLINE` 注入，不手工复制

## 十、常见问题

**Q：能否直接引用 Iconify 的 API？**
❌ 不行。`https://api.iconify.design/...` 是外部依赖，违反零外部依赖原则，且离线时全部失效。

**Q：能否下载整个图标库本地部署？**
技术上可以，但不推荐。Lucide 全量约 1600 个图标，即便只保留 SVG 也有数百 KB，而实际用到的可能不到 50 个。按需子集化体积可控制在 10KB 以内。

**Q：网站 sprite 和工具图标能否共用一份？**
不能。工具必须自包含（内联），而 sprite 是外部文件引用。共用会导致工具的单文件离线性被破坏。

**Q：图标颜色怎么改？**
用 `currentColor`。图标 SVG 中的 `stroke` / `fill` 设为 `currentColor`，父元素的 `color` 决定图标颜色。

**Q：如何在老浏览器上兼容 `<use href>`？**
老版 Chrome 需要 `xlink:href`。脚本产出时可同时写两个属性：

```xml
<use href="#i-search" xlink:href="#i-search"/>
```

并在 `<svg>` 根元素声明 `xmlns:xlink="http://www.w3.org/1999/xlink"`。
