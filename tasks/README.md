## 使用规则

1. **每个阶段一个文件**，包含目标、前置条件、任务清单、验收标准
2. **完成即勾选**（`- [ ]` → `- [x]`），进度必须与实际代码状态一致
3. 阶段文档顶部的"状态"字段同步更新
4. 阶段完成后，在文件内记录完成日期与遗留问题
5. 不新建阶段文件——如需调整，修改现有文件
