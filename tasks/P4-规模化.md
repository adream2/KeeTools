## 验收标准

1. **规模达标**：工具总数 ≥ 30，覆盖 ≥ 5 个学科，每学科 ≥ 3 个
2. **全部合规**：`check_manifest.py` / `check_no_external.py` / `sync_shared.py --check` / `check_css_tokens.py` 全部退出码 0
3. **可打包**：任一学段能一键打出 < 10MB 的合集包
4. **SEO 就绪**：`sitemap.xml` 可访问且包含全部详情页；归档版本 `noindex` 生效
5. **数据驱动**：后台能列出"零使用工具"，并且有下线/重做记录
6. **脚手架可用**：`python scripts/new_tool.py` 能在 5 分钟内产出一个可扫描入库的新工具骨架
7. **架构未污染**：`git status` 干净，`var/` 无残留，无临时文件进入仓库

## 风险与备注

| 风险 | 应对 |
|---|---|
| **批量生产导致规范漂移** | 强制走 `new_tool.py` 脚手架 + pre-commit 校验，禁止手抄复制 |
| 工具同质化（同一功能做 10 个变体） | `family` 关联；只在样式/数据/玩法确有差异时才做独立工具 |
| 共享逻辑被绕过手工内联 | `sync_shared.py --check` 进 pre-commit；发现即失败 |
| 零使用工具堆积 | 每季度清理，不看数量看使用率 |
| SEO 垃圾页（搜索页/归档页被索引） | `/search` 与 `/tool/{id}/v/*` 一律 `noindex` |
| 体积膨胀拖慢首屏 | 详情页 iframe 懒加载；静态资源走缓存头 |
