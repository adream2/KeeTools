## 二、现行标准速查（每个工具都必须满足）

### 2.1 生成方式（禁止手抄）

```bash
python scripts/new_tool.py --id <id> --title "<标题>" \
    --type <shell|fixed|experiment> --subjects <学科> --grades <学段> \
    --description "<≤60 字简介>" --family <family> --yes
```

脚手架自动完成：模板渲染 → 登记 `shared.manifest.json` → 内联共享片段 → 双自检 + 体积守卫。

- id：**kebab-case 全小写**，语义英文（`times-table` 而非 `chengfakoujue`）
- `family`：同一玩法的不同版本才填（如 `random-name`），否则留空
- 名单/词表类 `shell` 工具**必须复用 `et-import`**（粘贴 / CSV / 编码识别 / 去重）
- `accent` 按学科自动选取，同批内避免重复

### 2.2 每批自检（缺一不可）

```bash
# 1) 六项门禁
python scripts/check_manifest.py
python scripts/check_no_external.py
python scripts/sync_shared.py --check
python scripts/check_css_tokens.py
python scripts/build_css.py --check
python scripts/icons/build_sprite.py --check

# 2) 运行时抽检（门禁抓不到，必做）
#    抽 <script> 块 → node --check；无头 Chrome/Edge 打开 file:// → 抓 DOM / 截图 / 控制台报错
#    重点验：代码示例里的 ET:INLINE 文本、script 结束标签字面量（见 规范 §6.4.1）
python scripts/check_tools_runtime.py          # 本机 Node v26 + Chrome 可用；缺环境自动跳过

# 3) 入库
php scripts/init_db.php            # 首次
# 后台「扫描同步工具」或等价 CLI 扫描；确认 failed = 0、warnings = 0
```

> 批 1 起，运行时抽检固化为 `scripts/check_tools_runtime.py`（**非门禁**，不进 pre-commit，
> 避免无 Node / 无浏览器的环境被卡住）。截图落在 `var/tmp/render/`，可直接人工核对版式。

### 追加需求：电路「典型电路图库」（2026-09-19）

用户提出「电路中可以再加上典型电路图」→ `circuit-builder` 升到 **1.2.0**。

- **做了什么**：工具栏加「典型电路图」按钮（快捷键 <kbd>G</kbd>），弹出图库展示 **12 个课本常见电路**的示意图缩略图
  （串联一灯 / 串联两灯带开关 / 两灯并联 / 并联·支路开关 / 并联·干路开关 / 电流表测电流 / 电压表测灯泡电压 /
  串联两灯·测其中一灯 / 伏安法测电阻 / 滑动变阻器调光 / 电动机电路 / 短路演示），点图即载入画布；
  图库顶部附电路符号对照表。缩略图**复用同一套电路数据实时生成 SVG**（不是另画一套图），
  所以连接点、符号朝向、电表并联跨接画法与画布完全一致。
- **实现要点**：预设数据仍是 `[方向, 固定行/列, 起, 止, 类型]` 的 runs，新增 `tip` 字段；
  `schematic()` 把 runs 展开成边表 → 算包围盒 → 逐边画标准符号（电源长短板 / 灯泡圆叉 / 开关刀杆触点 /
  电阻矩形 / 变阻器矩形带斜箭头 / 圆圈字母表）→ 按节点度数 ≥3 补连接点。
- **自证（重要，因为上次就是示例图画错）**：12 个示例逐个载入跑求解器，把判定 / 警告 / 总电流 / 各元件
  电流电压 dump 出来核对。关键结论：并联总电流 0.509A；**支路开关只担 0.252A、干路开关担满 0.509A**；
  电压表跨接读数 2.65V 且自身 0A（说明并联跨接没串进主回路）；串联两灯各 1.41V（和 ≈ 电源电压）；
  伏安法 0.266A / 2.66V → R = 10Ω；短路演示给出短路警告且总电流 2.07A、灯泡仅 0.031A。
- **顺带修复**：判定逻辑遗漏电动机（只有电动机时误报「还没有接入用电器」），并补上电阻 / 电动机电路的结论文案。
- **踩坑**：`schematicSymbol()` 第一版漏了 `wire` 分支，导致所有导线被画成电动机表盘（截图对照表一眼看出）——
  说明「生成图形的功能一定要出图核对」，不能只看代码或 DOM 校验。
