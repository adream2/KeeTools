## 验收标准

1. **转化链路**：首页 → 详情页 → 点主按钮 → 网盘中间页 → 拿到链接与提取码
2. **统计可记录**：完成上述流程后，后台看板 3 秒内出现 `view` + `netdisk_click`
3. **统计不越界**：工具内部操作（如点名 100 次）不产生任何统计记录
4. **单文件干净**：下载得到的 HTML 中**不含**任何统计代码
5. **开关生效**：`DOWNLOAD_DIRECT_ENABLED=false` 时详情页无"下载本工具"入口
6. **失效反馈**：点击"链接失效"按钮能通知到管理员
7. **权限**：`editor` 访问网盘管理返回 403
8. **注入安全**：手动构造 `?id=../../.env` 访问 `/tool/{id}/use` 返回 404 而非文件内容
9. **运营模块**：见 `docs/站点运营模块设计.md` §十（关闭零痕迹 / 工具页无广告 / URL 白名单 / 分区保存 / 公告指纹记忆 / 友链投放面）
