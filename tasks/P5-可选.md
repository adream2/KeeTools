## 一、PWA（可选，优先级最低）

**触发条件**：有真实用户反馈"希望像 App 一样打开"。

> 已识别的不利因素：教师认知度低、iOS 不支持 Background Sync、能力与离线合集包重复。

- [ ] `manifest.webmanifest`（本站图标 / 名称 / 主题色）
- [ ] Service Worker（静态资源缓存优先）
- [ ] 离线降级页
- [ ] 上报补传：`online` / `visibilitychange` 触发（**不做复杂重试队列**）
- [ ] 统计端点幂等（同一事件重复上报去重）
- [ ] 明确：SW 不缓存 `/api/track`，不干扰统计

---

## 二、用户系统（可选）

**触发条件**：确定要做"收藏 / 云同步 / 付费增值"时。

- [ ] 用户表 + 注册 / 登录 / 找回
- [ ] 复用后台同款：`Session` / `Csrf` / 密码哈希（`password_hash`）
- [ ] 登录限流与验证码
- [ ] 用户中心：收藏工具 / 使用历史
- [ ] 与访客统计打通（登录用户去重）
- [ ] 隐私合规：隐私政策页 + Cookie 提示
- [ ] **不做**第三方登录（除非明确需要）

---

## 三、云同步（依赖用户系统）

**触发条件**：用户系统上线且有明确"跨设备同步"诉求。

- [ ] 工具内数据结构约定（`localStorage` → 可序列化 JSON 快照）
- [ ] 同步端点（用户态）
- [ ] 冲突策略：**后写覆盖 + 保留一份上一版本**（不做复杂合并）
- [ ] 工具侧零改造优先（靠外壳注入同步桥），否则登记例外

---

## 四、广告联盟（可选）

**触发条件**：流量达到可接广告的量级，且不影响体验。

- [ ] 后台广告位配置（位置 / 代码 / 启用开关 / 生效时间）
- [ ] 广告位：列表页信息流 / 详情页底部 / 网盘中间页（**工具 iframe 内绝不插入**）
- [ ] 广告脚本不影响首屏（懒加载 / `async`）
- [ ] 合规：广告标识、屏蔽检测不做对抗
- [ ] 老浏览器降级（广告脚本失败时页面正常）

## 验收标准

（仅对**实际决定实现**的子项验收）

1. **不破坏既有能力**：实现后 `check_manifest.py` / `check_no_external.py` 仍退出码 0
2. **工具侧零改造**：新增能力不要求修改 `tools/` 内任何文件（否则登记例外）
3. **可关闭**：每个子项有开关，关闭后行为与实现前一致
4. **零外部依赖不破**：引入任何第三方脚本（如广告）必须登记 `THIRD-PARTY-LICENSES.md`，且默认关闭
5. **不污染架构**：临时产物仍只写 `var/`

## 风险与备注

| 风险 | 应对 |
|---|---|
| **为"万一"预埋代码** | 明确禁止。每项都由触发条件驱动，未触发不做 |
| PWA 与离线包能力重叠 | 优先离线包；PWA 只做轻量补强 |
| 广告破坏体验与合规 | 只在信息流与中间页；工具内绝不插；默认关闭 |
| 用户系统带来合规与运维成本 | 无明确变现路径不做 |
| 过早引入第三方脚本破坏"零外部依赖" | 第三方脚本必须默认关闭 + 许可证登记 + 老浏览器降级 |
