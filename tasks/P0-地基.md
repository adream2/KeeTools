## 目标

建立标准化的工程规范与可变现前的最小可用框架：能扫描 `tools/` 目录 → 入库 → 前台展示 → 后台 CRUD。

## 验收标准

（P0 完成的客观判据）

1. **工程规范**：`AGENTS.md` + `docs/` 8 份文档 + `tasks/` 6 份任务单齐备
2. **框架可用**：`php -S localhost:8000 -t public` 启动后首页 200
3. **扫描链路**：放入一个新工具目录 → 后台点"扫描同步" → 前台列表出现 → 详情页可访问
4. **manifest 回写**：后台改工具标题 → `tools/{id}/manifest.json` 文件内容变更 → git diff 可见
5. **版本一致性检测**：故意改错 `ET-META` 版本 → 后台列表该行高亮报错
6. **后台认证**：未登录访问 `/admin/tools` 跳登录页；`editor` 角色访问站点设置返回 403
7. **零外部依赖**：`check_no_external.py` 退出码 0
8. **临时产物隔离**：`git status` 中无 `var/`、无 `*.db`、无 `.env`
9. **CSS 令牌**：`check_css_tokens.py` 退出码 0（`base/components/site` 无字面量）
10. **生产自检**：故意设 `APP_ENV=production` + `APP_DEBUG=true` → 启动报错并退出
