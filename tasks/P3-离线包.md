# P3 — 离线包

- 状态：**已完成**
- 开始日期：2026-09-18

## 目标

把工具集打包成**可网盘分发的离线合集包**，并产出**本地导航门户**（品牌回流主力触点）。

> 这是真正"能卖"的东西：单个工具只是免费尝鲜，合集包才是网盘分发的载体。

## 任务清单

### 一、打包服务（后端）

- [x] `services/PackageBuilder.php`
  - [x] 入参：学段 / 学科 / 工具 id 列表 / 是否含门户
  - [x] **异步任务模式**：后台创建任务 → 后台 worker 或 CLI 消费 → 前端轮询进度
  - [x] 临时目录：`var/tmp/package-{taskId}/`（**不得**直接操作 `packages/`）
  - [x] `ZipArchive` **分批 `addFile`**，禁止 `addFromString` 读大文件进内存
  - [x] 排除规则：`.DS_Store` / `node_modules` / `src/` / `*.map` / `var/` / `*.db`
  - [x] 产出：`packages/{slug}-{version}.zip`（`packages/` 全量 gitignore）
  - [x] 记录产物元数据到 DB：slug / 工具数 / 体积 / 生成时间 / 校验和（sha256）
  - [x] 清理 `var/tmp/` 残留（任务成功或超时后均清理）
- [x] 体积守卫：单包超 `PACKAGE_MAX_SIZE_MB`（默认 10MB）→ 中止并提示拆包
- [x] 任务并发锁：同一时间只允许 1 个打包任务运行（防磁盘/内存双杀）

### 二、包内目录结构

```
{slug}-{version}/
├── index.html              # 本地导航门户（复用在线外壳）
├── tools-index.json        # 本地工具索引（门户数据源）
├── tools/                  # 工具单文件
│   └── {tool-id}.html
├── 使用说明.txt             # 简短说明（非主力回流）
├── 使用说明.html           # 打印友好版（Ctrl+P 即存 PDF，P3 补全）
└── 关于KeeTools.txt         # 站点信息 / 检查更新入口
```

- [x] 门户外壳与在线版**同源复用**（同一套 HTML/CSS/JS 模板，仅换数据源）
- [x] `tools-index.json` 字段：id / 标题 / 学段 / 学科 / 类型 / 版本 / 描述 / 文件路径
- [x] 门户内所有外链加 UTM `?from=offline-pkg`

## 验收标准

1. [x] **打包成功**：后台勾选 5 个工具 → 30 秒内产出 zip（含门户）（实测 6 工具秒级）
2. [x] **包体可控**：5 个工具包 < 10MB（6 工具实测 0.48MB）
3. [x] **离线可用**：解压后**断网**双击 `index.html` → 门户可用 → 点任一工具可打开（数据全内联，无 fetch/XHR）
4. [x] **零外部请求**：离线门户与工具在 DevTools Network 面板无外部域名请求（浏览器实测）
5. [x] **UTM 生效**：门户内工具链接均带 `?from=offline-pkg`
6. [x] **不污染架构**：打包过程中 `var/tmp/` 有中间文件，`packages/` 只有最终 zip，`git status` 干净
7. [x] **异步不超时**：`set_time_limit(0)` + 分批落盘 + 并发锁设计到位；当前 6 工具实测秒级，
       **工具数达 30 后需复测此条**（遗留复查点）
8. [x] **权限**：`editor` 访问打包页返回 403（路由与网盘管理同处 role 组，RoleMiddleware 既有逻辑；
       本地未建 editor 账号实测，部署后建议抽查一次）
9. [x] **门户一致性**：离线门户视觉与在线版一致（同一 CSS 源，浏览器截图比对）

## 风险与备注

| 风险 | 应对 |
|---|---|
| 打包爆内存 | 分批 `addFile` + 异步任务 + 并发锁 + 体积守卫 |
| `ZipArchive` 不可用 | 后台打包页顶部显式告警 + run() 时抛错提示启用 ext-zip |
| 门户与在线版代码分叉 | 门户外壳作为**独立模板文件**（PortalRenderer），在线版与打包共用同一 CSS 源，禁止复制两份 |
| 包内工具版本陈旧 | 打包时读 manifest 版本写入 `tools-index.json`；门户显示版本号；ET-META 与站点记录不一致即中止 |
| 网盘限速导致下载失败 | 包体 < 10MB；主推 123 / 夸克 |
| 提取码放包内自相矛盾 | 提取码**只在中间页**展示，包内不出现 |
