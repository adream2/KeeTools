## 目标

把工具集打包成**可网盘分发的离线合集包**，并产出**本地导航门户**（品牌回流主力触点）。

> 这是真正"能卖"的东西：单个工具只是免费尝鲜，合集包才是网盘分发的载体。

## 任务清单

### 一、打包服务（后端）

- [ ] `services/PackageBuilder.php`
  - [ ] 入参：学段 / 学科 / 工具 id 列表 / 是否含门户
  - [ ] **异步任务模式**：后台创建任务 → 后台 worker 或 CLI 消费 → 前端轮询进度
  - [ ] 临时目录：`var/tmp/package-{taskId}/`（**不得**直接操作 `packages/`）
  - [ ] `ZipArchive` **分批 `addFile`**，禁止 `addFromString` 读大文件进内存
  - [ ] 排除规则：`.DS_Store` / `node_modules` / `src/` / `*.map` / `var/` / `*.db`
  - [ ] 产出：`packages/{slug}-{version}.zip`（`packages/` 全量 gitignore）
  - [ ] 记录产物元数据到 DB：slug / 工具数 / 体积 / 生成时间 / 校验和（sha256）
  - [ ] 清理 `var/tmp/` 残留（任务成功或超时后均清理）
- [ ] 体积守卫：单包超 `PACKAGE_MAX_SIZE_MB`（默认 10MB）→ 中止并提示拆包
- [ ] 任务并发锁：同一时间只允许 1 个打包任务运行（防磁盘/内存双杀）

### 二、包内目录结构

```
{slug}-{version}/
├── index.html              # 本地导航门户（复用在线外壳）
├── tools-index.json        # 本地工具索引（门户数据源）
├── tools/                  # 工具单文件
│   └── {tool-id}.html
├── 使用说明.txt             # 简短说明（非主力回流）
└── 关于EduTools.txt         # 站点信息 / 检查更新入口
```

- [ ] 门户外壳与在线版**同源复用**（同一套 HTML/CSS/JS 模板，仅换数据源）
- [ ] `tools-index.json` 字段：id / 标题 / 学段 / 学科 / 类型 / 版本 / 描述 / 文件路径
- [ ] 门户内所有外链加 UTM `?from=offline-pkg`

## 验收标准

1. **打包成功**：后台勾选 5 个工具 → 30 秒内产出 zip（含门户）
2. **包体可控**：5 个工具包 < 10MB
3. **离线可用**：解压后**断网**双击 `index.html` → 门户可用 → 点任一工具可打开
4. **零外部请求**：离线门户与工具在 DevTools Network 面板无外部域名请求
5. **UTM 生效**：门户内工具链接均带 `?from=offline-pkg`
6. **不污染架构**：打包过程中 `var/tmp/` 有中间文件，`packages/` 只有最终 zip，`git status` 干净
7. **异步不超时**：打包 30+ 个工具时不触发 `max_execution_time` 错误
8. **权限**：`editor` 访问打包页返回 403
9. **门户一致性**：离线门户视觉与在线版一致（同一 CSS 源）

## 风险与备注

| 风险 | 应对 |
|---|---|
| 打包爆内存 | 分批 `addFile` + 异步任务 + 并发锁 + 体积守卫 |
| `ZipArchive` 不可用 | 启动自检报错；降级方案为"生成目录 + 提示用户自行压缩" |
| 门户与在线版代码分叉 | 门户外壳作为**独立模板文件**，在线版与打包共用同一模板，禁止复制两份 |
| 包内工具版本陈旧 | 打包时读 manifest 版本写入 `tools-index.json`；门户显示版本号 |
| 网盘限速导致下载失败 | 包体 < 10MB；主推 123 / 夸克 |
| 提取码放包内自相矛盾 | 提取码**只在中间页**展示，包内不出现 |
