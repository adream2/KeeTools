## 验收标准

1. **5 个工具全部可用**：双击 HTML 即用，断网可用
2. **零外部请求**：DevTools Network 面板无任何外部域名请求
3. **共享生效**：改 `_shared/logic/random-pick.js` → 跑同步脚本 → 两个工具的代码同步更新
4. **导入组件复用**：至少 3 个工具使用 `et-import`，且是同一份代码注入
5. **大屏可用**：1920×1080 全屏下，关键信息后排可辨
6. **版本一致**：`check_manifest.py` 退出码 0
7. **规范可执行**：开发过程中未出现需要违反 `docs/工具开发规范.md` 的情况，或违规点已回写文档
8. **examples**：每个工具内 `README.md`（可选）说明数据格式

## 风险与备注

| 风险 | 应对 |
|---|---|
| `et-import` 复杂度超预期 | 这是**核心基建**，值得投入。若 xlsx 解析过重，先砍掉 Excel 支持（CSV 覆盖 90% 场景） |
| 老浏览器 Canvas 性能 | 转盘用 SVG 或降低帧率；实测 360 浏览器 |
| 规范与实际不符 | **这正是本阶段的目的** — 发现问题立即回写文档，不要绕过 |
| 工具数量诱惑 | 严格控制在 3-5 个。**规范未稳不做第 6 个** |
